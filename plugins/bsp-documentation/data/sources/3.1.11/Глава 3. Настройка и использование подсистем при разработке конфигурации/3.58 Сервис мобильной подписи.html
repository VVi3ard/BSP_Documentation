Сервис мобильной подписи

Подсистема Сервис мобильной подписи предоставляет программный и пользовательский интерфейс для отправки документов в сервис 1С:Мобильная подпись для подписания в приложении Моя подпись от ФНС. Используется совместно с подсистемой Электронная подпись.

Примечание

Для отправки обращений в службу поддержки фирмы «1С» используется подсистема Обращения в техническую поддержку.

Настройка

Для удобства заполнения данных подписанта при добавлении в общем модуле СервисМобильнойПодписиПереопределяемый необходимо вписать код в процедуры ПриЗаполненииРеквизитовОрганизации, ПриЗаполненииРеквизитовФизическогоЛица. См. пример в демонстрационной конфигурации.

Настройка прав доступа пользователей

Для настройки прав доступа пользователей к данным подсистемы Сервис мобильной подписи следует использовать следующие роли:

№ Роли и их назначение
БазовыеПраваБСП(из подсистемы Базовая функциональность)
Отправка документов подписантам при условии, что отправителю известны их данные в сервисе мобильной подписи и подписант есть в справочнике.
ДобавлениеИзменениеПодписантовМобильногоСервиса
Добавление подписантов сервиса мобильной подписи, выбор из справочника при отправке документов. Просмотр и удаление документов, отправленных подписанту пользователем.
ПолныеПрава (из подсистемы Базовая функциональность)
Изменение всех доступных свойств подписантов и отправленных в сервис документов.
