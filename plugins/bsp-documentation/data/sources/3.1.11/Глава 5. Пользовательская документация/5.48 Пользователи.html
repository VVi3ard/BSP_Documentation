5.48 Пользователи

Примечание для технического писателя: в зависимости от того, используется ли подсистема «Пользователи» в конфигурации совместно с подсистемой «Управление доступом» или нет, могут различаться внешний вид и функциональные возможности подсистемы. Поэтому далее по тексту приведены примечания, к какому варианту внедрения относится тот или иной фрагмент документации. При компоновке документации необходимо оставить только те фрагменты, которые относятся к определенному варианту внедрения, используемому в конфигурации.

Для администратора предусмотрена возможность вести список пользователей, работающих с приложением, а также настраивать им права доступа. Учет пользователей ведется в списке Пользователи, который можно сгруппировать, например, по подразделениям компании. Подробнее см. раздел Список пользователей. Часть работы может выполнять ответственный за список пользователей. Подробнее см. раздел Ответственный за список пользователей.

Партнерам, покупателям в интернет-магазине, респондентам в приложении для анкетирования можно разрешить вход в приложение с помощью списка Внешние пользователи. Подробнее см. раздел Внешние пользователи.

В приложении предусмотрена возможность оперативного и безопасного восстановления паролей пользователей. Подробнее см. раздел Настройка восстановления паролей.

Пользователи (и внешние пользователи) могут указываться в качестве ответственных за те или иные документы, исполнителей в задачах, также можно задавать по ним отбор в отчетах, которые содержат информацию о них и т. п.

Для администратора в приложении предусмотрена возможность просмотра и редактирования сведений о пользователях приложения. Подробнее см. раздел Пользователи приложения.

Примечание: не следует использовать Конфигуратор для добавления пользователей и настройки прав доступа.

Приложение соответствует современным требованиям информационной безопасности. Для повышения степени защиты от несанкционированного доступа предусмотрены возможности:

■ Настройка и контроль сложности пароля;

■ Требование смены пароля по расписанию или вручную. Смена пароля – периодически или по требованию;

■ Настройка и контроль повторяемости пароля;

■ Ограничение срока действия учетных записей.

Подробнее см. раздел Настройки входа.

Настройка приложения

Для того чтобы в списке Пользователи (и Внешние пользователи) можно было использовать группы, включите флажок Группы пользователей в разделе Администрирование – Настройки пользователей и прав – Пользователи.

Удобно использовать группы, когда в приложении много пользователей:

■ для группировки большого количества пользователей (например, при выборе пользователя);

■ для групповой настройки прав доступа сразу для всех пользователей, входящих в группу (например, бухгалтеров включают в группу Бухгалтерия, затем группе настраивают права доступа к спискам, документам и т. п.).

При небольшом количестве пользователей или когда он всего один, группы, как правило, не нужны.

Для предоставления внешним пользователям доступа к приложению включите флажок Разрешить доступ внешним пользователям.

Приложение выводит сообщение с просьбой подтвердить свой выбор. Выводится также предупреждение, что в случае разрешения доступа внешним пользователям список выбора пользователей при входе в приложение станет пустым.

Для того чтобы исключить возможность просмотра имен пользователей злоумышленником, флажок Показывать в списке выбора автоматически выключается и скрывается у всех пользователей при включении администратором использования внешних пользователей в приложении. Подробнее см. раздел Ввод нового пользователя.

Для подтверждения своего выбора нажмите Да.

После включения флажка Разрешить доступ внешним пользователям становится доступной ссылка Внешние пользователи, если перейти по данной ссылке, откроется список внешних пользователей. Подробнее см. раздел Список внешних пользователей.

Настройка восстановления паролей

В приложении предусмотрена возможность оперативного и безопасного восстановления паролей пользователей. Если пользователь забыл свой пароль для входа в приложение, он может восстановить пароль без обращения к администратору (подробнее см. раздел Восстановление пароля при входе в приложение).

Для того чтобы у пользователей (и внешних пользователей) появилась возможность восстановления пароля, необходимо произвести настройки с помощью ссылки Восстановление паролей в разделе Администрирование – Настройки пользователей и прав – Пользователи. При этом настройку почты для восстановления пароля у внешних пользователей может выполнять только администратор.

Включите флажок Отображать гиперссылку «Нужна помощь» в диалоге аутентификации, введите путь для получения помощи в Интернете. Кнопку «Нужна помощь» можно использовать, чтобы указать адрес сайта с информацией о том, что делать, когда пользователь не может зайти, забыл логин, или вообще не зарегистрирован в приложении (куда звонить или писать, где регистрироваться и т. д.). С помощью кнопки  можно сразу проверить ссылку в работе.

Включите флажок Отображать гиперссылку «Забыли пароль», для того чтобы у пользователей была возможность восстановить забытый пароль при входе в приложение.

С помощью кнопок укажите, как Восстанавливать пароль:

■ по электронной почте – подробнее см. раздел Настройки для восстановления пароля по электронной почте.

■ переходом по ссылке (пароль можно будет восстановить на указанном в этой строке сайте).

Настройки для восстановления пароля по электронной почте

В приложении предусмотрено три способа восстановления пароля по электронной почте:

■ Стандартный сервис отправки – используется стандартный сервис восстановления паролей от фирмы"1С";

■ Настройка почты – для отправки используются настройки почты, которые хранятся в приложении. Потребуется выбрать из списка адрес почты, с которого будет отсылаться пароль, например, Служба техподдержки (support@mycompany.zzz). Подробнее см. раздел документации Работа с почтовыми сообщениями.

■ Указанный почтовый сервер – требуется ввести параметры сервера для отправки. Если выбраны Настройки почты, данные о почтовом сервере заполняются приложением автоматически, подробнее см. раздел документации Работа с почтовыми сообщениями.

Шаблон сообщения

Во время настройки восстановления пароля можно заготовить шаблон сообщения: написать текст письма, который придет пользователю с кодом для восстановления пароля. Шаблоном сообщения можно воспользоваться только при отправке писем в вариантах Настройки почты и Указанный почтовый сервер.   Текст сообщения является произвольным, однако имеются необходимые параметры, без которых его отсылать нет смысла. С помощью кнопки в текст можно Вставить параметр:

■ Код подтверждения (&VerificationCode) – код для восстановления пароля, является обязательным, будет сгенерирован приложением автоматически при отправке сообщения;

■ Имя пользователя (&UserPresentation);

■ Наименование конфигурации (&ApplicationPresentation).

Код подтверждения

При необходимости изменить настройки длины кода подтверждения и попыток восстановления пароля:

■ Длина генерируемого кода – длина кода подтверждения для восстановления пароля, целое число в диапазоне от 8 до 50.

■ Минимальное время между повторными запросами – длительность блокировки запроса отправки нового кода для подтверждения пароля (в секундах).

■ Допустимое количество неудачных попыток ввода – максимальное количество попыток проверки кода подтверждения восстановления пароля. Если данное значение превышено, пользователю необходимо запросить отправку нового кода для восстановления пароля.

Проверка карточек пользователей

Если у всех пользователей было выключено восстановление пароля, то при первом включении флажка Отображать гиперссылку "Забыли пароль?" приложение автоматически выключает флажок Пользователю запрещено восстанавливать пароль у всех пользователей, у которых заполнено поле Электронная почта на вкладке Адреса, телефоны.

Для новых пользователей необходимо заполнять вкладку с контактной информацией, а также проверить состояние флажка. Подробнее см. раздел Адреса, телефоны.

Особенности восстановления пароля в приложении в Интернете

В приложении в Интернете настройки восстановления пароля выполняются в менеджере сервиса на всю информационную базу (неразделенная).

Ссылка Восстановление паролей в разделе Администрирование отсутствует.

Сейчас почта пользователя вводится обязательно, поэтому она есть у всех. Запись предупреждения в журнале регистрации при попытке восстановления пароля выполняется приложением.

Настройки входа

Для защиты от несанкционированного доступа к приложению в разделе Администрирование – Настройки пользователей и прав – Пользователи предусмотрена ссылка Настройки входа.

Настройки входа содержат четыре вкладки:

■ Для пользователей;

■ Для внешних пользователей (если разрешен доступ внешним пользователям);

■ Дополнительно;

■ Запрещенные пароли (доступно в платформе 1С:Предприятие 8.3.26).

Для пользователей и внешних пользователей приложения можно настроить такие параметры как:

■ настройка и контроль сложности пароля;

■ смена пароля – периодически или по требованию, частота смены пароля;

■ контроль повторяемости пароля;

■ ограничение срока действия пользователей (внешних пользователей);

■ завершение сеанса при бездействии пользователя (доступно в платформе 1С:Предприятие 8.3.26);

■ список и сервис запрещенных паролей (доступно в платформе 1С:Предприятие 8.3.26);

■ настройка предупреждения об окончании срока работы пользователя (доступно в платформе 1С:Предприятие 8.3.26).

Для внешних пользователей можно установить Отдельные настройки для внешних пользователей.

Ссылка Настройки входа недоступны в базовых версиях приложения.

При работе в приложении в Интернете настройки можно только посмотреть. Установить настройки входа может только администратор сервиса в менеджере сервиса. При этом настройки входа будут общие для всех пользователей сервиса.

Укажите с помощью флажков требования к паролю:

■ Пароль должен отвечать требованиям сложности – проверять, чтобы новый пароль имел не менее 7 символов, содержал любые 3 из 4-х типов символов: заглавные буквы, строчные буквы, цифры, специальные символы, не совпадал с именем (для входа);

■ Минимальная длина пароля – по умолчанию 8 знаков;

■ Пароль должен отсутствовать в списке запрещенных – подробнее см. Запрещенные пароли (доступно в платформе 1С:Предприятие 8.3.26);

■ Если одно из требований выше не выполнено при входе – то можно предложить смену пароля или потребовать смену пароля;

■ Максимальный срок действия пароля – срок после первого входа с новым паролем, после которого пользователю потребуется сменить пароль, по умолчанию 30 дн.;

■ Минимальный срок действия пароля – срок после первого входа с новым паролем, в течение которого пользователь не может сменить пароль, по умолчанию 1 дн.;

■ Запретить повторение пароля среди последних – по умолчанию 10 знач. Таким образом, обеспечивается контроль повторяемости паролей;

■ Предупреждать об окончании срока действия пароля за – по умолчанию 5 дней до истечения срока действия пароля. При входе в приложение появляется предупреждающее окно для смены пароля, где сразу можно сменить пароль.

■  Запрещать вход в приложение пользователям, которые не работали в приложении более – срок относительно последней активности пользователя, после которого вход в приложение будет запрещен, по умолчанию 45 дн.

Подробнее об установке пароля см. раздел Аутентификация.

На вкладке Дополнительно отображается настройка Показывать в списке выбора в карточке пользователя.

Включено для новых пользователей – данная настройка означает, что в карточке нового пользователя флажок Показывать в списке выбора будет включен.

Соответственно, если выбрать Выключено для новых пользователей – в карточке нового пользователя флажок Показывать в списке выбора будет выключен.

Если в настройках списка выбора Скрыто и включено для всех пользователей, то при входе в приложение список выбора пользователей станет полным, а флажок Показывать в списке выбора в карточках всех пользователей будет включен и скрыт.

Скрыто и выключено для всех пользователей – при входе в приложение список пользователей станет пустым, а флажок Показывать в списке выбора в карточках всех пользователей будет очищен и скрыт.

Если в настройках приложения включен флажок Разрешить доступ внешним пользователям, то настройка Показывать в списке выбора на вкладке Дополнительно станет недоступной.

С помощью флажка Если пользователю ограничен срок работы в программе, предупреждать об окончании срока за (по умолчанию 7 дней) - выводится предупреждение, если включено ограничение на вход в карточке пользователя или включена общая настройка входа.

В случае клиент-серверного варианта работы на вкладке Дополнительно также можно указать следующие параметры:

■ Количество попыток ввода пароля до блокировки – по умолчанию 3 попытки;

■ Длительность блокировки ввода пароля – время блокировки входа, после неудачных попыток ввода пароля,  по умолчанию 5 мин.;

При использовании платформы 1С:Предприятие версии 8.3.26 на вкладке Дополнительно также можно задать следующие параметры:

■ Если пользователю ограничен срок работы в приложении, предупреждать об окончании срока за – предупреждение выводится, если включено ограничение на вход в карточке пользователя или включена общая настройка входа, по умолчанию 7 дней;

■ Завершать сеанс при бездействии пользователя более – если пользователь не выполняет никаких действий в приложении в течение определенного периода времени, можно завершить его сеанс, по умолчанию более 960 мин. Также есть возможность Предупредить о завершении сеанса при бездействии, по умолчанию за 5 мин.;

■ Разрешить сохранять пароль при входе в приложение – cохранение пароля при входе в приложение упрощает авторизацию и избавляет от необходимости вводить пароль каждый раз. При этом можно указать Время сохранения пароля, по умолчанию 7200 мин.

На вкладке Запрещенные пароли отображается настройка списка запрещенных паролей, которая помогает повысить безопасность учетных записей пользователя, предотвращая использование ненадежных паролей (доступно в платформе 1С:Предприятие 8.3.26).

■ Стандартный список – база паролей, которая встроена в платформу 1С:Предприятие.

■ Дополнительный список – позволяет установить список паролей из текстового файла.

■ Сервис проверки – позволяет проверять вводимые пароли на соответствие списку запрещённых паролей. Если вводимый пароль совпадает с одним из запрещённых, система отказывает в регистрации такого пароля. Максимальное время ожидания сервиса, по умолчанию 1 сек. Также можно Разрешить вход, если сервис не сможет выполнить проверку.

Персональные настройки

Некоторые функции приложения настраиваются непосредственно на рабочем месте пользователя, поэтому их называют персональными настройками. См. также раздел документации Настройка приложения.

Восстановление пароля при входе в приложение

В настоящее время увеличилось количество удаленных пользователей. Это накладывает определенные требования на приложение, в частности, теперь пользователям необходимо при входе всегда вводить пароль, для того чтобы в приложение не проникли злоумышленники. Однако пароль можно забыть. Приложение позволяет безопасно восстановить пароль при входе.

Вид ссылок и необходимые действия при восстановлении пароля зависят от настроек администратора (подробнее см. раздел Настройка восстановления паролей). Пользователю может быть запрещено восстанавливать пароль, сведения об этом необходимо узнать у администратора.

Если забыли пароль, то можно восстановить его, например:

■ По ссылке для перехода на сайт восстановления паролей.

■ По электронной почте. Для этого необходимо перейти по ссылке Забыли пароль? Также можно перейти по ссылке Нужна помощь? По ссылке можно перейти на сайт с информацией о том, что делать, когда пользователь не может зайти, забыл логин, или вообще не зарегистрирован в приложении (куда звонить или писать, где регистрироваться и т. д.).

После ввода адреса электронной почты необходимо нажать кнопку Получить код, на этот адрес высылается письмо с кодом для восстановления пароля.

После получения письма введите код подтверждения, после этого можно ввести Новый пароль и Подтверждение пароля. Следует запомнить новый пароль, также можно записать его в надежном месте. Нажмите кнопку Установить новый пароль.

После этого можно войти в приложение с новым паролем.

■ Программно в связи с окончанием срока действия пользователя, подробнее об этом см. разделы Настройки входа и Ограничение на вход в приложение.

Хороший пароль должен состоять не менее чем из восьми символов, включать в себя заглавные и прописные латинские буквы, цифры, символы (подчеркивание, скобки и т. д.) и быть малопонятным выражением. Нежелательно, чтобы пароль совпадал с именем пользователя, полностью состоял из цифр, содержал понятные слова, содержал чередующиеся группы символов. Примеры хороших паролей: “nj7{jhjibq*Gfhjkm, F5”njnGhkmNj;t{HI. Примеры неудачных паролей: Иванов, qwerty, 12345678, 123123123. Подробнее см. книгу 1С:Предприятие 8.3. Руководство администратора.

В приложении предусмотрена возможность автоматической проверки сложности пароля раздельно для внутренних и внешних пользователей. Подробнее см. раздел Настройки входа.

По умолчанию в целях безопасности пароль при вводе не показывается. Для того чтобы видеть, какие символы вводятся, включите флажок Показывать новый пароль. В этом случае подтверждение вводить не требуется.

Нажмите кнопку Установить пароль.

После этого состояние аутентификации 1С:Предприятие меняется на Пароль установлен. В карточке пользователя, которая доступна в персональных настройках приложения, кнопка меняет значение на Сменить пароль.

Это открытая децентрализованная система аутентификации пользователей, которая позволяет пользователю иметь один логин-пароль для различных веб-сайтов. Данный вид аутентификации доступен в веб-клиенте и тонком клиенте, который работает через веб-сервер. Для корректной работы приложения в этом случае должен быть также включен флажок Аутентификация 1С:Предприятия. Подробнее см. книгу 1С:Предприятие 8.3. Руководство администратора.

Аутентификация по протоколу OpenID-Connect - позволяет системе проверить личность пользователя на основе аутентификации, выполненной сторонним провайдером. В результате, для того чтобы получить доступ к прикладному решению 1С:Предприятия, пользователи могут использовать свои учетные данные на других сайтах, поддерживающих OpenID-Connect Аутентификацию. В частности, в качестве такого сайта можно использовать Единую систему идентификации и аутентификации (ЕСИА), при этом авторизация будет происходить через сайт госуслуг gosuslugi.ru. Аутентификация OpenID-Connect применима при использовании тонкого клиента, веб-клиента и мобильного клиента.

Аутентификация токеном доступа – аутентификация с помощью JWT-токенов (стандарт RFC 7519). По сравнению с ранее принятыми способами аутентификации JWT-токены имеют ряд преимуществ, например, при помощи JWT-токена можно сгенерировать ссылку, по которой пользователю будет на определенное время предоставлен интерактивный вход в приложение (без ввода логина/пароля). Многие публичные сервисы используют аутентификацию через JWT-токены – например, Единая система идентификации и аутентификации (ЕСИА), сервисы Министерства здравоохранения и социального развития, Национальная система цифровой маркировки «Честный знак».

Для того чтобы упростить вход в приложение, можно включить флажок Аутентификация операционной системы, в поле Пользователь с помощью кнопки  Выберите, под каким именем данный пользователь работает в операционной системе. Под этим именем он будет входить в приложение.

Если ни один флажок Аутентификация не включен, то автоматически выключается и флажок Вход в приложение разрешен.

Для того чтобы в списке посмотреть всех пользователей, которые имеют Аутентификацию по протоколу OpenID-Connect, необходимо установить в Настройке списка отбор по данной аутентификации.

Только для конфигураций, в которых подсистема используется совместно с подсистемой «Управление доступом»:

Изменения прав доступа применяются после перезапуска приложения. В текущих сеансах действуют прежние права доступа.

Ответственный за список пользователей

Если пользователей (внешних пользователей) много, то работу по ведению списка может выполнять ответственный за список пользователей.

Для ввода или редактирования сведений о пользователе необходимы права администрирования или ответственного за список пользователей.

Вход в приложение разрешает только администратор.

Ответственный за список может выполнять ограниченное ведение списка пользователей:

■ настройка пользователя до разрешения входа в приложение администратором;

■ ведение списков Пользователи и Группы пользователей;

■ настройка прав доступа пользователей.

Если пользователя ввел ответственный за список и заполнил имя для входа, то администратору в карточке пользователя выводится рекомендация проверить настройки для входа. После разрешения входа рекомендация скрывается, а ответственный более не может изменить настройки для входа, кроме отключения разрешения на вход в приложение.

Для того чтобы посмотреть всех пользователей, которых подготовил ответственный, можно установить отбор в списке по полю Подготовлен.

Внешние пользователи

Внешние пользователи предназначены для входа в приложение тех пользователей, которые представлены в ней одним из объектов (например, Сотрудники, Партнеры, Физические лица и др.). Их доступ, как правило, сильно ограничен, они не принимают активного участия в процессах учета, работают обособленно, не взаимодействуют между собой. Например, это партнеры, покупатели в интернет-магазине, респонденты в базе для анкетирования.

Внешние пользователи приложения разного типа, поэтому информация о них хранится в различных списках:

■ Демо: Партнеры;

■ Демо: Контактные лица партнеров.

Для того чтобы внешние пользователи стали доступны, необходимо произвести настройки (см. раздел Настройка приложения).

При вводе или редактировании данных о партнере (контактном лице партнера) можно нажать кнопку  Внешний доступ, для того чтобы зарегистрировать его как внешнего пользователя.

Приложение автоматически заполнит поле Демо: Партнер, с которым связан данный внешний пользователь. Поле редактированию не подлежит.

Если внешний пользователь больше не работает в приложении (например, с партнером прекращены отношения и т. д.), но в приложении введены данные, где он фигурирует (например, он являлся автором документов, исполнителем задач, и т. п.), то его невозможно удалить. Для того чтобы скрывать таких внешних пользователей в различных списках выбора, можно воспользоваться флажком Недействителен. Включение у внешнего пользователя флажка Недействителен доступно администратору приложения и ответственному за список пользователей. Флажок можно выключить в любой момент времени. Подробнее см. раздел Ввод нового пользователя.

По умолчанию новый внешний пользователь не имеет доступа на вход в приложение. Для предоставления доступа необходимо включить флажок Вход в приложение разрешен, после этого можно задать Имя (для входа) и установить пароль для входа в приложение, а также ввести ограничения для входа внешнего пользователя.

Для того чтобы внешний пользователь при входе в приложение ввел свой пароль, который будет известен только ему, включите флажок Потребовать установку пароля при входе.

При необходимости включите флажок Пользователю запрещено изменять пароль.

При необходимости выключите флажок Пользователю запрещено восстанавливать пароль (По умолчанию включен), это позволит восстановить забытый пароль при входе. Подробнее см. раздел Настройка восстановления паролей.

При необходимости включите флажок Аутентификация по протоколу OpenID. Подробнее см. в разделе Ввод нового пользователя.

При необходимости включите флажок Аутентификация по протоколу OpenID-Connect. Подробнее см. в разделе Ввод нового пользователя.

При необходимости включите флажок Аутентификация токеном доступа. Подробнее см. в разделе Ввод нового пользователя.

В списках также можно воспользоваться кнопкой  Внешний доступ. Для этого выделите нужный элемент списка. Обратите внимание, что элементы списка, у которых уже имеется внешний доступ, обозначены значком  в колонке  Предоставлен внешний доступ.

Список внешних пользователей

Список Внешние пользователи позволяет разрешать вход в приложение пользователям, которые представлены в ней одним из объектов. Ведение списка внешних пользователей выполняет администратор или сотрудник, отвечающий за работу с внешними пользователями, например, за работу с партнерами (см. раздел Ответственный за список пользователей).

Список Внешние пользователи можно открыть с помощью ссылки раздела Администрирование – Настройки пользователей и прав – Внешние пользователи.

Если в приложении предусмотрены группы пользователей (см. раздел Настройка приложения), то внешних пользователей в списке также можно группировать, например, по видам отношений с ними: партнеры, контрагенты и т. д. Для этого в левой части списка необходимо создать необходимое количество групп внешних пользователей и добавить в них внешних пользователей. При настройке состава участников групп внешних пользователей в группы можно добавлять всех внешних пользователей нескольких видов (например, все партнеры и респонденты) или только выбранных пользователей указанных видов. Укажите с помощью кнопки , какие пользователи будут включены в данную группу:

■ Выбранные пользователи указанных видов;

■ Все пользователи указанных видов.

По ссылке Вид, которая по умолчанию принимает значение Не указан, перейдите к выбору вида пользователей.

С помощью флажков укажите вид внешних пользователей, например, Демо: Партнеры. После подтверждения выбора ссылка указывает выбранные виды внешних пользователей.

После этого можно приступить к выбору конкретных участников группы среди внешних пользователей указанного вида. В остальном работа с группами внешних пользователей аналогична работе с группами внутренних пользователей приложения. Подробнее см. разделы Группы и права доступа и Ведение групп пользователей.

Обратите внимание, что в списке выбора значком  обозначены элементы, которым уже предоставлен внешний доступ. Их выбрать уже нельзя, при сохранении такого внешнего пользователя приложение выдает сообщение о проблеме.

После сохранения приложение указывает элемент списка, с которым связан внешний пользователь. Это поле редактировать больше нельзя. С помощью кнопки  Открыть можно просмотреть данные внешнего пользователя в списке, при наличии прав доступа заполнить недостающую информацию о нем.

В остальном работа со списком внешних пользователей не отличается от работы со списком пользователей. См. раздел Список пользователей. Настройка прав внешних пользователей аналогична настройке прав пользователей, см. раздел Группы и права доступа.

Тогда с помощью данного списка могут быть решены следующие задачи:

1. Найти "некорректных" (несопоставленных) пользователей ИБ:

■ Приложение автоматически сопоставляет пользователей ИБ и пользователей в списках;

■ По результатам сопоставления пользователи ИБ становятся неактивными (выделяются серым), если пользователи в приложении были добавлены, изменены или удалены с помощью конфигуратора;

■ Красным шрифтом выделены пользователи ИБ, не сопоставленные с пользователями в списках приложения.

2. Найти рассогласования списка пользователей ИБ со списками пользователей списков приложения:

■ если пользователь ИБ был добавлен с помощью Конфигуратора (или каким-либо нештатным программным способом), предлагается Сопоставить такого пользователя ИБ с пользователем в списке или Удалить с помощью команды меню Еще;

■ если пользователь ИБ был удален с помощью Конфигуратора (или каким-либо нештатным программным способом), но при этом осталась ссылка на него из пользователя в списке, предлагается открыть пользователя в списке и перезаписать его, для того чтобы очистить эту ссылку (или обновить эту ссылку путем создания нового пользователя ИБ);

■ если полное имя пользователя ИБ было изменено с помощью Конфигуратора (или каким-либо нештатным программным способом), предлагается открыть пользователя в списке и перезаписать его, для того чтобы восстановить полное имя пользователя ИБ. Подробнее см. раздел Сопоставление пользователей.

3. Посмотреть список всех пользователей ИБ (этот список также доступен в Конфигураторе).

В списке выводятся сведения:

■ Полное имя – полное имя пользователя ИБ (при рассогласовании может не совпадать с полным именем пользователя в списке Пользователи (Внешние пользователи);

■ Имя (для входа);

■ Аутентификация 1С – принимает значение Да, если в карточке пользователя этот флажок включен;

■ Аутентификация OpenID – принимает значение Да, если флажок включен;

■ Аутентификация OpenID-Connect – принимает значение Да, если флажок включен;

■ Аутентификация токеном доступа – принимает значение Да, если флажок включен;

■ Аутентификация ОС – принимает значение Да, если флажок включен, в этом случае указывается через запятую Пользователь ОС – имя, с которым пользователь входит в ОС, и которое используется для входа в приложение.

Дополнительно выводится информация (по команде Еще – Изменить форму):

■ Сопоставлен с внешним пользователем – принимает значение Да, если это внешний пользователь приложения;

■ Добавлен в конфигураторе – принимает значение Да, если пользователя добавили в Конфигураторе или остается пустым;

■ Изменен в конфигураторе – принимает значение Да, если данные пользователя изменили в Конфигураторе, или остается пустым;

■ Удален в конфигураторе – принимает значение Да, если данные пользователя были удалены в Конфигураторе или остается пустым.

Просмотр проблемных элементов или всего списка

В случае рассинхронизации списков приложение показывает проблемные, несопоставленные элементы, требующие вмешательства. По умолчанию в списке включен флажок Показать только добавленные, измененные или удаленные с помощью конфигуратора.

Выключите флажок, для того чтобы увидеть весь список пользователей ИБ.

Сопоставление пользователей

Для согласования списков в приложении предусмотрены следующие возможности.

С помощью кнопки Сопоставить можно вручную сопоставить пользователя ИБ с существующим в приложении пользователем, для этого:

■ выберите для сопоставления значение Пользователь или Внешний пользователь, нажмите кнопку ОК;

■ выберите пользователя из списка двойным щелчком мыши или выделив его и нажав Выбрать;

■ в открывшемся окне Пользователь (Внешний пользователь) внесите необходимые исправления.

В карточке «некорректного» пользователя выводится предупреждение и две кнопки:

■ Нажмите Заполнить из пользователя ИБ, если в списке пользователей ИБ информация более точная;

■ Нажмите Записать, если в списке Пользователи информация более точная.

Подробнее см. разделы Ввод нового пользователя, Внешние пользователи. Нажмите Записать и закрыть. После этого сопоставление пользователя в двух списках будет восстановлено.

С помощью кнопки Сопоставить с новым можно вручную сопоставить пользователя ИБ, введя нового пользователя, для этого:

■ выберите для сопоставления значение Пользователь или Внешний пользователь, нажмите кнопку ОК;

■ введите нового пользователя (внешнего пользователя) приложения. Подробнее см. раздел Ввод нового пользователя, Внешние пользователи. После сохранения данных сопоставление пользователя в двух списках будет восстановлено.

С помощью кнопки Отменить сопоставление можно отменить автоматическое сопоставление выделенного пользователя ИБ и пользователя одного из списков приложения, для того чтобы сопоставить их вручную. Отмена сопоставления требуется крайне редко – только если сопоставление было выполнено некорректно, например, при обновлении приложения, поэтому не рекомендуется отменять сопоставление по любой другой причине.

Для того чтобы просмотреть информацию о пользователе (внешнем пользователе), сопоставленном выделенному пользователю ИБ, нажмите кнопку Перейти к пользователю.

Отчет Сведения о пользователях

Отчет открывается из списка Пользователи (Внешние пользователи) по команде Еще – Отчеты – Сведения о пользователях (о внешних пользователях). В зависимости от вида списка приложение автоматически выбирает нужный вариант отчета.

Отчет предназначен для просмотра сведений о пользователях приложения, включая настройки для входа (свойства пользователя приложения).

Необходимость в отчете возникает, если требуется выполнить групповой анализ настроек для входа (имени для входа, видов аутентификации и других).

В отчете по умолчанию выдаются сведения:

■ Полное имя пользователя;

■ Вход в приложение разрешен – поле может принимать значение Да, если пользователю разрешен вход в приложение, или остается пустым в обратном случае;

■ Имя (для входа);

■ Аутентификация стандартная – поле может принимать значение Да, если пользователь ее имеет, или остается пустым;

■ Аутентификация ОС – поле может принимать значение Да или остается пустым;

■ Пользователь ОС – имя, с которым пользователь входит в ОС, если пользователь имеет аутентификацию ОС;

■ Аутентификация OpenID – поле может принимать значение Да, если пользователь ее имеет, или остается пустым;

■ Режим запуска.

С помощью кнопки Настройки можно открыть список полей и при необходимости добавить нужные поля в отчет. Например, можно добавить в отчет поля Потребовать смену пароля при входе и Срок действия. Для этого перейдите в расширенный вид настроек и на вкладке Поля и сортировки выделите поля с помощью флажков. Настройки запоминаются. Подробнее см. раздел документации Варианты отчетов.

Отборы пользователей

Для отбора пользователей по одному или нескольким параметрам откройте Настройки отчета с помощью кнопки панели навигации, на вкладке Отборы с помощью флажков укажите нужные параметры.

Подробнее см. раздел документации Варианты отчетов.

По умолчанию возможен отбор пользователей по следующим признакам:

■ Недействительные;

■ Помеченные на удаление;

■ Без пользователя приложения;

■ Вход в приложение разрешен;

■ Аутентификация стандартная;

■ Аутентификация ОС;

■ Аутентификация OpenID.

После выбора параметров отбора пользователей нажмите кнопку Сформировать.

Варианты отчета

С помощью кнопки  Варианты отчета можно открыть список других доступных вариантов отчета.

Существует три варианта отчета:

■ Сведения о пользователях – открывается из списка Пользователи;

■ Сведения о внешних пользователях – открывается из списка Внешние пользователи;

■ Сведения о пользователях и внешних пользователях – общий отчет обо всех пользователях приложения, в котором предусмотрено поле Это внешний пользователь (принимает значение Да или остается пустым) для выделения и отбора внешних пользователей.

Управление настройками пользователей

 Ссылки для управления настройками пользователей можно найти в разделе Администрирование – Настройка пользователей и прав – Персональные настройки пользователей. Управление пользовательскими настройками выполняет администратор.

Доступны ссылки:

■ Копирование настроек – с помощью этой ссылки можно выполнить копирование пользовательских настроек. Подробнее см. раздел Копирование настроек;

■ Очистка настроек – с помощью этой ссылки можно удалить настройки у всех или выбранных пользователей. Подробнее см. раздел Очистка настроек;

■ Настройки пользователей – перейдите по ссылке, для того чтобы открыть список, в котором производится управление пользовательскими настройками. Подробнее см. раздел Список Настройки пользователей.

Копирование настроек

Это может понадобиться, например, если настраивается несколько новых пользователей в одной группе, в которой уже есть пользователи. Для копирования пользовательских настроек выберите ссылку Копирование настроек раздела Администрирование – Настройки пользователей и прав – Персональные настройки пользователей.

Выберите пользователя, от которого необходимо скопировать настройки, например, Администратор.

С помощью переключателя выберите, Кому копировать настройки:

■ Выбранным пользователям – в этом случае становится доступной ссылка Выбрать.

Нажмите на ссылку Выбрать, затем с помощью флажков в правой части списка укажите, каким пользователям нужно скопировать настройки. В левой части списка автоматически подсчитывается, сколько пользователей и в каких группах выбрано.

С помощью кнопки Активные пользователи можно посмотреть список пользователей, работающих в приложении в данный момент.

Нажмите кнопку Выбрать, для того чтобы перейти к дальнейшим настройкам.

Выбор сохраняется, при этом ссылка показывает количество выбранных пользователей. После этого можно перейти к выбору и копированию настроек.

■ Всем пользователям. В этом случае необходимо перейти к указанию, какие настройки будут копироваться.

С помощью переключателя выберите, Что копировать:

■ Все настройки – будут скопированы все настройки. После завершения выбора перейдите к копированию настроек.

■ Отдельные настройки – в этом случае становится доступной ссылка Выбрать. Перейдите по ссылке, выберите из списка нужные настройки с помощью флажков, нажмите кнопку Выбрать.

При выборе настроек для копирования на вкладке Настройки отчетов личные варианты отчетов и их настройки скрываются. Можно скопировать только настройки общих вариантов отчетов. Подробнее о вариантах отчетов и их настройках см. раздел документации Варианты отчетов. Приложение ведет подсчет количества настроек. После завершения выбора настроек можно перейти к их копированию. Ссылка показывает количество выбранных настроек.

Для копирования настроек и возвращения в приложение нажмите кнопку Скопировать и закрыть. Для того чтобы продолжить копирование настроек далее и не закрывать окно, нажмите кнопку Скопировать, для возвращения в приложение нажмите кнопку Закрыть.

Копирование настроек также может быть произведено в списке Настройки пользователей. Подробнее см. раздел Список Настройки пользователей.

Не все пользовательские настройки можно скопировать, даже если был нажат переключатель Все настройки.

При попытке скопировать настройки варианта отчета пользователям, которые не имеют прав доступа на работу с этим вариантом, приложение не копирует настройки и выводит предупреждение Не все варианты отчетов и настройки были скопированы, что у пользователя недостаточно прав. Для получения подробной информации нажмите кнопку Показать отчет.

Личные варианты отчетов также скопировать невозможно. Для того чтобы личный вариант отчета стал доступен другим пользователям, необходимо его пересохранить с выключенным флажком Только для автора. Подробнее см. раздел документации Варианты отчетов.

Очистка настроек

Иногда требуется удалить пользовательские настройки, например, если из-за этих неправильных настроек работа в приложении стала невозможной. Очистить можно все настройки, в том числе и личные варианты отчетов.

Для удаления пользовательских настроек у пользователей перейдите по ссылке Очистка настроек раздела Администрирование – Настройки пользователей и прав.

Очистить настройки можно (выберите с помощью переключателя):

■ У всех пользователей.

При попытке выбрать для очистки Отдельные настройки у всех пользователей приложение выводит сообщение, что это невозможно.

■ У выбранных пользователей:

Для того чтобы очистить настройки у нескольких пользователей, перейдите по ссылке Выбрать. Выберите список пользователей, нажмите кнопку ОК. Подробнее см. раздел Копирование настроек.

В списке Выбор пользователей для очистки настроек включите флажки для нужных пользователей. Для подтверждения нажмите кнопку Выбрать.

Выбор сохраняется. При этом очистить у нескольких выбранных пользователей можно только все настройки, так как по умолчанию переключатель Что очистить установлен в положение Все настройки и недоступен.

Для того чтобы очистить несколько одинаковых настроек у всех или нескольких пользователей, можно открыть список Настройки пользователей. Подробнее см. раздел Список Настройки пользователей.

■ Для того чтобы очистить отдельные настройки у одного пользователя, выберите его из списка, затем выберите с помощью флажков, какие настройки очистить. Выбор сохраняется. Подробнее см. раздел Копирование настроек. При этом окно выбора настроек устроено аналогично списку Настройки пользователей, подробнее см. раздел Список Настройки пользователей.

После окончания выбора нажмите кнопку Очистить и закрыть, для того чтобы очистить настройки и вернуться в приложение.

Нажмите кнопку Очистить, для того чтобы продолжить очистку настроек у других пользователей.

Нажмите кнопку Закрыть для возвращения в приложение без очистки настроек.

Список Настройки пользователей

По ссылке Настройки пользователей раздела Администрирование – Настройки пользователей и прав – Персональные настройки пользователей можно открыть список, который предназначен для управления пользовательскими настройками.

В поле Пользователь  Выберите нужного пользователя. По умолчанию выбран Пользователь Администратор, при этом поле не может быть пустым. При этом если в приложении имеются внешние пользователи, то можно управлять и их настройками, например, можно скопировать другим внешним пользователям настройки внешнего пользователя ООО «Альфа».

Нужную настройку пользователя можно отобрать с помощью поиска по наименованию или его части (в поле Найти).

Также можно открыть список настроек в карточке каждого пользователя с помощью ссылки Настройки панели навигации.

Список пользовательских настроек состоит из трех вкладок. Вкладка Внешний вид включает настройки внешнего вида рабочего стола, различных списков приложения.

На вкладке Настройки отчетов можно управлять настройками вариантов отчетов. Личные варианты отчетов и их настройки скопировать другим пользователям невозможно.

На вкладке Прочие настройки отражены персональные настройки, настройки раздела Избранное, настройки быстрого доступа к дополнительным отчетам и обработкам и прочие настройки.

В списке доступны возможности:

■ Скопировать другим – с помощью этой кнопки выбранные настройки указанного пользователя можно скопировать одному или нескольким пользователям приложения. Выберите нужных пользователей из списка с помощью флажков. В списке выбора с помощью кнопки Активные пользователи можно просмотреть список пользователей, которые работают в настоящий момент. О других возможностях копирования настроек см. раздел Копирование настроек;

■ Очистить – с помощью этой кнопки можно очистить выделенные настройки. Подтвердите свой выбор, нажав кнопку Да;

■ Очистить все – нажмите кнопку, далее выберите, что очистить: Все настройки или Настройки отчетов и внешнего вида указанного пользователя. Подтвердите свой выбор, нажав кнопку Очистить. Также для очистки настроек можно воспользоваться ссылкой раздела Администрирование – Настройки пользователей и прав – Персональные настройки пользователей, см. раздел Очистка настроек;

■ Скопировать от – нажмите эту кнопку, для того чтобы скопировать настройки указанному пользователю от другого пользователя приложения. Выберите пользователя, от которого скопировать настройки. Выберите настройки, которые необходимо копировать. Подробнее см. в разделе Копирование настроек.

Также в меню Еще доступны команды:

1. Скопировать другим группу настроек – работает аналогично кнопке Скопировать другим, но при этом для выбора доступны следующие группы настроек:

■ Настройки отчетов;

■ Настройки внешнего вида;

■ Настройки отчетов и внешнего вида;

■ Настройки отчетов, внешнего вида и прочие.

2. Очистить все – кроме уже перечисленных в разделе возможностей этой команды очистки настроек, доступны также следующие:

■ Выделенные настройки у пользователей – с помощью команды можно удалить одну или несколько выделенных настроек у нескольких пользователей. Перезапуск приложения при изменении прав доступа

При сокращении или ограничении прав доступа (подробнее см. документацию Управление доступом) приложение оповещает пользователя и автоматически инициирует процедуру перезапуска:

1. После изменения прав пользователь получает оповещение от приложения.

Пользователю рекомендуется сохранить все свои данные. Также предлагается выполнить перезапуск немедленно или отложить. Если пользователь не выполнил перезапуск сразу, приложение запускает автоматический перезапуск его сеанса через 15 минут.

2. Промежуточные предупреждения:

■ За 10–5 минут до перезапуска - один раз в минуту появляется предупреждающее сообщение.

■ Каждую минуту в течение последних пяти минут до перезапуска появляется диалоговое окно.

Отмена перезапуска

Если до момента автоматического перезапуска администратор снова изменит права доступа пользователя, и необходимость в перезапуске отпадет (например, права будут возвращены или расширены), приложение отменит запланированное действие. Пользователь получит уведомление.

Важно!

■ Во избежание потери данных рекомендуется сохранять работу при появлении первых уведомлений о перезапуске.

■ В текущем сеансе продолжают действовать прежние права доступа до момента перезапуска приложения.
