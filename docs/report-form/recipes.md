# Рецепты: доработка поведения отчета в общей форме БСП

БСП 3.1.11. Отчет на СКД, открывается в `ОбщаяФорма.ФормаОтчета`. Общую форму **не менять никогда**.
Почему устроено именно так и откуда взяты правила — [overview.md](overview.md).

## Правила, которые нельзя нарушать

1. Серверная логика отчета — в **модуле объекта отчета**. Клиентская — в общем модуле
   `ОтчетыКлиентПереопределяемый` (он один на все отчеты; внутри сразу проверять имя отчета).
2. Событие модуля объекта вызывается, только если:
   - отчет зарегистрирован с `ОпределитьНастройкиФормы = Истина` (рецепт 0);
   - в `ОпределитьНастройкиФормы` включен флаг `Настройки.События.<ИмяСобытия> = Истина`;
   - процедура объявлена `Экспорт` с точной сигнатурой.

   Исключения — платформенные события `ПриКомпоновкеРезультата` и `ОбработкаПроверкиЗаполнения`: без флага, без `Экспорт`.
3. Всё, что влияет на **результат**, живет в настройках компоновки (параметр СКД, отбор, структура), а не в
   реквизитах формы. Реквизиты формы в формирование не передаются.
4. Отчет формируется в **фоновом задании** на новом объекте отчета. Там нет формы и нет клиента. Код в
   `ПриКомпоновкеРезультата` не должен обращаться к форме и показывать диалоги.
5. В событиях формы (`ПриСозданииНаСервере`, `ПередЗагрузкойВариантаНаСервере` и т.п.) `ЭтотОбъект` —
   временная копия. Менять надо `Форма.Отчет.КомпоновщикНастроек` или переданные настройки, а не
   `ЭтотОбъект.КомпоновщикНастроек`.
6. Элементы внутри панели быстрых настроек пересоздаются при каждом обновлении настроек. Свой
   `ПриИзменении` у программно добавленного поля ввода сделать нельзя — обработчик может быть только в модуле формы.

## Какой рецепт выбрать

| Задача | Рецепт | Где код |
|---|---|---|
| Любая задача ниже впервые для отчета | 0 | модуль менеджера, `ВариантыОтчетовПереопределяемый`, модуль объекта |
| Флажок или поле выбора, влияющее на отчет | 1 | схема СКД (+ модуль объекта для списка) |
| Кнопка на форме отчета | 2 | модуль объекта + `ОтчетыКлиентПереопределяемый` |
| Изменить поля, группировки, отборы перед формированием | 3 | модуль объекта, `ПриКомпоновкеРезультата` |
| Запретить формирование с сообщением | 4 | модуль объекта, `ОбработкаПроверкиЗаполнения` |
| Обработать табличный документ после вывода | 5 | модуль объекта, `ПриКомпоновкеРезультата` |
| Своя расшифровка, открыть другой отчет | 6 | `ОтчетыКлиентПереопределяемый` + серверный модуль |
| Предупредить «отчет долгий, продолжить?» | 7 | модуль объекта, `ПередФормированиемОтчета` |
| Значение по умолчанию для быстрой настройки; отбор при открытии из своей команды | 8 | модуль объекта, `ПередЗагрузкойНастроекВКомпоновщик` / `ПриСозданииНаСервере` |
| Ограничить список выбора значения параметра или отбора | 1 (раздел «Список выбора») | схема СКД или модуль объекта |
| Расставить поля шапки по группам, ширине | 1 (раздел «Раскладка») | модуль объекта, `ПриОпределенииСвойствЭлементовФормыНастроек` |

В АСПУ нет функций `КомпоновкаДанныхКлиентСервер.ПолучитьПараметр`/`УстановитьПараметр`,
`КомпоновкаДанныхСервер.*` из статей про ERP/УТ — это не БСП. Использовать методы платформы
(`ПараметрыДанных.НайтиЗначениеПараметра`, `УстановитьЗначениеПараметра`) и БСП
(`ОбщегоНазначенияКлиентСервер.УстановитьЭлементОтбора`, `НайтиЭлементыИГруппыОтбора`).

## Рецепт 0. Подключить отчет к событиям формы

Нужен один раз на отчет, если используются события модуля объекта (рецепты 2, 7, списки выбора из рецепта 1).
Рецептам 3, 4, 5 он **не нужен** (платформенные события), но и не мешает.

**Шаг 1.** Общий модуль `ВариантыОтчетовПереопределяемый`, процедура `НастроитьВариантыОтчетов`:

```bsl
Процедура НастроитьВариантыОтчетов(Настройки) Экспорт
	ВариантыОтчетов.НастроитьОтчетВМодулеМенеджера(Настройки, Метаданные.Отчеты.ИмяОтчета);
КонецПроцедуры
```

**Шаг 2.** Модуль менеджера отчета:

```bsl
#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда

#Область ПрограммныйИнтерфейс

// Параметры:
//   Настройки - см. ВариантыОтчетовПереопределяемый.НастроитьВариантыОтчетов.Настройки.
//   НастройкиОтчета - см. ВариантыОтчетов.ОписаниеОтчета.
//
Процедура НастроитьВариантыОтчета(Настройки, НастройкиОтчета) Экспорт
	НастройкиОтчета.ОпределитьНастройкиФормы = Истина;
КонецПроцедуры

#КонецОбласти

#КонецЕсли
```

**Шаг 3.** Модуль объекта отчета:

```bsl
#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда

#Область ПрограммныйИнтерфейс

// Параметры:
//   Форма - ФормаКлиентскогоПриложения, Неопределено - всегда Неопределено, форму здесь не трогать.
//   КлючВарианта - Строка, Неопределено
//   Настройки - см. ОтчетыКлиентСервер.НастройкиОтчетаПоУмолчанию
//
Процедура ОпределитьНастройкиФормы(Форма, КлючВарианта, Настройки) Экспорт
	// Включать только те события, обработчики которых есть ниже.
	// Настройки.События.ПриСозданииНаСервере = Истина;
	// Настройки.События.ПослеЗагрузкиНастроекВКомпоновщик = Истина;
	// Настройки.События.ПередФормированиемОтчета = Истина;
КонецПроцедуры

#КонецОбласти

#Область ОбработчикиСобытий

// Платформенные события: ПриКомпоновкеРезультата, ОбработкаПроверкиЗаполнения.

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

#КонецОбласти

#КонецЕсли
```

**Шаг 4.** Обновить кэш вариантов отчетов: запуск с параметром `ЗапуститьОбновлениеИнформационнойБазы`,
обработка `ОбновлениеВспомогательныхДанных.epf` из дистрибутива БСП или новый номер версии конфигурации.
Без этого `ОпределитьНастройкиФормы` не вызывается.

**Проверка:** поставить точку останова в `ОпределитьНастройкиФормы` и открыть отчет. Не остановилось —
не выполнен шаг 1, 2 или 4.

Диагностика:

| Что видно | Причина |
|---|---|
| Ничего не происходит, ошибок нет | отчет не в кэше: нет шага 1/2, не обновлен кэш (шаг 4), для расширения — не перезапущен сеанс |
| Журнал регистрации: «Недопустимое значение параметра КлючВарианта в процедуре ВариантыОтчетов.НастроитьОтчетВМодулеМенеджера» | ошибка внутри `НастроитьВариантыОтчета` или у нее один параметр вместо двух |
| Исключение «…подключен к подсистеме "Варианты отчетов", но при получении настроек возникла следующая ошибка…» | регистрация есть, но `ОпределитьНастройкиФормы` нет в модуле объекта, она не `Экспорт` или падает |
| Событие не вызывается, хотя `ОпределитьНастройкиФормы` вызывается | не поднят флаг `Настройки.События.<Имя>` или у обработчика неверная сигнатура/нет `Экспорт` |

Не копировать `НастроитьВариантыОтчета` с **одним** параметром из отчетов ERP/УТ — их вызывает прикладной
модуль конфигурации, не БСП.

**Отчет в расширении:** вместо шага 1 — включить отчет в подсистему `ПодключаемыеОтчетыИОбработки` и
объявить в модуле менеджера:

```bsl
Процедура ПриОпределенииНастроек(Настройки) Экспорт
	Настройки.ОпределитьНастройкиФормы = Истина;
	Настройки.НастроитьВариантыОтчета = Истина; // если есть НастроитьВариантыОтчета
КонецПроцедуры
```

или `&После("НастроитьВариантыОтчетов")` на `ВариантыОтчетовПереопределяемый` с
`ВариантыОтчетов.ОписаниеОтчета(Настройки, Метаданные.Отчеты.ИмяОтчета).ОпределитьНастройкиФормы = Истина`.
После изменения расширения — перезайти в базу.

**Внешний отчет:** регистрация не нужна (`ОпределитьНастройкиФормы` вызывается всегда), но ошибки в ней
глушатся молча. Флаги ставить через `Настройки.События.Вставить("ИмяСобытия", Истина)`. Если изменения не
видны — платформа кэширует внешний отчет, переименовать файл.

## Рецепт 1. Флажок или поле выбора на форме отчета

Не создавать элементы формы кодом. Создать **параметр СКД** и вывести его в быстрые пользовательские
настройки — БСП нарисует элемент сама, значение сохранится в варианте и дойдет до формирования.

**Шаги в схеме СКД (конфигуратор/EDT):**

1. Вкладка «Параметры» → добавить параметр, например `ВРазрезеПризнакаУдержания`:
   - Тип: `Булево` — будет флажок;
   - для поля выбора: ссылочный тип или примитивный тип со списком «Доступные значения»;
   - Заголовок: текст рядом с флажком;
   - «Ограничение использования» — снять, «Использование» — «Всегда».
2. Параметр **не обязан** использоваться в тексте запроса.
3. Настройки варианта → «Параметры» → у параметра включить «Использование», задать значение по умолчанию,
   свойства элемента пользовательских настроек → «Включать в пользовательские настройки», режим «Быстрый
   доступ».

**Список значений из кода** (если нельзя задать в схеме). Рецепт 0 + событие:

```bsl
// ОпределитьНастройкиФормы:
Настройки.События.ПослеЗагрузкиНастроекВКомпоновщик = Истина;

// Модуль объекта, область ПрограммныйИнтерфейс:
Процедура ПослеЗагрузкиНастроекВКомпоновщик(ДополнительныеПараметры) Экспорт
	ДоступныйПараметр = КомпоновщикНастроек.Настройки.ПараметрыДанных.ДоступныеПараметры.НайтиПараметр(
		Новый ПараметрКомпоновкиДанных("РежимВывода"));
	Если ДоступныйПараметр = Неопределено Тогда
		Возврат;
	КонецЕсли;
	Список = Новый СписокЗначений;
	Список.Добавить("Кратко", НСтр("ru = 'Кратко'"));
	Список.Добавить("Подробно", НСтр("ru = 'Подробно'"));
	ДоступныйПараметр.ДоступныеЗначения = Список;
КонецПроцедуры
```

Образец: демо `Отчет.ПраваРолей`, `НастроитьПараметрУровеньДоступа`.

**Список выбора — выбрать способ по порядку:**

1. **Без кода, в схеме СКД.** У параметра (вкладка «Параметры») или поля набора (вкладка «Наборы данных») —
   колонка «Параметры редактирования»:
   - «Связи параметров выбора» — отбор формы выбора по значению другого параметра или отбора
     (`Отбор.Владелец` ← `Номенклатура`);
   - «Параметры выбора» — фиксированный отбор (`Отбор.ЭтоГруппа` = `Ложь`).

   Форма выбора остается штатной: иерархия, поиск по коду.
2. **Фиксированный список значений** — `ДоступныеЗначения` (в схеме или кодом выше). Выбор становится плоским
   списком.
3. **Список из запроса для одного отчета** — рецепт 0 + событие (устаревшее, но рабочее):

```bsl
// ОпределитьНастройкиФормы:
Настройки.События.ПриОпределенииПараметровВыбора = Истина;

// Вызывается на каждую настройку при каждом перестроении панели.
Процедура ПриОпределенииПараметровВыбора(Форма, СвойстваНастройки) Экспорт
	Если СвойстваНастройки.ПолеКД <> Новый ПолеКомпоновкиДанных("ПараметрыДанных.Стратегия") Тогда
		Возврат;
	КонецЕсли;
	СвойстваНастройки.ЗапросЗначенийВыбора.Текст = // объект Запрос: задавать Текст, не присваивать строку
		"ВЫБРАТЬ РАЗРЕШЕННЫЕ
		|	Стратегии.Ссылка
		|ИЗ
		|	Справочник.Стратегии КАК Стратегии
		|ГДЕ
		|	НЕ Стратегии.ПометкаУдаления";
КонецПроцедуры
```

`ПолеКД` для параметра — `"ПараметрыДанных.<Имя>"`, для отбора — имя поля. БСП добавит первую колонку
результата к `ЗначенияДляВыбора` и отсортирует по представлению (`УПОРЯДОЧИТЬ ПО` не действует). Флаги
`ОграничиватьВыборУказаннымиЗначениями`, `БыстрыйВыбор` в БСП 3.1.11 после обработчика не читаются.
Имя справочника в примере условное.

**Раскладка полей шапки** (группа, ширина, заголовок) — рецепт 0 + событие, вызывается до построения панели:

```bsl
// ОпределитьНастройкиФормы:
Настройки.События.ПриОпределенииСвойствЭлементовФормыНастроек = Истина;

Процедура ПриОпределенииСвойствЭлементовФормыНастроек(ТипФормы, СвойстваЭлементов, ПользовательскиеНастройки) Экспорт
	Если ТипФормы <> ТипФормыОтчета.Основная Тогда
		Возврат;
	КонецЕсли;
	
	СвойстваГруппы = ОтчетыСервер.СвойстваГруппыЭлементовФормы();
	СвойстваГруппы.Группировка = ГруппировкаПодчиненныхЭлементовФормы.ГоризонтальнаяВсегда;
	СвойстваЭлементов.Группы.Вставить("Основные", СвойстваГруппы);
	
	Для Каждого ЭлементНастройки Из ПользовательскиеНастройки Цикл
		Если ТипЗнч(ЭлементНастройки) <> Тип("ЗначениеПараметраНастроекКомпоновкиДанных")
			Или Строка(ЭлементНастройки.Параметр) <> "ПериодОтчета" Тогда
			Продолжить;
		КонецЕсли;
		СвойстваПоля = СвойстваЭлементов.Поля.Найти(
			ЭлементНастройки.ИдентификаторПользовательскойНастройки, "ИдентификаторНастройки");
		Если СвойстваПоля <> Неопределено Тогда
			СвойстваПоля.ИдентификаторГруппы = "Основные";
		КонецЕсли;
	КонецЦикла;
КонецПроцедуры
```

Образец — `УниверсальныйОтчет.ПриОпределенииСвойствЭлементовФормыНастроек`. При подписке БСП не
распределяет поля по колонкам сама. Колонки `СвойстваЭлементов.Поля`: `ИдентификаторГруппы`, `ПоложениеЗаголовка`,
`РастягиватьПоГоризонтали`, `Ширина`, `Представление`.

**Отбор-флажок по булеву полю без «Да/Нет»**: в настройках варианта заполнить колонку «Представление» у
элемента отбора — поле значения на форме не выводится (поведение платформы; по отзывам, при разработке на 8.5
не работает).

**Чтобы форма перестраивалась сразу при изменении параметра** (нужно для рецепта 3, вариант Б):

```bsl
// ОпределитьНастройкиФормы:
Настройки.ЗагрузитьНастройкиПриИзмененииПараметров.Добавить(
	Новый ПараметрКомпоновкиДанных("ВРазрезеПризнакаУдержания"));
```

**Чтение значения** — только в серверном коде отчета (рецепты 3–5):

```bsl
// Флажок: читать Значение. Использование у флажка форма не переключает.
Функция ЗначениеФлажка(Настройки, ИмяПараметра)
	Параметр = Настройки.ПараметрыДанных.НайтиЗначениеПараметра(Новый ПараметрКомпоновкиДанных(ИмяПараметра));
	Возврат Параметр <> Неопределено И Параметр.Значение = Истина;
КонецФункции

// Обычный параметр: учитывать Использование.
Функция ЗначениеПараметра(Настройки, ИмяПараметра, ПоУмолчанию = Неопределено)
	Параметр = Настройки.ПараметрыДанных.НайтиЗначениеПараметра(Новый ПараметрКомпоновкиДанных(ИмяПараметра));
	Если Параметр = Неопределено Или Не Параметр.Использование Тогда
		Возврат ПоУмолчанию;
	КонецЕсли;
	Возврат Параметр.Значение;
КонецФункции
```

`Настройки` — результат `КомпоновщикНастроек.ПолучитьНастройки()`: вариант с примененными пользовательскими
настройками.

**Если нужен элемент, который параметром не выразить** (надпись, картинка): рецепт 0 + событие
`ПослеЗаполненияПанелиБыстрыхНастроек`, создавать элемент при **каждом** вызове:

```bsl
// ОпределитьНастройкиФормы:
Настройки.События.ПослеЗаполненияПанелиБыстрыхНастроек = Истина;

Процедура ПослеЗаполненияПанелиБыстрыхНастроек(Форма, ПараметрыЗаполнения) Экспорт
	Если Форма.Элементы.Найти("ПодсказкаОтчета") <> Неопределено Тогда
		Возврат;
	КонецЕсли;
	Надпись = Форма.Элементы.Добавить("ПодсказкаОтчета", Тип("ДекорацияФормы"),
		Форма.Элементы.КомпоновщикНастроекПользовательскиеНастройки);
	Надпись.Вид = ВидДекорацииФормы.Надпись;
	Надпись.Заголовок = НСтр("ru = 'При выборе лицевого счета период должен быть один день.'");
КонецПроцедуры
```

Не делать: поле ввода с реквизитом формы, `ИзменитьРеквизиты` ради значения, влияющего на отчет.

## Рецепт 2. Кнопка на форме отчета

Рецепт 0 + событие `ПриСозданииНаСервере`. Команда выводится через `ОтчетыСервер.ВывестиКоманду` — она
регистрирует команду как постоянную и назначает общий обработчик.

```bsl
Настройки.События.ПриСозданииНаСервере = Истина;

// Модуль объекта, область ПрограммныйИнтерфейс:
Процедура ПриСозданииНаСервере(Форма, Отказ, СтандартнаяОбработка) Экспорт

	Команда.Действие = "Подключаемый_Команда";
	Команда.Заголовок = НСтр("ru = 'Открыть журнал'");
	ОтчетыСервер.ВывестиКоманду(Форма, Команда, "Настройки");
КонецПроцедуры
```

`ТипГруппы` в `ВывестиКоманду`: `"Главное"`, `"Настройки"`, `"РаботаСТабличнымДокументом"`, `"Интеграция"`,
`"ПодменюОтправить"`, `"Прочее"`. Имя команды — с префиксом отчета, чтобы не пересечься с командами формы.

Обработчик — общий модуль `ОтчетыКлиентПереопределяемый`:

```bsl

		Результат = Истина;
	КонецЕсли;
КонецПроцедуры
```

оповещения `(ФормаОтчета, Команда)`.

## Рецепт 3. Изменить настройки перед формированием

Пример: флажок `ВРазрезеПризнакаУдержания` (рецепт 1) включает или выключает поле `ПризнакУдержания` в
группировке и в колонках. Настройкой СКД это не выразить.

**Подготовка варианта в схеме:** поле `ПризнакУдержания` **уже есть** в полях группировки и в выбранных
полях нужной группировки. Группировке задано имя (свойство «Имя» элемента структуры), например
`Основная`. Код только переключает `Использование` — порядок полей не ломается.

**Вариант А (рекомендуется).** Модуль объекта, событие `ПриКомпоновкеРезультата`. Работает в форме,
рассылке, снимках. Меняет только текущий прогон, сохраненный вариант не трогает. Рецепт 0 не нужен.

```bsl
#Область ОбработчикиСобытий

Процедура ПриКомпоновкеРезультата(ДокументРезультат, ДанныеРасшифровки, СтандартнаяОбработка)
	
	СтандартнаяОбработка = Ложь;
	
	Настройки = КомпоновщикНастроек.ПолучитьНастройки(); // вариант + пользовательские, копия
	
	ВРазрезе = ЗначениеФлажка(Настройки, "ВРазрезеПризнакаУдержания");
	Группировка = НайтиЭлементСтруктуры(Настройки.Структура, "Основная");
	Если Группировка <> Неопределено Тогда
		Поле = Новый ПолеКомпоновкиДанных("ПризнакУдержания");
		УстановитьИспользованиеПоляГруппировки(Группировка, Поле, ВРазрезе);
		УстановитьИспользованиеВыбранногоПоля(Группировка.Выбор.Элементы, Поле, ВРазрезе);
	КонецЕсли;
	
	СкомпоноватьВДокумент(Настройки, ДокументРезультат, ДанныеРасшифровки);
	
КонецПроцедуры

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

Процедура СкомпоноватьВДокумент(Настройки, ДокументРезультат, ДанныеРасшифровки)
	
	КомпоновщикМакета = Новый КомпоновщикМакетаКомпоновкиДанных;
	// ЭтотОбъект.СхемаКомпоновкиДанных, а не ПолучитьМакет: схему могли изменить в форме.
	МакетКомпоновки = КомпоновщикМакета.Выполнить(СхемаКомпоновкиДанных, Настройки, ДанныеРасшифровки);
	
	ПроцессорКомпоновки = Новый ПроцессорКомпоновкиДанных;
	ПроцессорКомпоновки.Инициализировать(МакетКомпоновки, , ДанныеРасшифровки, Истина);
	
	ПроцессорВывода = Новый ПроцессорВыводаРезультатаКомпоновкиДанныхВТабличныйДокумент;
	ПроцессорВывода.УстановитьДокумент(ДокументРезультат);
	ПроцессорВывода.Вывести(ПроцессорКомпоновки);
	
	// Для рассылки «не отправлять пустой».
	КомпоновщикНастроек.ПользовательскиеНастройки.ДополнительныеСвойства.Вставить("ОтчетПустой",
		ОтчетыСервер.ОтчетПустой(ЭтотОбъект, ПроцессорКомпоновки));
	
КонецПроцедуры

// Ищет элемент структуры настроек по имени, в том числе во вложенных группировках и таблицах.
Функция НайтиЭлементСтруктуры(Коллекция, Имя)
	
	Для Каждого Элемент Из Коллекция Цикл
		Если Элемент.Имя = Имя Тогда
			Возврат Элемент;
		КонецЕсли;
		ТипЭлемента = ТипЗнч(Элемент);
		Если ТипЭлемента = Тип("ТаблицаКомпоновкиДанных") Тогда
			Найденный = НайтиЭлементСтруктуры(Элемент.Строки, Имя);
			Если Найденный = Неопределено Тогда
				Найденный = НайтиЭлементСтруктуры(Элемент.Колонки, Имя);
			КонецЕсли;
		ИначеЕсли ТипЭлемента = Тип("ДиаграммаКомпоновкиДанных") Тогда
			Найденный = НайтиЭлементСтруктуры(Элемент.Точки, Имя);
			Если Найденный = Неопределено Тогда
				Найденный = НайтиЭлементСтруктуры(Элемент.Серии, Имя);
			КонецЕсли;
		Иначе
			Найденный = НайтиЭлементСтруктуры(Элемент.Структура, Имя);
		КонецЕсли;
		Если Найденный <> Неопределено Тогда
			Возврат Найденный;
		КонецЕсли;
	КонецЦикла;
	
	Возврат Неопределено;
	
КонецФункции

Процедура УстановитьИспользованиеПоляГруппировки(Группировка, Поле, Использование)
	
	Для Каждого ПолеГруппировки Из Группировка.ПоляГруппировки.Элементы Цикл
		Если ТипЗнч(ПолеГруппировки) = Тип("ПолеГруппировкиКомпоновкиДанных")
			И ПолеГруппировки.Поле = Поле Тогда
			ПолеГруппировки.Использование = Использование;
		КонецЕсли;
	КонецЦикла;
	
КонецПроцедуры

Процедура УстановитьИспользованиеВыбранногоПоля(ЭлементыВыбора, Поле, Использование)
	
	Для Каждого ЭлементВыбора Из ЭлементыВыбора Цикл
		Если ТипЗнч(ЭлементВыбора) = Тип("ГруппаВыбранныхПолейКомпоновкиДанных") Тогда
			УстановитьИспользованиеВыбранногоПоля(ЭлементВыбора.Элементы, Поле, Использование);
		ИначеЕсли ТипЗнч(ЭлементВыбора) = Тип("ВыбранноеПолеКомпоновкиДанных")
			И ЭлементВыбора.Поле = Поле Тогда
			ЭлементВыбора.Использование = Использование;
		КонецЕсли;
	КонецЦикла;
	
КонецПроцедуры

#КонецОбласти
```

Если поле выводится и в выбранных полях корня отчета (`Настройки.Выбор`) — вызвать
`УстановитьИспользованиеВыбранногоПоля(Настройки.Выбор.Элементы, Поле, ВРазрезе)` тоже.

Добавлять поле, которого в варианте нет:
`Группировка.ПоляГруппировки.Элементы.Добавить(Тип("ПолеГруппировкиКомпоновкиДанных"))`, затем `.Поле = Поле`,
`.Использование = Истина`; для колонки — `Группировка.Выбор.Элементы.Добавить(Тип("ВыбранноеПолеКомпоновкиДанных"))`.
Новое поле встает в конец коллекции.

**Вариант Б (образец БСП — демо `Отчет.РезультатыПроверкиУчета`, `СкрытьГруппировкуПоОтветственным`).**
Рецепт 0 + событие `ПередЗагрузкойНастроекВКомпоновщик`: правит настройки при каждой загрузке — и в форме,
и в фоне. Пользователь видит изменения в структуре настроек. Минус: правка попадает в вариант.

```bsl
// ОпределитьНастройкиФормы:
Настройки.События.ПередЗагрузкойНастроекВКомпоновщик = Истина;
Настройки.ЗагрузитьНастройкиПриИзмененииПараметров.Добавить(
	Новый ПараметрКомпоновкиДанных("ВРазрезеПризнакаУдержания"));

// Контекст - форма ИЛИ структура (вызов из фона). Не обращаться к нему как к форме.
Процедура ПередЗагрузкойНастроекВКомпоновщик(Контекст, КлючСхемы, КлючВарианта, НовыеНастройкиКД,
	НовыеПользовательскиеНастройкиКД) Экспорт
	
	Если НовыеНастройкиКД = Неопределено Или НовыеПользовательскиеНастройкиКД = Неопределено Тогда
		Возврат;
	КонецЕсли;
	
	// Параметр ищем в текущих настройках, чтобы узнать его идентификатор пользовательской настройки.
	Параметр = КомпоновщикНастроек.Настройки.ПараметрыДанных.НайтиЗначениеПараметра(
		Новый ПараметрКомпоновкиДанных("ВРазрезеПризнакаУдержания"));
	Если Параметр = Неопределено Тогда
		Возврат;
	КонецЕсли;
	Настройка = НовыеПользовательскиеНастройкиКД.Элементы.Найти(Параметр.ИдентификаторПользовательскойНастройки);
	Если Настройка = Неопределено Тогда
		Возврат;
	КонецЕсли;
	
	Группировка = НайтиЭлементСтруктуры(НовыеНастройкиКД.Структура, "Основная");
	Если Группировка <> Неопределено Тогда
		Поле = Новый ПолеКомпоновкиДанных("ПризнакУдержания");
		УстановитьИспользованиеПоляГруппировки(Группировка, Поле, Настройка.Значение = Истина);
		УстановитьИспользованиеВыбранногоПоля(Группировка.Выбор.Элементы, Поле, Настройка.Значение = Истина);
	КонецЕсли;
	
КонецПроцедуры
```

Не делать: менять настройки в событиях формы через `ЭтотОбъект.КомпоновщикНастроек` (это копия).

## Рецепт 4. Запретить формирование с сообщением

Пример: если лицевой счет выводится в отчете и отбора по счету нет, период должен быть ровно один день.

Точка — платформенное событие модуля объекта `ОбработкаПроверкиЗаполнения`. Вызывается до запуска
формирования: в форме (сообщение + отказ, отчет не формируется), в рассылке и снимках (ошибка с текстом
сообщения). Рецепт 0 не нужен.

```bsl
#Область ОбработчикиСобытий

Процедура ОбработкаПроверкиЗаполнения(Отказ, ПроверяемыеРеквизиты)
	
	Настройки = КомпоновщикНастроек.ПолучитьНастройки();
	
	ПолеСчета = Новый ПолеКомпоновкиДанных("ЛицевойСчет");
	Если Не ПолеВыводится(Настройки, ПолеСчета) Тогда
		Возврат;
	КонецЕсли;
	// Указать поле, по которому реально отбирают (в отчете может быть отдельное поле отбора).
	Если ОтборПоПолюУстановлен(Настройки.Отбор.Элементы, ПолеСчета) Тогда
		Возврат;
	КонецЕсли;
	
	ПараметрПериод = Настройки.ПараметрыДанных.НайтиЗначениеПараметра(
		Новый ПараметрКомпоновкиДанных("ПериодОтчета"));
	Если ПараметрПериод = Неопределено Тогда
		Возврат;
	КонецЕсли;
	Период = ПараметрПериод.Значение; // СтандартныйПериод
	
	Если НачалоДня(Период.ДатаНачала) <> НачалоДня(Период.ДатаОкончания) Тогда
		ОбщегоНазначения.СообщитьПользователю(
			НСтр("ru = 'При выводе лицевых счетов без отбора по счету период отчета должен быть один день.'"),
			, , , Отказ);
	КонецЕсли;
	
КонецПроцедуры

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

// Истина, если поле выбрано в колонках или группировках итоговых настроек (с учетом флажков использования).
Функция ПолеВыводится(Настройки, Поле)
	
	Возврат ПолеЕстьВВыборе(Настройки.Выбор.Элементы, Поле)
		Или ПолеЕстьВСтруктуре(Настройки.Структура, Поле);
	
КонецФункции

	Для Каждого ЭлементВыбора Из ЭлементыВыбора Цикл
		Если Не ЭлементВыбора.Использование Тогда
			Продолжить;
		КонецЕсли;
		Если ТипЗнч(ЭлементВыбора) = Тип("ГруппаВыбранныхПолейКомпоновкиДанных") Тогда
			Если ПолеЕстьВВыборе(ЭлементВыбора.Элементы, Поле) Тогда
				Возврат Истина;
			КонецЕсли;
		ИначеЕсли ТипЗнч(ЭлементВыбора) = Тип("ВыбранноеПолеКомпоновкиДанных")
			И ЭлементВыбора.Поле = Поле Тогда
			Возврат Истина;
		КонецЕсли;
	КонецЦикла;
	
	Возврат Ложь;
	
КонецФункции

Функция ПолеЕстьВСтруктуре(Коллекция, Поле)
	
	Для Каждого Элемент Из Коллекция Цикл
		Если Не Элемент.Использование Тогда
			Продолжить;
		КонецЕсли;
		ТипЭлемента = ТипЗнч(Элемент);
		Если ТипЭлемента = Тип("ТаблицаКомпоновкиДанных") Тогда
			Если ПолеЕстьВВыборе(Элемент.Выбор.Элементы, Поле)
				Или ПолеЕстьВСтруктуре(Элемент.Строки, Поле)
				Или ПолеЕстьВСтруктуре(Элемент.Колонки, Поле) Тогда
				Возврат Истина;
			КонецЕсли;

			Если ПолеЕстьВСтруктуре(Элемент.Точки, Поле)
				Или ПолеЕстьВСтруктуре(Элемент.Серии, Поле) Тогда
				Возврат Истина;
			КонецЕсли;
		Иначе // Группировка отчета, таблицы или диаграммы.
			Для Каждого ПолеГруппировки Из Элемент.ПоляГруппировки.Элементы Цикл
				Если ТипЗнч(ПолеГруппировки) = Тип("ПолеГруппировкиКомпоновкиДанных")
					И ПолеГруппировки.Использование
					И ПолеГруппировки.Поле = Поле Тогда
					Возврат Истина;
				КонецЕсли;
			КонецЦикла;

	КонецЦикла;
	
	Возврат Ложь;

// Истина, если есть включенный отбор «Равно» / «В списке» по полю с заполненным значением.

Функция ОтборПоПолюУстановлен(ЭлементыОтбора, Поле)
	
	Для Каждого ЭлементОтбора Из ЭлементыОтбора Цикл
		Если Не ЭлементОтбора.Использование Тогда
			Продолжить;
		КонецЕсли;

				Или ЭлементОтбора.ВидСравнения = ВидСравненияКомпоновкиДанных.ВСписке)
			И ЗначениеЗаполнено(ЭлементОтбора.ПравоеЗначение) Тогда
			Возврат Истина;
		КонецЕсли;
	КонецЦикла;
	
	Возврат Ложь;
```

- Поле выводится «без группировки», если оно есть в корневом `Настройки.Выбор`: детальные записи с
  автовыбранными полями берут колонки оттуда. Функция считает это выводом.
- Отборы могут быть и у группировок (`Элемент.Отбор`). Если в отчете они используются — проверять и их.
- Если отбор по счету сделан параметром (`&ЛицевойСчет`), проверять параметр:
  `ЗначениеПараметра(Настройки, "ЛицевойСчет")` из рецепта 1.
- `ОбработкаПроверкиЗаполнения` — без `Экспорт`, в области `ОбработчикиСобытий`.

Альтернативы — хуже: `ПередФормированиемОтчета` только спрашивает «Продолжить?» (рецепт 7);
`ВызватьИсключение` в `ПриКомпоновкеРезультата` срабатывает уже после запуска фона и выглядит как сбой.

## Рецепт 5. Обработать табличный документ после вывода

Место — `ПриКомпоновкеРезультата` после вывода (рецепт 3, процедура `СкомпоноватьВДокумент`). Объект —
`ДокументРезультат` (`ТабличныйДокумент`). Работает везде, где формируется отчет. Рецепт 0 не нужен.

```bsl
Процедура ПриКомпоновкеРезультата(ДокументРезультат, ДанныеРасшифровки, СтандартнаяОбработка)
	
	СтандартнаяОбработка = Ложь;
	Настройки = КомпоновщикНастроек.ПолучитьНастройки();
	СкомпоноватьВДокумент(Настройки, ДокументРезультат, ДанныеРасшифровки);
	ДоработатьРезультат(ДокументРезультат);
	
КонецПроцедуры

Процедура ДоработатьРезультат(ДокументРезультат)
	
	// Оформить найденный текст.
	Область = ДокументРезультат.НайтиТекст("Итого");
	Пока Область <> Неопределено Цикл
		Область.Шрифт = Новый Шрифт(Область.Шрифт, , , Истина);
		Область = ДокументРезультат.НайтиТекст("Итого", Область);
	КонецЦикла;
	
	// Дописать строку в конец.
	НомерСтроки = ДокументРезультат.ВысотаТаблицы + 2;
	Ячейка = ДокументРезультат.Область(НомерСтроки, 1, НомерСтроки, 1);
	Ячейка.Текст = НСтр("ru = 'СЧА рассчитана по цене пая на дату строки.'");
	
	// Гиперссылка (e1cib/... и http(s)://... форма откроет сама).
	Ячейка = ДокументРезультат.Область(НомерСтроки + 1, 1, НомерСтроки + 1, 1);
	ОтчетыСервер.ВывестиГиперссылку(Ячейка, "e1cib/list/РегистрСведений.ЦеныПаев", НСтр("ru = 'Цены паев'"));
	
КонецПроцедуры
```

Правила:

- Менять значения и оформление ячеек и дописывать в конец. Не вставлять строки и колонки внутрь или выше
  таблицы результата — может разъехаться с данными расшифровки и заголовками, по которым работает контекстное
  меню формы (не проверено).
- Образцы БСП: демо `Отчет.РезультатыПроверкиУчета` (`ДоопределитьГотовыйМакет`),
  `Отчет._ДемоДинамикаИзмененийФайлов`.

**Только визуальная правка в форме** (не нужна в рассылке): `ОтчетыКлиентПереопределяемый.ПослеФормирования`.

```bsl
Процедура ПослеФормирования(ФормаОтчета, ОтчетСформирован) Экспорт
	Если Не ОтчетСформирован Или ФормаОтчета.НастройкиОтчета.ПолноеИмя <> "Отчет.ИмяОтчета" Тогда
		Возврат;
	КонецЕсли;
	ТабличныйДокумент = ФормаОтчета.ОтчетТабличныйДокумент;
	// ... правка на клиенте
КонецПроцедуры
```

## Рецепт 6. Своя расшифровка: открыть другой отчет с параметрами из ячейки

Образец БСП: `УправлениеДоступомСлужебныйКлиент.ПриОбработкеРасшифровкиОтчета` (отчет `АнализПравДоступа`
открывает `Отчет.ПраваРолей`).

**Шаг 1.** Общий модуль `ОтчетыКлиентПереопределяемый` — только вызов проектного модуля:

```bsl
Процедура ОбработкаРасшифровки(ФормаОтчета, Элемент, Расшифровка, СтандартнаяОбработка) Экспорт
	ОтчетыПроектаКлиент.ОбработкаРасшифровки(ФормаОтчета, Элемент, Расшифровка, СтандартнаяОбработка);
КонецПроцедуры
```

**Шаг 2.** Клиентский общий модуль проекта (`ОтчетыПроектаКлиент` — условное имя):

```bsl
Процедура ОбработкаРасшифровки(ФормаОтчета, Элемент, Расшифровка, СтандартнаяОбработка) Экспорт
	
	Если ФормаОтчета.НастройкиОтчета.ПолноеИмя <> "Отчет.ИсходныйОтчет" Тогда
		Возврат; // чужой отчет - стандартная обработка
	КонецЕсли;
	Если Не ЭтоАдресВременногоХранилища(ФормаОтчета.ОтчетДанныеРасшифровки) Тогда
		Возврат;
	КонецЕсли;
	
	Контекст = ОтчетыПроектаВызовСервера.КонтекстРасшифровки(ФормаОтчета.ОтчетДанныеРасшифровки,
		Расшифровка, "ПериодОтчета");
	Стратегия = Контекст.ЗначенияПолей.Получить("Стратегия");
	Если Не ЗначениеЗаполнено(Стратегия) Тогда
		Возврат; // не наша ячейка - стандартная расшифровка
	КонецЕсли;
	
	СтандартнаяОбработка = Ложь;
	
	// Ключ = имя параметра данных целевого отчета -> установится параметр.
	// Ключ = имя поля -> установится отбор «Равно» (Массив/СписокЗначений -> «В списке»).
	Отбор = Новый Структура;
	Отбор.Вставить("Стратегия", Стратегия);
	Если Контекст.ПараметрыДанных.Получить("ПериодОтчета") <> Неопределено Тогда
		Отбор.Вставить("ПериодОтчета", Контекст.ПараметрыДанных.Получить("ПериодОтчета"));
	КонецЕсли;
	
	ПараметрыФормы = Новый Структура;
	ПараметрыФормы.Вставить("Отбор", Отбор);
	ПараметрыФормы.Вставить("СформироватьПриОткрытии", Истина);
	ПараметрыФормы.Вставить("КлючВарианта", "Основной");
	ПараметрыФормы.Вставить("КлючНазначенияИспользования", "РасшифровкаИсходныйОтчет");
	
	ОткрытьФорму("Отчет.ЦелевойОтчет.Форма", ПараметрыФормы, ФормаОтчета);
	
КонецПроцедуры
```

**Шаг 3.** Серверный общий модуль с вызовом сервера (`ОтчетыПроектаВызовСервера` — условное имя):

```bsl
// Возвращаемое значение:
//   Структура:
//   * ИмяПоля - Строка - поле ячейки, по которой щелкнули.
//   * ЗначенияПолей - Соответствие из КлючИЗначение - поле ячейки и значения всех группировок выше:
//     ** Ключ - Строка - имя поля.
//     ** Значение - Произвольный
//   * ПараметрыДанных - Соответствие из КлючИЗначение - значения запрошенных параметров,
//     с которыми сформирован отчет.
//
Функция КонтекстРасшифровки(Знач АдресДанныхРасшифровки, Знач Расшифровка, Знач ИменаПараметров = "") Экспорт
	
	ДанныеРасшифровки = ПолучитьИзВременногоХранилища(АдресДанныхРасшифровки); // ДанныеРасшифровкиКомпоновкиДанных
	ЭлементРасшифровки = ДанныеРасшифровки.Элементы[Расшифровка];
	
	Результат = Новый Структура;
	Результат.Вставить("ИмяПоля", "");
	Результат.Вставить("ЗначенияПолей", Новый Соответствие);
	Результат.Вставить("ПараметрыДанных", Новый Соответствие);
	
	Если ТипЗнч(ЭлементРасшифровки) = Тип("ЭлементРасшифровкиКомпоновкиДанныхПоля") Тогда
		Для Каждого ЗначениеПоля Из ЭлементРасшифровки.ПолучитьПоля() Цикл
			Результат.ИмяПоля = ЗначениеПоля.Поле;
			Прервать;
		КонецЦикла;
	КонецЕсли;
	ЗаполнитьЗначенияПолей(Результат.ЗначенияПолей, ЭлементРасшифровки);
	
	Для Каждого ИмяПараметра Из СтрРазделить(ИменаПараметров, ",", Ложь) Цикл
		ИмяПараметра = СокрЛП(ИмяПараметра);
		Параметр = ДанныеРасшифровки.Настройки.ПараметрыДанных.НайтиЗначениеПараметра(
			Новый ПараметрКомпоновкиДанных(ИмяПараметра));
		Если Параметр <> Неопределено И Параметр.Использование Тогда
			Результат.ПараметрыДанных.Вставить(ИмяПараметра, Параметр.Значение);
		КонецЕсли;
	КонецЦикла;
	
	Возврат Результат;
	
КонецФункции

// Ближайшее к ячейке значение поля побеждает: сначала сама ячейка, потом группировки выше.
Процедура ЗаполнитьЗначенияПолей(ЗначенияПолей, ЭлементРасшифровки)
	
	Если ТипЗнч(ЭлементРасшифровки) = Тип("ЭлементРасшифровкиКомпоновкиДанныхПоля") Тогда
		Для Каждого ЗначениеПоля Из ЭлементРасшифровки.ПолучитьПоля() Цикл
			Если ЗначенияПолей[ЗначениеПоля.Поле] = Неопределено Тогда
				ЗначенияПолей.Вставить(ЗначениеПоля.Поле, ЗначениеПоля.Значение);
			КонецЕсли;
		КонецЦикла;
	КонецЕсли;
	
	Для Каждого Родитель Из ЭлементРасшифровки.ПолучитьРодителей() Цикл
		ЗаполнитьЗначенияПолей(ЗначенияПолей, Родитель);
	КонецЦикла;
	
КонецПроцедуры
```

Как целевой отчет применит `Отбор` (`ОтчетыСервер.УстановитьФиксированныеОтборы`):

| Ключ структуры | Значение | Что будет |
|---|---|---|
| имя параметра данных | любое | параметр установлен, `Использование = Истина`, недоступен пользователю |
| имя поля | одно значение | отбор «Равно», недоступен пользователю |
| имя поля | `Массив` / `СписокЗначений` | отбор «В списке» |
| имя поля | `Структура("ВидСравнения, ПравоеЗначение")` | отбор с указанным видом сравнения |

Ключ — только поле верхнего уровня, без точки. Отбор применяется к варианту из `КлючВарианта`.

**Несколько вариантов перехода** — меню, как в образце БСП:

```bsl
Действия = Новый СписокЗначений;
Действия.Добавить("Выписка", НСтр("ru = 'Выписка по счету'"));
Действия.Добавить("Движения", НСтр("ru = 'Движение паев'"));
Оповещение = Новый ОписаниеОповещения("ПослеВыбораДействияРасшифровки", ЭтотОбъект,
	Новый Структура("ФормаОтчета, Контекст", ФормаОтчета, Контекст));
ФормаОтчета.ПоказатьВыборИзМеню(Оповещение, Действия, Элемент);
```

**Про «вывести в то же окно».**

- Стандартная расшифровка БСП тоже открывает **новую форму** того же отчета, с параметром `Расшифровка`.
- Открыть другой отчет внутри текущей формы нельзя: форма привязана к объекту своего отчета.
- Можно попробовать открыть в том же окне приложения — передать окно формы:
  `ОткрытьФорму("Отчет.ЦелевойОтчет.Форма", ПараметрыФормы, ФормаОтчета, , ФормаОтчета.Окно)` (не проверено).
- Тот же отчет с другими настройками в той же форме: изменить `ФормаОтчета.Отчет.КомпоновщикНастроек` на
  клиенте и вызвать `ОтчетыКлиент.СформироватьОтчет(ФормаОтчета)`.
- Не подменять `ФормаОтчета.ОтчетТабличныйДокумент` результатом чужого отчета.

### Вариант 6Б. Другая схема СКД в стандартной форме расшифровки

Когда нужен вид «как обычная расшифровка» (штатная форма «(Расшифровка)»), но с другим набором данных, а
заводить второй отчет в метаданных не хочется. Источник — статья Инфостарта 2656467 (УТ 11.5); механика
подтверждена кодом БСП 3.1.11, перенос настроек в новую схему не проверен.

1. Отчету, который открывается, нужен рецепт 0 и `Настройки.События.ПередЗагрузкойНастроекВКомпоновщик = Истина`.
2. Клиент, вместо `ОткрытьФорму` из шага 2 выше:

```bsl
НастройкиРасшифровки = Новый НастройкиКомпоновкиДанных;
НастройкиРасшифровки.ДополнительныеСвойства.Вставить("РасшифровкаВСхему", "Договоры"); // что открыть
НастройкиРасшифровки.ДополнительныеСвойства.Вставить("ЗначенияРасшифровки", ЗначенияДляПередачи); // Структура
ПараметрыФормы = Новый Структура;
ПараметрыФормы.Вставить("Расшифровка", Новый ОписаниеОбработкиРасшифровкиКомпоновкиДанных(
	ФормаОтчета.ОтчетДанныеРасшифровки, Расшифровка, НастройкиРасшифровки));
ПараметрыФормы.Вставить("СформироватьПриОткрытии", Истина);
ОткрытьФорму(ФормаОтчета.НастройкиОтчета.ПолноеИмя + ".Форма", ПараметрыФормы, ФормаОтчета);
```

3. Модуль объекта:

```bsl
Процедура ПередЗагрузкойНастроекВКомпоновщик(Контекст, КлючСхемы, КлючВарианта, НовыеНастройкиКД,
	НовыеПользовательскиеНастройкиКД) Экспорт
	
	// Только в форме: в фон уже придет подмененная схема (ПодключитьСхему помечает ее модифицированной).
	Если ТипЗнч(Контекст) <> Тип("ФормаКлиентскогоПриложения") Тогда
		Возврат;
	КонецЕсли;
	Расшифровка = ОбщегоНазначенияКлиентСервер.СвойствоСтруктуры(Контекст.Параметры, "Расшифровка");
	Если ТипЗнч(Расшифровка) <> Тип("ОписаниеОбработкиРасшифровкиКомпоновкиДанных") Тогда
		Возврат;
	КонецЕсли;
	ДопСвойства = Расшифровка.ПрименяемыеНастройки.ДополнительныеСвойства;
	ИмяМакета = ОбщегоНазначенияКлиентСервер.СвойствоСтруктуры(ДопСвойства, "РасшифровкаВСхему");
	Если Не ЗначениеЗаполнено(ИмяМакета) Или КлючСхемы = ИмяМакета Тогда
		Возврат;
	КонецЕсли;
	
	КлючСхемы = ИмяМакета;
	Схема = ПолучитьМакет(ИмяМакета);
	ОтчетыСервер.ПодключитьСхему(ЭтотОбъект, Контекст, Схема, КлючСхемы);
	
	// Не проверено: настройки старого варианта новой схеме не подходят - берем настройки новой схемы
	// и переносим значения параметров по имени.
	НовыеНастройкиКД = Схема.НастройкиПоУмолчанию;
	Значения = ОбщегоНазначенияКлиентСервер.СвойствоСтруктуры(ДопСвойства, "ЗначенияРасшифровки", Новый Структура);
	Для Каждого КлючИЗначение Из Значения Цикл
		НовыеНастройкиКД.ПараметрыДанных.УстановитьЗначениеПараметра(КлючИЗначение.Ключ, КлючИЗначение.Значение);
	КонецЦикла;
	
КонецПроцедуры
```

Проверить запуском: какие настройки получает новая схема, работает ли повторная расшифровка из нее.
Не глушить ошибки пустым `Попытка ... Исключение КонецПопытки`, как в исходной статье.

Дополнительная расшифровка (меню ячейки) — `ОтчетыКлиентПереопределяемый.ОбработкаДополнительнойРасшифровки`,
та же сигнатура. Щелчок по гиперссылке и двойной щелчок по обычной ячейке —
`ОбработкаВыбораТабличногоДокумента(ФормаОтчета, Элемент, Область, СтандартнаяОбработка)`.

## Рецепт 8. Значение по умолчанию для быстрой настройки и отбор при открытии

**Правило двойника.** Если параметр или отбор выведен в пользовательские настройки, его значение берется из
пользовательских настроек. Правка только в `Настройки` будет перекрыта. Менять надо элемент
`ПользовательскиеНастройки`, найденный по `ИдентификаторПользовательскойНастройки`.

**Значение по умолчанию** (например, заполнить пустой список при первом открытии). Рецепт 0 + событие:

```bsl
// ОпределитьНастройкиФормы:
Настройки.События.ПередЗагрузкойНастроекВКомпоновщик = Истина;

Процедура ПередЗагрузкойНастроекВКомпоновщик(Контекст, КлючСхемы, КлючВарианта, НовыеНастройкиКД,
	НовыеПользовательскиеНастройкиКД) Экспорт
	
	Если НовыеНастройкиКД = Неопределено Или НовыеПользовательскиеНастройкиКД = Неопределено Тогда
		Возврат;
	КонецЕсли;
	
	Параметр = НовыеНастройкиКД.ПараметрыДанных.НайтиЗначениеПараметра(
		Новый ПараметрКомпоновкиДанных("Стратегии"));
	Если Параметр = Неопределено Тогда
		Возврат;
	КонецЕсли;
	Двойник = НовыеПользовательскиеНастройкиКД.Элементы.Найти(Параметр.ИдентификаторПользовательскойНастройки);
	Если Двойник = Неопределено Тогда
		// В пользовательские настройки не выведен - достаточно правки варианта.
		Параметр.Значение = СтратегииПоУмолчанию();
		Параметр.Использование = Истина;
		Возврат;
	КонецЕсли;
	
	// Не затирать выбор пользователя - заполнять только пустое.
	Если Не ЗначениеЗаполнено(Двойник.Значение)
		Или ТипЗнч(Двойник.Значение) = Тип("СписокЗначений") И Двойник.Значение.Количество() = 0 Тогда
		Двойник.Значение = СтратегииПоУмолчанию();
		Двойник.Использование = Истина;
	КонецЕсли;
	
КонецПроцедуры
```

- В форме событие вызывается при загрузке **новых** настроек (открытие, смена варианта, «По умолчанию»); в
  фоне — при каждом формировании. Если значение должно подставляться «только при открытии», проверять
  `ТипЗнч(Контекст) = Тип("ФормаКлиентскогоПриложения")`.
- Для отбора — то же с `НовыеНастройкиКД.Отбор.Элементы` и `Двойник.ПравоеЗначение`.
- Не делать через `ЭтотОбъект.КомпоновщикНастроек` в `ПередЗаполнениемПанелиБыстрыхНастроек` (так в старых
  статьях): в событиях формы `ЭтотОбъект` — копия.

**Отбор при открытии отчета из своей команды или формы** — без кода в отчете:

```bsl
Отбор = Новый Структура;
Отбор.Вставить("Стратегия", Стратегия); // имя параметра данных или поля отбора
Отбор.Вставить("ЛицевойСчет", Новый Структура("ВидСравнения, ПравоеЗначение",
	ВидСравненияКомпоновкиДанных.ВСписке, СписокСчетов));
ПараметрыФормы = Новый Структура("Отбор, СформироватьПриОткрытии, КлючВарианта", Отбор, Истина, "Основной");
ОткрытьФорму("Отчет.ИмяОтчета.Форма", ПараметрыФормы, ЭтотОбъект);
```

Отборы из параметра `Отбор` ставятся недоступными для изменения. Нужен отбор «по умолчанию», который
пользователь может поменять, — передать значение своим параметром формы и поставить через двойник:
в `ПриСозданииНаСервере` положить его в `Форма.Отчет.КомпоновщикНастроек.ПользовательскиеНастройки.ДополнительныеСвойства`,
в `ПередЗагрузкойНастроекВКомпоновщик` прочитать (не проверено). Если отбор зависит от команды —
дописать `Форма.ФормаПараметры.Отбор` в `ПриСозданииНаСервере` отчета по `Форма.Параметры`.

## Шпаргалка: где что доступно

| Нужно | В событиях формы (сервер) | В фоне (`ПриКомпоновкеРезультата`, `ОбработкаПроверкиЗаполнения` в рассылке) | На клиенте (`ОтчетыКлиентПереопределяемый`) |
|---|---|---|---|
| Итоговые настройки | `Форма.Отчет.КомпоновщикНастроек.ПолучитьНастройки()` | `КомпоновщикНастроек.ПолучитьНастройки()` | `ФормаОтчета.Отчет.КомпоновщикНастроек` |
| Имя отчета | `Форма.НастройкиОтчета.ПолноеИмя` | `Метаданные().ПолноеИмя()` | `ФормаОтчета.НастройкиОтчета.ПолноеИмя` |
| Ключ варианта | `Форма.КлючТекущегоВарианта` | `КомпоновщикНастроек.ПользовательскиеНастройки.ДополнительныеСвойства.КлючВарианта` | `ФормаОтчета.КлючТекущегоВарианта` |
| Табличный документ | — | `ДокументРезультат` | `ФормаОтчета.ОтчетТабличныйДокумент` |
| Данные расшифровки | — | `ДанныеРасшифровки` | адрес `ФормаОтчета.ОтчетДанныеРасшифровки` |
| Параметры открытия | `Форма.Параметры` | — | — |
| Сформировать заново | — | — | `ОтчетыКлиент.СформироватьОтчет(ФормаОтчета)` |

## Частые ошибки

| Симптом | Причина | Исправление |
|---|---|---|
| Событие модуля объекта не вызывается | нет регистрации, флага в `ОпределитьНастройкиФормы` или не обновлен кэш | рецепт 0, шаги 1–4 |
| `ОпределитьНастройкиФормы` упала на `Форма.Элементы` | `Форма` там всегда `Неопределено` | работать с формой в `ПриСозданииНаСервере` |
| Изменил `КомпоновщикНастроек` в `ПриСозданииНаСервере` — не сработало | `ЭтотОбъект` в событиях формы — копия | менять `Форма.Отчет.КомпоновщикНастроек` |
| Свой элемент исчезает после смены варианта | панель быстрых настроек пересоздается | параметр СКД (рецепт 1) или создание в `ПослеЗаполненияПанелиБыстрыхНастроек` |
| Значение с формы не влияет на отчет | реквизит формы не передается в фон | параметр СКД (рецепт 1) |
| В рассылке правка результата не видна | правка сделана на клиенте в `ПослеФормирования` | перенести в `ПриКомпоновкеРезультата` |
| После своей компоновки не работает расшифровка | не передан `ДанныеРасшифровки` | передавать в `Выполнить` и `Инициализировать` |
| Изменения схемы пользователем игнорируются | использован `ПолучитьМакет(...)` | использовать `СхемаКомпоновкиДанных` объекта |
| Расшифровка перехватывается у всех отчетов | нет проверки `ПолноеИмя` | первой строкой проверять имя отчета |
| Проверка «наш отчет» в общем модуле всегда ложна | сравнение `ТипЗнч(Форма.Отчет)` — в форме это `ДанныеФормыСтруктура` | сравнивать `Форма.НастройкиОтчета.ПолноеИмя` |
| Программное значение параметра не применяется | параметр выведен в пользовательские настройки, правка перекрыта двойником | рецепт 8 |
| `ПередЗагрузкойНастроекВКомпоновщик` не вызывается при изменении значения в шапке | в форме событие идет только при загрузке новых настроек | `ЗагрузитьНастройкиПриИзмененииПараметров` (рецепт 1) или логика в `ПриКомпоновкеРезультата` |
| Кнопка есть, нажатие ничего не делает | кнопка добавлена вручную, а не `ОтчетыСервер.ВывестиКоманду` | рецепт 2 |
| В отчете из расширения событий нет, во внешнем — есть | не включен в `ПодключаемыеОтчетыИОбработки` / не перезапущен сеанс | рецепт 0, раздел «Отчет в расширении» |
| Вызов `КомпоновкаДанныхКлиентСервер.УстановитьПараметр` падает | это функция ERP/УТ, в БСП ее нет | методы платформы и `ОбщегоНазначенияКлиентСервер` |
| Отчет пустой при очищенном периоде | `КОНЕЦПЕРИОДА` от пустой даты окончания в запросе или выражении параметра | не оборачивать `ДатаОкончания`; пустой конец обрабатывать явно |
