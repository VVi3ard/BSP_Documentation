5.47 Получение файлов из интернета

При работе с приложением для выполнения определенных операций (таких, как загрузка курсов валют, загрузка классификаторов, синхронизация данных через FTP-ресурс, обновление версии приложения через Интернет и т. п.) может потребоваться доступ к сети Интернет.

В случае если доступ в Интернет осуществляется через прокси-сервер (эту информацию можно уточнить у системного администратора или у поставщика услуг доступа к сети Интернет), в приложении необходимо указать параметры прокси-сервера. Эти параметры централизованно распространяются на все функции приложения, которые получают файлы из Интернета по протоколам HTTP(S) и FTP(S), в то же время, для других протоколов (например, для работы в приложении с электронной почтой) задавать параметры прокси-сервера не требуется.

В корпоративных средах при указании настроек прокси-сервера можно использовать аутентификацию операционной системы.

В файловом варианте работы приложения параметры прокси-сервера, как правило, указываются для каждого рабочего места по отдельности (см. раздел Персональные настройки), поскольку настройки доступа к сети Интернет могут различаться для разных рабочих мест.

Если в организации используется клиент-серверная версия 1С:Предприятия, то в этом случае необходимо также указать параметры прокси-сервера на сервере 1С:Предприятия (см. раздел Настройка параметров прокси-сервера). При этом параметры прокси-сервера для рабочего места и сервера 1С:Предприятия могут различаться.

Настройка параметров прокси-сервера

Настройка параметров прокси‑сервера на сервере 1С:Предприятия осуществляется администратором приложения с помощью ссылки Параметры доступа в интернет раздела Администрирование – Общие настройки – Параметры серверного приложения на сервере 1С:Предприятия.

Для выбора варианта использования прокси-сервера установите переключатель в одно из следующих положений:

■ Не использовать прокси-сервер – если доступ в Интернет настроен напрямую, без использования прокси-сервера;

■ Использовать системные настройки прокси-сервера – если приложение должно использовать общие настройки прокси-сервера, заданные в операционной системе (с помощью кнопки Дополнительно в этом случае можно просмотреть дополнительные параметры прокси-сервера);

■ Использовать другие настройки прокси-сервера – если приложение должно использовать специальные настройки прокси-сервера, отличные от настроек операционной системы (в этом случае с помощью кнопки Дополнительно можно настроить дополнительные параметры прокси-сервера).

Вручную можно указать такие параметры прокси-сервера как: Адрес сервера и Порт прокси-сервера.

С помощью кнопки  выберите способ Аутентификации:

■ Базовая – в этом случае для каждого рабочего места и сервера необходимо указать Пользователя прокси-сервера и его Пароль (в общем случае могут быть различными, зависит от политики сетевой безопасности в организации);

■ Операционная система – в этом случае для работы с прокси-сервером будет использована учетная запись пользователя операционной системы.

Укажите имя Пользователя и Пароль.

Включение флажка Не использовать прокси для локальных адресов позволит снизить нагрузку на прокси-сервер при обращении к ресурсам локальной сети организации.

С помощью кнопки Дополнительно можно провести более «тонкую» настройку параметров прокси-сервера:

■ Адреса прокси-серверов для отдельных протоколов;

■ Адреса страниц веб-ресурсов, к которым должен использоваться прямой доступ.

По умолчанию включен флажок Один прокси-сервер для всех протоколов.

Для того чтобы указать адреса Прокси-серверов для отдельных протоколов, выключите флажок, в одном из полей – HTTP, HTTPS, FTP откорректируйте имя прокси-сервера, который будет использоваться для каждого протокола, при необходимости укажите Порт.

В списке Не использовать прокси-сервер для адресов с помощью кнопки Добавить укажите адреса, к которым будет осуществляться прямой доступ.

Для подтверждения введенных параметров нажмите кнопку ОК.

По окончании настройки параметров прокси-сервера нажмите кнопку ОК.

Настройки параметров прокси-сервера могут быть недоступны, если для приложения включено использование профилей безопасности. При включенных профилях безопасности настройка параметров доступа в Интернет на сервере 1С:Предприятия может быть выполнена только путем редактирования служебного файла inetcfg.xml (подробнее см. в руководстве администратора платформы 1С:Предприятие). Приложение выводит об этом сообщение.

Персональные настройки

В файловом варианте работы параметры прокси-сервера, как правило, указываются для каждого рабочего места по отдельности, поскольку настройки доступа к сети Интернет могут различаться для разных рабочих мест.

Если в организации используется клиент-серверная версия 1С:Предприятия, то персональная настройка параметров прокси-сервера на рабочих местах также может быть необходима для корректной работы некоторых функций приложения, обращающихся к ресурсам сети Интернет на клиенте. Например, для поиска и получения обновлений версии приложения через Интернет.

Для того чтобы указать параметры прокси‑сервера для доступа приложения в Интернет на вашем рабочем месте, воспользуйтесь командой Демо: Мои настройки раздела Главное. Перейдите по ссылке Настроить доступ к Интернету, затем выполните необходимые настройки, как это описано выше в разделе Настройка параметров прокси‑сервера.

Для веб-клиента настройка прокси-сервера производится в настройках браузера. При попытке настройки приложение выводит об этом сообщение.

При необходимости персональные настройки прокси-сервера можно скопировать нескольким или всем пользователям приложения. Для этого можно перейти по ссылке Копирование настроек раздела Администрирование – Настройки пользователей и прав – Персональные настройки пользователей. Подробнее см. в разделе документации Пользователи.

Базовые права
