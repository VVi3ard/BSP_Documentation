5.38 Обсуждения

Пользователи приложения могут общаться друг с другом посредством текстовых сообщений или видео-звонков, создавать тематические обсуждения и вести переписку по конкретным документам, например, заказам, реализациям или контрагентам. Подробнее см. книгу 1С:Предприятие 8.3. Руководство администратора.

Для участия в обсуждениях необходимо подключиться к серверу 1С:Диалог. В приложении предусмотрена возможность быстрого подключения к серверу.

Необходимо также иметь подключение к сети Интернет, возможно, потребуется ввести данные прокси-сервера, подробнее см. раздел документации Получение файлов из Интернета.

Для подключения обсуждений необходима роль Полные права.

Для участия в обсуждениях не требуется особых прав.

Настройка приложения

При вводе нового пользователя выводится предложение подключить обсуждения. Нажмите Да, для того чтобы перейти к подключению.

Подключить обсуждения можно и в разделе Администрирование – Интернет-поддержка и сервисы – Обсуждения.

Нажмите кнопку Подключить.

По умолчанию подключение производится к серверу 1С:Диалог (рекомендуется).

Для подключения укажите адрес электронной почты, на которую будет выслан цифровой код. Впоследствии приложение будет связано с этим электронным адресом, при этом необходимые данные приложения будут автоматически указаны на сервере 1С:Диалог. В личном кабинете на сервере администратор может увидеть имена приложений, которые подключил. Нажмите кнопку Зарегистрироваться. После этого выводится сообщение Код регистрации выслан на адрес (указанный ранее адрес электронной почты). Нажмите кнопку ОК. Письмо с кодом регистрации необходимо найти в ящике электронной почты по адресу, который был указан.

Код, полученный на указанный адрес электронной почты (например, 121146), напишите в окне Подключение обсуждений. Нажмите кнопку Зарегистрироваться.

После этого производится подключение обсуждений. Нажмите кнопку Готово, для того чтобы продолжить работу в приложении.

Если Интернета нет, но необходимо наладить процесс взаимодействия, в приложении предусмотрена возможность использовать для организации обсуждений свой локальный сервер. Для этого нужно произвести дополнительные настройки, открыть их с помощью кнопки  и указать адрес локального сервера.

После настройки обсуждения стали доступны в центре оповещения (в «колокольчике»). Теперь пользователи приложения могут общаться между собой.

Если обсуждения не нужны, их можно Отключить с помощью кнопки в разделе Администрирование – Интернет-поддержка и сервисы – Обсуждения.

Особенности работы с обсуждениями в приложении в Интернете

Если в приложении в Интернете база данных разделена на области данных (приложения), то для подключения обсуждений можно указывать один и тот же адрес электронной почты (e-mail) для всех областей данных. Если указывается один и тот же e-mail, приложение создается для того же самого владельца. То есть область данных будет соответствовать приложению обсуждений для одного и того же владельца абонента, идентифицируемого по e-mail.

Подробнее см. документацию.

Использование для обсуждения других приложений

Если подключены обсуждения, можно использовать для обсуждения другие приложения, это расширяет возможности взаимодействий.

Для организации обсуждений с помощью внешних приложений перейдите по ссылке Сообщения из других приложений. С помощью кнопки Создать выберите и настройте нужный чат.

Чат Telegram

Перейдите в Telegram, следуя указаниям приложения, создайте бот, выберите ему имя и произведите необходимые настройки в Telegram, после успешного создания бота укажите Наименование бота и Токен. С помощью кнопки Подобрать выберите из списка пользователей, которые будут получать и отправлять сообщения в Telegram. Нажмите кнопку Активировать.

Чат ВКонтакте

Перейдите в социальную сеть ВКонтакте, следуя указаниям приложения, создайте сообщество (группу), выберите ему имя и произведите необходимые настройки во ВКонтакте, после успешного создания чата заполните поля Наименование, Ключ и Ключ Группы.

■ С помощью кнопки Подобрать выберите из списка пользователей, которые будут получать и отправлять сообщения в приложении.

■ Нажмите кнопку Активировать.

Чат WhatsApp

Необходимо предварительно заключить договор с провайдером WhatsApp Business API — компанией «Девино Телеком». После заключения договора получите у менеджера «Девино Телеком» Ключ (token) и Имя канала.  После настройки интеграции необходимо передать навигационную ссылку точки подключения менеджеру в «Девино Телеком».

Далее следуя указаниям приложения, заполните поля Наименование, Ключ (token), Имя канала.  Точка подключения - заполняется автоматически.

■ С помощью кнопки Подобрать выберите из списка пользователей, которые будут получать и отправлять сообщения от лица аккаунта WhatsApp.

■ Нажмите кнопку Активировать.

Чат на сайте

Чат можно интегрировать с корпоративным сайтом или интернет-магазином, что обеспечит непрерывность коммуникации и автоматизирует общение с посетителями даже в нерабочее время благодаря использованию бота.

■ На вкладке Основное заполните поле Наименование. Поле Точка подключения будет автоматически заполнено после успешной активации.

■ С помощью кнопки Подобрать выберите из списка пользователей, которые будут получать и отправлять сообщения.

■ Настройте (при необходимости) на соответствующей вкладке Параметры отображения. Вы можете выбрать внешний вид мессенджера, включая цветовую схему, расположение окна чата системы взаимодействия на веб-сайте, а также настроить доступность видеозвонков.

■ Нажмите кнопку Активировать.

■ Обратитесь к техническому специалисту, ответственному за сопровождение сайта, сообщите ему Точку подключения.

Интеграция с Webhook

Webhook - это механизм, который позволяет различным сервисам и приложениям обмениваться данными в режиме реального времени. Интеграция с Webhook обеспечивает одностороннюю коммуникацию от внешнего приложения в Систему взаимодействия.

С помощью интеграции с Webhook можно создать новые сценарии взаимодействия, например, информировать пользователей о новых заказах через сайт интернет-магазина или уведомлять юристов компании об изменениях в законодательстве через сервис уведомлений от государственных органов.

■ Заполните Наименование бота в 1С.

■ С помощью кнопки Подобрать выберите из списка пользователей, которые будут получать сообщения.

■ Нажмите Активировать. Поле Точка подключения будет автоматически заполнено после успешной активации.

■ Обратитесь к техническому специалисту, ответственному за сопровождение сайта, сообщите ему Точку подключения.

Если все было корректно настроено, должны приходить сообщения из приложений.
