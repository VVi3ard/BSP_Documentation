5.12 Выгрузка объектов в файлы

Справочники и документы в приложении можно выгрузить в виде файла в различных форматах: DBF, XML, JSON, HTML, TXT (в кодировках ANSI и UTF-8), XLS, XLSX, MXL. Структуру и содержимое файлов можно настраивать с помощью конструктора печатных форм.

Настройка приложения

Создать макеты можно в списке Макеты файлов выгрузки, к которому можно перейти с помощью ссылки в разделе Администрирование – Печатные формы, отчеты и обработки.

Список макетов файлов выгрузки доступен в двух режимах: По подсистемам (по разделам интерфейса) и По объектам (видам объектов).

В списке Макеты файлов выгрузки можно с помощью кнопки панели навигации Создать новый макет выгрузки. По умолчанию наименование макета Новая форма выгрузки, которое можно изменить на произвольное. Также можно создать новый макет с помощью копирования.

После ввода наименования макета выгрузки необходимо нажать ОК, для того чтобы открыть макет в конструкторе и начать работу.

Новый макет выгрузки автоматически сохраняется в списке макетов, но по умолчанию не отображается в списке подменю Выгрузить и в списке макетов выделяется серым цветом.

Для того чтобы показывать форму в подменю Выгрузить, нажмите флажок в колонке Показывать в подменю Выгрузить файл. После этого макет выгрузки будет доступен в подменю Выгрузить в файл.

Доступно создание произвольного количества макетов выгрузки одного формата (DBF, XML, JSON, HTML, TXT, XLS, XLSX, MXL). В списке для каждого макета выводится формат сохранения.

С помощью кнопки Показать в списке можно перейти в список объектов, для которого настраивается выбранная печатная форма.

Создание макета выгрузки

После ввода наименования макета выгрузки необходимо нажать ОК, для того чтобы открыть макет в конструкторе и начать работу. Работа с макетом выгрузки осуществляется в конструкторе макетов (подробнее о возможностях конструктора см. раздел Создание макета табличного документа).

В макете выгрузки необходимо указать формат сохранения выгрузки.

На панели навигации доступны стандартные кнопки редактирования и форматирования. В зависимости от формата сохранения выгрузки могут быть ограничены определенные кнопки:

● в макетах форматов XML, JSON, DBF недоступны кнопки настройки форматированием текста;

● в макетах форматов XML, JSON доступны команды Назначить имя/Убрать имя для управления областями строк.

Ограничения при настройке макетов

Некоторые форматы имеют свои структурные ограничения, которые необходимо учитывать при настройке макетов для корректного формирования файлов.

DBF

Структура макета должна представлять собой таблицу: заголовок и его значение.

Иные ограничения формата:

● Наименование колонок должно содержать только латинские буквы.

● Длина наименования колонки не более 10 символов.

● Объединение колонок запрещено.

XML и JSON

Структура макета должна состоять из двух столбцов: наименование поля и его значение.

Поля могут быть объединены в один элемент - тогда они должны входить в одну область строки. Например, если нужно задать определённое имя тега для данных табличной части Товары, тогда необходимо объединить их в одну область. В макетах формата XML также возможна настройка подчиненных тегов: для этого необходимо задать наименование области строки через разделитель "_": например, "Товары_товар". Пересечение областей строк недопустимо.

Для форматов JSON и XML при записи макета производится проверка написания имен элементов согласно спецификации форматов (использование тех или иных символов).

Особенности вывода чисел и дат

Если при выводе числовых полей или дат в макете XML требуется представление, отличное от стандартного для XML, то можно задать формат полей, чтобы их значения были выгружены как строки.

При выводе числовых полей в макет JSON можно задать формат, чтобы значение числового поля выгружалось как строка.

Сравнительная таблица вывода дат в зависимости от формата сохранения файла и параметров.

Иные форматы

В макетах формата DBF, HTML, TXT, XLS, MXL запрещено использование областей строк/столбцов/ячеек (проверяется при записи макета).

Использование изображений и форматированного текста поддерживается в форматах XLS, XLSX, HTML, MXL.

Выгрузка файлов

Для выгрузки файлов по настроенным макетам не требуется наличия каких-либо специальных прав - выгрузка доступна, если есть права на просмотр документа или справочника.

В списке справочников или документов (элементе списка) доступно подменю Выгрузить в файл, которое содержит настроенные макеты файлов выгрузки. Возможна выгрузка файлов по макету на основании нескольких объектов. Из подменю выгрузки доступен переход в общий список макетов файлов выгрузки.

Доступна выгрузка полученного файла на компьютер или прикрепление к объекту в системе.

Также макеты файлов выгрузки можно прикрепить к шаблону электронного сообщения или к электронному письму, сформированному без использования шаблона (подробнее см. раздел документации Шаблоны сообщений).

Роль

Краткое описание

Изменение макетов файлов выгрузки

Дает право добавлять и редактировать макеты файлов выгрузки. Используется совместно с ролью Изменение макетов печатных форм.
