5.9 Взаимодействия

Бизнес-процессы помимо обычного делопроизводства в настоящее время включают и общение партнеров между собой, т. е. их взаимодействие: между партнерами проходят различные встречи, переговоры, электронная переписка. В процессе общения принимаются важные решения, заключаются различные договоры, составляются другие документы, поэтому необходимо это взаимодействие также зафиксировать.

Приложение позволяет планировать, регистрировать, упорядочивать и работать с результатами взаимодействия – общения пользователей с кем-либо по поводу предмета взаимодействия. Например, один сотрудник может взаимодействовать с другим сотрудником (контактом) по поводу заказа клиента (предмета).

Для отражения будущих взаимодействий в приложении используется документ Запланированное взаимодействие.

Для отражения фактически состоявшихся контактов служат документы Встреча, Телефонный звонок, Сообщение SMS, Электронное письмо входящее и Электронное письмо исходящее.

В качестве контактов взаимодействий в приложении могут выступать:

■ Пользователи;

■ Демо: Партнеры;

■ Демо: Контактные лица партнеров;

■ Демо: Контрагенты.

Предметами взаимодействий в приложении могут являться как сами взаимодействия, так и другие документы приложения:

■ Демо: Заказ покупателя;

■ Встреча;

■ Телефонный звонок;

■ Электронное письмо входящее;

■ Электронное письмо исходящее;

■ Запланированное взаимодействие;

■ Сообщение SMS.

Приложение позволяет выстраивать различные взаимодействия в цепочку. Цепочка взаимодействий – это, например, одна законченная переписка (письмо и ответы на него).

Также приложение связывает между собой взаимодействия, возникшие на основании одного и того же предмета. В этом случае предметом может быть связано несколько цепочек взаимодействий. В случае с перепиской данные цепочки взаимодействий существуют только в рамках одной почты.

Если предмета нет, то взаимодействия связываются вокруг первого взаимодействия. В этом случае в цепочке взаимодействий в качестве предмета у всех взаимодействий указывается одно, как правило, первое по времени взаимодействие. При этом в любой момент времени в любом взаимодействии из цепочки можно указать другой предмет, не являющийся взаимодействием, например Демо: Заказ покупателя, приложение после этого автоматически поменяет предмет у всей цепочки. Например, переговоры с потенциальным клиентом, состоявшие из встреч, телефонных звонков и переписки (цепочки взаимодействий) закончились заказом клиента. В этом случае приложение позволяет изменить предмет во всех взаимодействиях, предшествовавших заказу, на итоговый заказ клиента.

Кроме этого, для удобства работы с контактами приложение формирует единую адресную книгу на основании контактов взаимодействий.

Для работы с взаимодействиями администратору необходимо настроить приложение (см. раздел Настройка приложения).

В состав ролей участников взаимодействий необходимо включить роли:

■  Чтение адресов электронной почты;

■ Добавление и изменение взаимодействий.

Настройка приложения

Перед тем как начать работать с взаимодействиями, в разделе Администрирование – Органайзер – Почта необходимо выполнить следующие настройки:

■ Почтовый клиент – включив флажок, можно использовать встроенный почтовый клиент. Использование всех типов взаимодействий без почтового клиента невозможно;

■ Включите флажок Исходящие письма в формате HTML, для того чтобы стало доступным расширенное форматирование исходящих писем. Если выбран формат HTML, то появляются дополнительные возможности оформления исходящих писем. В этом случае с помощью стандартных команд можно изменить форматирование текста, вставить гиперссылку или картинку (подробнее см. раздел Исходящее электронное письмо);

■ Звонки, SMS, встречи и запланированные взаимодействия – для отражения взаимодействий в приложении могут использоваться не только входящие и исходящие письма электронной почты. Включите флажок, для того чтобы использовать и другие документы взаимодействия;

■ Признаки «Рассмотрено» и «На контроле» – в документах взаимодействия можно включать флажок Рассмотрено в знак того, что взаимодействие не требует дальнейшего внимания. Флажок На контроле используется для постановки на контроль исходящего письма или сообщения SMS. Использовать Признаки «Рассмотрено» и «На контроле» рекомендуется при коллективной работе с документами взаимодействия. В списке взаимодействий приложение выделяет жирным шрифтом документы к рассмотрению и с включенным флажком На контроле. С документов с включенным флажком Рассмотрено выделение снимается (см. раздел Список взаимодействий).

■ Запретить отображение небезопасного содержимого в письмах – включите флажок, для того чтобы при наличии небезопасных элементов в письмах не предлагать их отображение. Входящие письма (подробнее см. раздел Входящее электронное письмо) могут содержать элементы, позволяющие отправителю скрытно отслеживать действия с письмом, в частности, время просмотра и некоторые параметры устройства, на котором письмо было прочитано. К небезопасным элементам относятся, например, загружаемые из Интернета картинки в письмах или встроенные скрипты. В целях безопасности такие элементы автоматически отключаются при просмотре письма.

Для того чтобы использовать возможность отправки и получения электронных писем из приложения, для каждого почтового ящика, с которым планируется работа в приложении, необходимо настроить почту (раздел Администрирование – Органайзер – Почта, ссылка Настройки почты). Подробнее см. раздел документации Работа с почтовыми сообщениями.

Для того чтобы использовать возможность автоматической отправки и получения электронных писем (в клиент-серверном варианте работы это единственный способ отправки и получения писем), необходимо настроить работу регламентного задания Получение и отправка электронных писем (раздел Администрирование – Обслуживание – Регламентные операции, ссылка Регламентные и фоновые задания). Подробнее см. раздел документации Регламентные задания.

Для того чтобы иметь возможность отправлять SMS-сообщения, необходимо произвести настройки (подробнее см. раздел документации Отправка SMS).

Для отправки SMS также предусмотрено регламентное задание Отправка SMS. Для того чтобы состояния доставки отправленных сообщений SMS обновлялись автоматически, необходимо настроить регламентное задание Обновление статусов доставки SMS. Подробнее см. раздел документации Регламентные задания.

Настройки почты

По ссылке в панели навигации настройки почты можно перейти к Дополнительным настройкам почты.

На вкладке Основное с помощью переключателя Использование для встроенного почтового клиента можно управлять доступностью электронной почты.

По умолчанию электронная почта включена, т. е. переключатель установлен в положение Получать, сохранять и отправлять письма с этой электронной почты во встроенном почтовом клиенте.

Иначе эта электронная почта будет недоступна для интерактивной работы.

Недоступная электронная почта может понадобиться, например, для синхронизации данных или для рассылки отчетов. В этом случае переключатель Использование для встроенного почтового клиента нужно установить в положение Не использовать. Тогда не выполняются получение, хранение и отправка почты для этой электронной почты, но все настройки почты сохраняются.

Для используемой электронной почты на вкладке Основное предусмотрены следующие настройки:

■ Для того чтобы в отправляемом сообщении в представление адреса не попадало имя пользователя, необходимо выключить флажок В представление включать имя пользователя;

■ Если для электронной почты не предполагается хранение писем после отправки, то для такой электронной почты можно настроить автоматическое удаление писем после их отправки (для этого нужно включить флажок Удалять письма после отправки). Флажок можно включить, например, для электронной почты, с которой осуществляется массовая рассылка писем клиентам компании.

Обработка писем

На вкладке Обработка писем можно указать свойства почты.

Если почта является общей или корпоративной (переключатель Почта используется на странице Основное установлен в положение Всеми пользователями, проверить это можно по ссылке Основное панели навигации настройки почты, подробнее см. раздел документации Работа с почтовыми сообщениями), то для нее нужно задать Ответственного за обработку писем. Выберите из списка Пользователи сотрудника, который по умолчанию назначается ответственным за рассмотрение писем.

Также необходимо выбрать Ответственного за ведение папок. Выберите из списка Пользователи сотрудника, который будет определять структуру папок и правила обработки входящих писем.

Для входящих писем можно задать правила обработки, по которым письма будут автоматически размещаться в той или иной папке (подробнее см. в разделе Правила обработки электронной почты).

Если включить флажок Помещать письма в папку письма-основания, то письма, отправленные в ответ на письмо-основание или полученные в ответ на отправленные письма, будут автоматически размещаться в папку письма-основания, а настроенные правила обработки для таких писем будут игнорироваться (это не касается предопределенных папок, если письмо находится в предопределенной папке, то правила применяются).

Если получение почты проходит по протоколу IMAP, то в этом случае обработка входящих писем может проводиться и в другом почтовом клиенте.

Проверить это можно в настройках почты на вкладке Получение писем по ссылке Основное панели навигации (подробнее см. раздел документации Работа с почтовыми сообщениями).

Электронные письма по протоколу IMAP загружаются из всех папок на почтовом сервере, в том числе и исходящие письма, за исключением папок Черновики, Удаленные, Спам.

Если на сервере нет ни одной активной папки, то загрузка выполняется из всех папок, кроме списка исключений, который описан выше. Связано такое решение с тем, что некоторые почтовые сервере все папки по умолчанию делают неактивными, при этом из собственных веб-клиентов работают с ними как с активными.

Исходящими считаются письма, у которых адрес отправителя совпадает с адресом, указанным в настройке почты. В случае если такое письмо отправлено и на собственный почтовый адрес, то оно не загружается.

Для загруженного письма проверяются ранее загруженные письма на предмет поиска основания, а также проверяется, а не является ли загруженное письмо основанием для одного или нескольких ранее загруженных писем. Таким образом, обеспечивается надежное выстраивание писем в цепочки и определение для вновь загруженных писем предметов.

Подписи

На вкладках Подписи можно создать шаблоны подписей, которые будут автоматически подставляться в письмо при создании нового письма (на вкладке Подпись для нового) или при ответе и пересылке письма (на вкладке Подпись при ответе), а также задать Формат подписи: Обычный текст или HTML.

Для того чтобы размещать подписи, включите флажки Включать подпись для новых писем (Включать подпись при ответе или пересылке).

Выбрать формат подписи можно, если в настройках параметров приложения включен флажок Исходящие письма в формате HTML, подробнее см. раздел Настройка приложения.

Если выбран формат подписи HTML, то появляются дополнительные возможности оформления подписи. В этом случае с помощью стандартных команд можно изменить форматирование текста, вставить гиперссылку или картинку.

Задать шаблон подписи для подстановки в письмо можно и по команде Еще – Персональные настройки в списке Взаимодействия (подробнее см. раздел Персональные настройки). По умолчанию используется шаблон подписи, указанный в настройке почты, если его использование не включено в настройке почты, то будет использоваться шаблон из персональных настроек пользователя.

Нажмите кнопку Записать для сохранения установленных настроек.

Папки электронных писем

Для того чтобы настроить Папки электронных писем, перейдите по ссылке панели навигации настройки почты.

Для каждой настройки почты по умолчанию используются следующие папки электронной почты (предопределенные папки):

■ Входящие – в эту папку попадают все входящие письма;

■ Исходящие – в эту папку попадают исходящие письма, которые ожидают отправки;

■ Нежелательная почта – могут попадать входящие письма, определенные почтовым сервером как нежелательные (подробнее см. документацию почтового сервера);

■ Отправленные – после отправки письма попадают в эту папку;

■ Удаленные – в эту папку попадают письма, помеченные на удаление;

■ Черновики – в эту папку попадают исходящие письма, редактирование которых еще не завершено.

Имеющиеся в приложении по умолчанию (предопределенные) папки нельзя отредактировать и удалить.

Помимо предопределенных папок электронной почты для каждой настройки почты можно создавать собственные папки. Вложенные папки можно создать и в предопределенных папках, и в собственных, тогда можно рассортировать имеющуюся в них почту.

Это поможет в случае, если в предопределенных папках почты накапливается слишком много.

Например, менеджер по продажам ведет переписку с клиентами, помимо этого, ему приходят рассылки и письма от сотрудников и объем переписки очень большой. Можно рассортировать входящие письма, создав вложенные папки:

■ для переписки с важными клиентами, при этом для нескольких ключевых клиентов ввести отдельные папки;

■ для рассылок;

■ для писем сотрудников.

Создание специальных папок поможет навести порядок в переписке. Кроме этого, можно автоматически сортировать письма и раскладывать их по папкам, используя правила обработки писем. Подробнее см. раздел Правила обработки электронной почты.

Для ввода папки нажмите кнопку Создать.

Введите Наименование папки.

Создать новую папку, отредактировать или удалить ранее созданную папку можно также в списке Взаимодействия (подробнее см. раздел Группировка списка по папкам электронных писем).

Правила обработки электронной почты

Для писем можно задать правила обработки электронной почты, по которым они будут автоматически размещаться в той или иной папке. Задавать правила обработки имеет смысл, если на этот адрес почты приходит много корреспонденции.

Правила хранятся в списке Правила обработки электронной почты, открыть список можно с помощью ссылки в панели навигации настройки почты.

Для того чтобы задать правила обработки, в списке нажмите кнопку Создать.

В поле Условие необходимо выбрать наименование созданного правила из выпадающего списка, после того как будут сформированы условия правила. Если такое наименование слишком длинно, можно написать свое наименование. Поле является обязательным для заполнения.

В поле Помещать в папку укажите, в какую папку попадут письма, удовлетворяющие заданным условиям, например, Отправленные – Клиентам. Поле является обязательным для заполнения.

Задать новое условие можно с помощью кнопки Добавить новый элемент. Условий может быть несколько.

В колонке Поле с помощью кнопки  укажите поле электронного письма, по которому будет производиться отбор.

Выберите Вид сравнения с помощью кнопки , при этом кроме стандартных видов (например, Больше или равно), можно выбрать и нестандартные, например, В списке:

■ С помощью вида сравнения В списке можно задать список возможных значений для отбора, например, сюда можно поместить несколько почтовых ящиков партнера (контрагента), с которых возможна отправка корреспонденции. Вид сравнения Не в списке является отрицанием предыдущего. Например, в другую папку нужно поместить остальные письма, кроме писем, полученных от перечисленных в списке отправителей;

■ С помощью вида сравнения Содержит или Не содержит можно использовать поиск по части поля (сочетанию букв) – наименования, темы, адреса, если полностью это поле неизвестно. Например, можно задать шаблон почтовых ящиков контактных лиц определенного партнера (контрагента), если название его сайта известно – @Gazeta.ru. В этом случае письма с почтовых адресов с этим сочетанием букв будут помещены в одну папку;

■ Определить, есть ли в поле значение, можно с помощью вида сравнения Заполнено или Не заполнено. Например, с помощью такого условия можно в отдельную папку поместить письма, в которых не указана тема.

Затем настройте Значение, например, список из нескольких адресов партнера (контрагента). Для этого в зависимости от выбранного поля и вида сравнения нажмите кнопку Выбрать и выберите из предложенного списка значений нужное, введите значение или создайте свой список значений. В список можно внести значения вручную. Если в качестве типа данных списка выбран какой-либо список приложения, то появляется возможность заполнить список значений с помощью кнопок Добавить или Подбор.

Можно использовать несколько условий для более тонкого отбора. Это позволит облегчить работу с почтой, если на почтовый ящик компании поступает много электронных писем.

В этом случае с помощью кнопки Сгруппировать условия к выделенным условиям необходимо применить логические операции И, ИЛИ, Не. Для того чтобы использовать группировку условий, выделите одно из нужных условий, нажмите кнопку Сгруппировать условия, выберите Тип группы: И, ИЛИ, Не. С помощью кнопки мыши перетащите остальные условия в группу или создайте их внутри группы.

Например, для того чтобы в папку определенного партнера (контрагента) попадали его письма, можно создать правило для папки таких писем, а в условиях указать все адреса электронной почты партнера и объединить условия в группу по логической операции ИЛИ. Если известно, что письма от данного клиента приходят только определенному сотруднику или с определенных адресов, то можно создать более точное условие для отбора почты также с помощью логической операции ИЛИ.

Если в правиле задается несколько условий без группировки, то по умолчанию к таким условиям применяется логическая операция И.

Нажмите кнопку Записать и закрыть, после этого созданные правила начнут применяться для всех новых писем (при получении писем и при изменении статуса писем, например с нового на черновик и т. д.).

Для того чтобы отсортировать по новым правилам письма, которые уже существовали в приложении на момент создания правила, нужно выделить условия, затем нажать на кнопку Применить правила.

В поле Для писем в папке укажите, к письмам какой папки будут применены правила (если включить флажок Включая подчиненные, то будут отсортированы письма и в подчиненных папках).

Оставьте включенными флажки только для тех правил, которые собираетесь применить.

С помощью кнопки Применить отмеченные в списке флажками правила будут применены к письмам указанной папки. Применить правила также можно во время работы с электронной перепиской в списке Взаимодействия. Подробнее см. раздел Группировка списка по папкам электронных писем. См. также описание флажка Помещать письмо в папку письма-основания в разделе Обработка писем.

Настройка почты для группы пользователей

При настройке почты необходимо учитывать, что ограничения по правам доступа взаимодействий осуществляются по следующим правилам:

1. Ограничения действуют во взаимодействиях по ИЛИ, тогда как в остальных случаях, как правило, по И.

Это означает, что если документ взаимодействий доступен хотя бы одному условий в группе доступа, то он доступен пользователю.

Например, если пользователю не запрещена электронная почта или не запрещен пользователь или не запрещен контакт, то письмо ему будет доступно.

Фактически для каждого пользователя необходимо создавать отдельную группу доступа, и в ней осторожно выдавать права.

Рассмотрим примеры настройки групп доступа для работы с взаимодействиями.

1. Менеджер отдела продаж:

У него рабочий персональный адрес электронной почты. Ему должны быть доступны письма по его электронной почте, и переписка с клиентами, с которыми он работает.

В данном случае настройка ограничений (виды доступа) такая:

■ Адреса электронной почты – запрещены все кроме одной;

■ Группы партнеров – некоторые (с которыми производится работа) разрешены;

■ Пользователи – все запрещены.

2. Сотрудник отдела продаж, отвечающий за разбор почты отдела, например почтовый ящик orders@mycompany.ru:

Ему должны быть доступны письма по его электронной почте, и общей электронной почте.

В данном случае настройка такая:

■ Адреса электронной почты, запрещены все кроме этих двух;

■ Группы партнеров – все запрещены;

■ Пользователи – все запрещены.

3. Руководитель группы продаж:

Ему должны быть доступны письма подчиненных и партнеров, с которыми отдел работает.

В данном случае настройка такая:

■ Адреса электронной почты – указывается список адресов электронной почты сотрудников отдела и общая почта, на которую присылают заказы;

■ Группы партнеров – какие-то группы разрешены;

■ Пользователи – разрешены все подчиненные сотрудники.

Рассмотрим подробнее процесс настройки почты для нескольких пользователей. В случае если возникает необходимость ограничить доступ к почте пользователям, т. е., для того чтобы переписка с использованием данного адреса электронной почты была доступна только конкретным пользователям (например, при использовании электронной почты для рассылки расчетных листков сотрудникам организации), необходимо выполнить следующие настройки:

1. Создать отдельную общую почту, которая будет в дальнейшем использоваться только конкретными пользователями (подробнее см. раздел документации Работа с почтовыми сообщениями);

2. Создать отдельную группу доступа с ограниченным количеством участников (пользователей) с доступом к электронной почте из п.1, одним из следующих способов:

1-й способ: Создание отдельной группы доступа и подбор в нее пользователей:

В разделе Администрирование – Настройки пользователей и прав – Группы доступа – необходимо создать новую группу доступа (подробнее см. раздел документации Управление доступом), в которой необходимо заполнить следующие поля:

■ Наименование – указать название группы доступа, например, Рассылка учетных листков;

■ Профиль – из выпадающего списка выбрать значение Ответственный за ведение взаимодействий (дополнительно);

■ На вкладке Участники группы (открывается по умолчанию) с помощью кнопки Подобрать выбрать перечень участников группы (можно заранее создать отдельную группу пользователей, тогда можно сразу выбрать группу пользователей, например, Рассылка расчетных листков), для которых создается новая электронная почта.

■ На вкладке Ограничение доступа выделить вид доступа почта и в поле Разрешенные значения Добавить с помощью кнопки панели навигации электронную почту, введенную ранее (см. п. 1 например, Рассылка расчетных листков).

■ После сохранения настроек использовать конкретную электронную почту (выполнять рассылку, просматривать переписку) будет возможность только у тех пользователей, которые включены в новую группу.

2-й способ: Добавление группы доступа каждому пользователю (данная настройка выполняется для каждого пользователя отдельно и может проводиться ответственным пользователем):

1. В разделе Администрирование – Настройки пользователей и прав – Пользователи, (или в разделе Управление доступом – Пользователи) открыть список пользователей.

2. Далее двойным кликом открыть карточку выбранного пользователя и перейти в раздел Права доступа.

3. Затем включить пользователя во вновь созданную группу доступа Рассылка учетных листков, если такой группы доступа еще нет, создать ее (о создании группы доступа см. способ 1), добавить в ограничения доступ электронной почты.

Персональные настройки

Перед тем как начать работать с почтовыми сообщениями, в приложении необходимо настроить работу с почтой. Для этого нужно произвести персональные настройки с помощью команды Демо: Мои настройки в разделе Главное. Для этого на вкладке Главное перейдите по ссылке Настройки работы с почтой.

Окно Настройки работы с почтой состоит из четырех вкладок:

■ Подпись для нового;

■ Подпись при ответе;

■ Отслеживание писем;

■ Прочее.

Подписи

Для настройки работы с почтой на вкладках Подпись для нового и Подпись при ответе можно создать шаблоны подписей. Шаблоны подписей можно создать также при настройке почты. Подробнее см. раздел Подписи.

Отслеживание писем

На вкладке Отслеживание писем можно включить возможность запроса уведомлений от получателя о прочтении и доставке отправленных писем (для этого необходимо включить флажки Уведомление о прочтении и Уведомление о доставке). Эти значения по умолчанию для каждого конкретного письма можно изменить в окне исходящего письма. См. раздел Исходящее электронное письмо.

С помощью переключателей можно настроить поведение приложения и при получении запросов уведомлений о прочтении писем:

■ Всегда отправлять уведомление – всегда автоматически отправлять уведомления о прочтении при получении писем;

■ Никогда не отправлять уведомление;

■ Запрашивать перед тем как отправить уведомление – запрашивать подтверждение на отправку уведомления о прочтении писем.

Прочее

На вкладке Прочее можно с помощью флажков включить возможность отображения или включения в переписку содержания исходного письма (подробнее см. в разделе Исходящее электронное письмо).

В приложении предусмотрена возможность Отправлять почтовые сообщения сразу (по умолчанию письма отправляются по расписанию регламентного задания Получение и отправка электронных писем). Письма в приложении можно отправить также с помощью кнопки  Отправить и получить списка Взаимодействия, подробнее см. раздел Список взаимодействий. Подробнее о работе с регламентными заданиями см. раздел документации Регламентные задания.

Отражение взаимодействий в приложении

С помощью кнопки  Взаимодействия из документа или контакта можно:

■ Запланировать взаимодействие;

■ Запланировать встречу;

■ Написать SMS;

■ Написать электронное письмо;

■ Позвонить.

Аналогичные действия возможны также из списка документов или контактов. В документах взаимодействий также можно создавать новые взаимодействия, выстраивая цепочку.

Документ можно ввести в списке Взаимодействия, который можно найти на начальной странице приложения или в разделе Органайзер. Подробнее см. раздел Список взаимодействий. Для отражения взаимодействий нажмите кнопку Создать, из выпадающего списка выберите нужный документ:

■ Встреча (подробнее см. раздел Встреча);

■ Запланированное взаимодействие (подробнее см. раздел Запланированное взаимодействие);

■ Телефонный звонок (подробнее см. раздел Телефонный звонок);

■ Сообщение SMS (подробнее см. раздел Сообщение SMS);

■ Электронное письмо (подробнее см. раздел Исходящее электронное письмо).

Заполните в документе необходимые поля.

Заполнение документов

В документах взаимодействий присутствуют следующие поля, общие для всех взаимодействий:

■ Предмет – поле показывает, чему посвящено взаимодействие. При сохранении документа взаимодействия пустое поле Предмет автоматически заполняется значением текущего документа (т. е. такой документ взаимодействия начинает цепочку взаимодействий). Подробнее см. раздел Заполнение поля Предмет;

■ Важность события – доступно три значения: Низкая, Обычная (значение по умолчанию), Высокая. Отображается в списке специальными значками. (Подробнее см. раздел Список взаимодействий);

■ В поле Ответственный необходимо указать пользователя, ответственного за данное взаимодействие. По умолчанию приложение указывает в качестве ответственного для большинства документов взаимодействия текущего пользователя, для входящих писем – ответственного за обработку писем;

■ В поле Рассмотреть после указывается время, через которое необходимо выполнить запланированные действия. Доступны значения из списка: через пятнадцать минут, полчаса, один и три часа, сутки. Помимо этих значений можно указать произвольную дату и время с помощью кнопки ;

■ В документе взаимодействий включенный флажок Рассмотрено означает, что документ не требует дальнейшего внимания. С рассмотренных документов приложение снимает выделение. Для исходящих писем и сообщений SMS используется флажок На контроле. В отличии от флажка Рассмотрено флажок На контроле следует включать у писем и сообщений SMS, которым необходимо уделить внимание в дальнейшей работе (если флажок На контроле не включен, то письмо или сообщение считается рассмотренным и наоборот). Флажки доступны, если в настройках приложения включен флажок Признаки «Рассмотрено» и «На контроле». Подробнее см. раздел Настройка приложения. Использовать флажки Рассмотрено и На контроле рекомендуется при коллективной работе с документами взаимодействия. Подробнее о действии флажков см. раздел Список взаимодействий;

■ В поле Тема нужно вкратце описать суть взаимодействия;

■ Описание – нужно указать, какие действия необходимо выполнить в рамках взаимодействия. Является обязательным в большинстве документов взаимодействий (только у писем это текст письма, который не является обязательным). Выносится на отдельную вкладку. В SMS-сообщениях это поле называется Текст сообщения;

■ Комментарий – можно добавить дополнительную информацию о взаимодействии. Выносится на отдельную вкладку;

■ Контакт – всегда присутствует во всех документах взаимодействий, однако представление контактов в документах различается. Подробнее см. раздел Заполнение поля Контакты (списка участников);

■ Создан – по умолчанию текущая дата, изменить поле невозможно;

■ Автор – по умолчанию текущий пользователь, изменить ссылку невозможно. Перейдите по ссылке, для того чтобы просмотреть информацию о пользователе – авторе взаимодействия.

В документах имеются поля, обязательные для заполнения. Они подчеркнуты красным цветом. Без заполнения этих полей сохранение документов невозможно. Часть полей заполняется приложением по умолчанию.

Заполнение поля Предмет

Для заполнения поля Предмет выберите тип документа.

При выборе предмета можно сузить выбор, включив флажок Не отображать взаимодействия. В этом случае в списке будут отражены остальные документы приложения, например, Демо: Заказ покупателя. В открывшемся списке выберите нужный документ.

Если поле Предмет остается пустым, то при сохранении документа приложение подставляет данные самого документа, т. е. тогда этот документ начинает цепочку взаимодействий.

При создании документа Взаимодействия на основании другого взаимодействия предметом взаимодействия во вновь созданном документе будет предмет, указанный в исходном документе, при этом основные поля будут также скопированы.

Заполнение поля Контакты (списка участников)

Документы взаимодействий чаще всего содержат поле Контакты.

Например, в документах Встреча и Запланированное взаимодействие присутствует список участников (вынесен на специальную вкладку), в который необходимо Добавить все контакты, которые будут участвовать в запланированном мероприятии или встрече.

В документе Запланированное взаимодействие контакты являются необязательным полем, т. к. состав участников планируемого мероприятия может быть неизвестен. Для писем заполнение поля также не проверяется. Для остальных документов это поле является обязательным для заполнения.

Если контакты были занесены в приложение ранее, то при заполнении списка контактов или поля Контакт можно воспользоваться кнопкой  Выбрать в колонке или поле Контакт или клавишей F4, в открывшемся окне Выбор контакта подобрать нужные значения. Подробнее см. раздел Выбор контакта. Для исходящих писем предусмотрена Адресная книга (подробнее см. раздел Адресная книга).

После выбора контакта его контактная информация и наименование будет отображаться в поле Как связаться. Подробнее см. раздел документации Контактная информация.

Если контакты не были внесены в приложение, то Представление контакта (например, Ф.И.О. или наименование организации) и его контактную информацию можно указать в списке участников или в поле документа Как связаться. По кнопке Создать контакт на основании выделенного в списке контакта можно добавить элемент в списки Демо: Партнеры, Демо: Контактные лица партнеров, Демо: Контрагенты (будет использовано только представление контакта).

Если поле Контакт не заполнено (или в списке контактов имеются незаполненные колонки Контакт), то приложение рядом с полем или списком размещает предупреждение Контакт не подобран (Не все контакты подобраны).

Сообщение SMS

Для проведения SMS-рассылки и последующего отражения факта отправки сообщений используется документ Сообщение SMS.

Документ позволяет создавать, редактировать и отправлять сообщение SMS, помимо их документирования и хранения. Возможна отправка нескольких сообщений разным адресатам с одинаковым текстом посредством одного документа Сообщение SMS. В этом случае точнее отслеживается состояние каждого сообщения, и при этом на основании состояния отдельного сообщения – каждому из различных адресатов – формируется общее состояние документа.

В документе имеются общие для всех взаимодействий поля, кроме этого есть особенности заполнения.

С помощью флажка Преобразовать кириллические символы в латинские можно отправить сообщение в транслите.

В поле Текст сообщения приложение производит подсчет букв введенного текста и указывает количество оставшихся символов до конца сообщения по правилам, принятым всеми провайдерами, в случае превышения размера одного сообщения текст автоматически разбивается на отдельные сообщения.

В таблице Адресаты можно указать один или несколько контактов, подробнее см. раздел Заполнение поля Контакты (списка участников). Контакты (и их телефонные номера) являются обязательным для заполнения элементом подробнее см. раздел Выбор контакта.

В приложении предусмотрена возможность регулировать сроки рассылки сообщений:

■ С помощью поля Когда отправить можно отложить рассылку до нужной даты. Также можно определить точное время начала рассылки;

■ С помощью поля Не отправлять после можно указать точные дату и время прекращения рассылки.

С помощью кнопки Отправить можно разослать сообщения SMS всем перечисленным контактам.

Действие кнопки:

■ В файловой базе пользователь выполняет непосредственную отправку;

■ В клиент-серверной базе пользователь инициирует отправку, сообщение переходит в состояние Исходящее (перечисление всех состояний см. ниже). Непосредственная отправка выполняется регламентным заданием в фоне. Подробнее см. раздел документации Регламентные задания.

Состояние SMS-сообщений отражается внизу документа и в таблице в колонке Состояние сообщения по каждому контакту отдельно.

Состояние сообщения SMS каждому адресату может принимать значения:

■ Черновик – сообщение еще не отправлялось и может быть отредактировано;

■ Исходящее – сообщение уже отправлено, но оно еще не передавалось провайдеру;

■ Не удалось передать провайдеру – приложение пыталось передать сообщение провайдеру, но не смогла этого сделать. Например, возникли технические проблемы на стороне провайдера;

■ Не отправлено провайдером – сообщение успешно передано провайдеру, но еще не было им обработано;

■ Отправляется провайдером – сообщение в данный момент отправляется провайдером;

■ Отправлено провайдером – сообщение отправлено провайдером, состояние доставки на данный момент неизвестно;

■ Доставлено - сообщение успешно доставлено адресату;

■ Не доставлено – сообщение не удалось доставить адресату. Дальнейших попыток доставки сообщения не будет;

■ Не опознано провайдером – провайдер не опознал, что когда-то принимал данное сообщение к доставке;

■ Ошибка получения статуса у провайдера – не удалось связаться с провайдером при попытке получения состояния сообщения.

Состояния документа Сообщение SMS в целом могут принимать значения:

■ Черновик – сообщение еще не отправлялось и доступно для редактирования;

■ Исходящее – сообщение уже отправлено, но оно еще не передавалось провайдеру;

■ Доставляется – все сообщения переданы провайдеру и хотя бы по одному из них не закончена доставка до адресата;

■ Доставлено – все сообщения успешно доставлены адресатам;

■ Частично доставлено – доставка сообщений прекращена, часть сообщений доставлена адресатам, часть нет;

■ Не доставлено.

Проверка состояния доставки осуществляется регламентным заданием. Также можно вручную проверить, воспользовавшись командой Проверить состояние доставки (команда становится активной после отправки сообщений).

В сообщении SMS предусмотрена кнопка  Записать и закрыть, ее можно использовать для сохранения сообщения, если отправка пока не требуется.

Входящее электронное письмо

В полях От и Кому указаны электронные адреса отправителя и получателей, в поле Копии – дополнительные получатели. Также в документе присутствует Тема письма и текст самого письма.

Входящие письма могут содержать элементы, позволяющие отправителю скрытно отслеживать действия с письмом, в частности, время просмотра и некоторые параметры устройства, на котором письмо было прочитано. К небезопасным элементам относятся, например, загружаемые из Интернета картинки письма или встроенные скрипты. В целях безопасности такие элементы автоматически отключаются при просмотре письма. Если в приложении разрешено включение таких элементов, то при их наличии выводится предупреждение со ссылкой, по которой можно Отобразить небезопасное содержимое.

Если нажать на ссылку Отобразить небезопасное содержимое, то будут включены картинки, загружаемые из Интернета. Остальные небезопасные элементы письма, такие как встроенные скрипты, включены не будут. У администратора имеется возможность запретить включать картинки (тогда не будет предупреждения и ссылки). Подробнее см. раздел Настройка приложения.

Помимо этих полей присутствуют поля, общие для всех взаимодействий в приложении: Предмет, Важность, Ответственный, Рассмотреть после, Рассмотрено. В нижней части письма отображается внутренний Номер письма, дата и время его отправки (присваивается приложением по умолчанию).

С помощью кнопки Ответить можно создать Исходящее электронное письмо, при этом в исходящее письмо будет подставлен в качестве адресата отправитель входящего письма, а само письмо попадет в цепочку взаимодействий.

С помощью кнопки  Ответить всем можно написать исходящее письмо отправителю и всем контактам, указанным во входящем письме (в полях Кому, Копии).

С помощью кнопки  Переслать будет сформировано исходящее письмо, включающее в себя текст и вложения входящего письма. Подробнее см. раздел Исходящее электронное письмо.

В случае если требуется переслать письмо c полным содержанием, необходимо в Персональных настройках с помощью соответствующих флажков включить возможность отображения или включения в переписку содержания исходного письма.

По ссылке Сохранить адреса в контакты адреса можно сопоставить с контактами и при необходимости обновить контактную информацию контактных лиц в окне Сохранение адресов в контактах.

Если адрес был ранее сопоставлен с контактом, то он будет отображен в списке. Если адрес не был ранее сопоставлен с контактом, или если необходимо сопоставить адрес с другим контактом, или записать адрес в другое поле контактной информации, то в поле Контакт можно выбрать контакт, в который будет записан новый адрес электронной почты. В поле Вид эл. почты контакта можно уточнить, в какое именно поле будет записан электронный адрес контакта. (О контактной информации подробнее см. раздел документации Контактная информация).

С помощью кнопки Записать и закрыть для указанных контактов адреса будут перезаписаны в указанный вид электронной почты. После сопоставления к адресу электронной почты (его представлению) в письме будет добавлено наименование контакта. Если у контакта в приложении указан адрес электронной почты, то при получении письма от такого контакта сопоставление контакта с адресом электронной почты произойдет автоматически.

Если для получения писем используется протокол IMAP, то появляются дополнительные возможности обработки писем. Подробнее см. раздел Обработка писем.

По команде Еще – Параметры письма можно изменить настройку уведомления о доставке и прочтении письма (значения по умолчанию задаются в персональных настройках, подробнее см. раздел Персональные настройки). Также отображается служебная информация.

Статусы исходящих писем

Исходящим письмам присваиваются следующие статусы, в зависимости от которых они попадают в предопределенные папки, статусы отображаются в списке значками (подробнее см. раздел Список взаимодействий):

■ Если письмо еще не отправлено, то оно имеет статус Черновик. Его можно редактировать и записывать изменения. С помощью кнопки панели навигации можно Отправить письмо (для файлового варианта) и оно перейдет в другой статус;

■ Если письмо находится в процессе отправки, то ему присваивается статус Исходящее. После попытки отправить письмо его статус меняется, а наименование кнопки меняется на Отправить сейчас. Редактировать такие письма уже нельзя;

■ После отправки исходящего письма его статус меняется на статус Отправлено. Редактирование такого письма также невозможно.

В зависимости от статуса письмо помещается в ту или другую папку (см. раздел Папки электронных писем). Также можно настроить правила обработки писем (см. разделы Правила обработки электронной почты и Группировка списка по папкам электронных писем).

Выбор контакта

Окно Выбор контакта предназначено для поиска и подбора контакта в документы взаимодействий, содержит вкладки:

■ Поиск контактов;

■ Контакты по предмету;

■ Пользователи;

■ Демо: Партнеры;

■ Демо: Контрагенты.

Если контактов много, то на вкладке Поиск контактов можно найти нужный контакт.

Поиск можно выполнить:

■ по адресу электронной почты (По e-mail);

■ По доменному имени почтового сервера;

■ По телефону;

■ По строке, входящей в наименование контакта;

■ по начальным символам наименования контакта (Начинается с).

Для поиска контактов По строке или по начальным символам наименования используется полнотекстовый поиск приложения, в этом случае поиск осуществляется по всем реквизитам контактов. Если индекс неактуален, поиск не производится, необходимо произвести обновление индекса. Подробнее см. раздел документации Полнотекстовый поиск.

Выберите способ поиска, напишите выражение для поиска и нажмите кнопку Найти. Будут подобраны контакты, удовлетворяющие условию.

На вкладке Пользователи можно подобрать контакты из списка Пользователи. Вкладка состоит из двух частей. В верхней части вкладки располагаются группы пользователей, в нижней части – пользователи выделенной группы. Если пользователей много, то можно воспользоваться кнопкой  Найти.

Если поле Предмет в документе взаимодействий было заполнено, то на вкладке Контакты по предмету приложение автоматически подбирает контакты, связанные с предметом. Данная вкладка содержит список контактов, которые фигурируют в самом предмете, а также во всех документах взаимодействий, где этот предмет указан.

На вкладке Демо: Партнеры отображается список партнеров. Список состоит из двух частей. Можно выбрать партнера в верхней части списка или контактное лицо выделенного партнера в нижней части списка, при необходимости можно добавить в список партнера (контактное лицо партнера) при наличии прав доступа, а также использовать другие возможности работы с данным списком с помощью команд меню Еще.

На вкладке Демо: Контрагенты отображается список контрагентов. При необходимости можно добавить в список нового контрагента при наличии прав доступа, а также использовать другие возможности работы с данным списком с помощью команд меню Еще.

Двойной щелчок по контакту добавит его в документ взаимодействия. Также можно воспользоваться кнопкой Выбрать.

Для добавления нескольких контактов из списка выделите их и нажмите кнопку Выбрать.

Адресная книга

В Адресной книге можно выполнить поиск и подбор контактов для исходящих электронных писем.

Левая часть окна содержит набор вкладок для выбора контактов: вкладка для поиска контактов и вкладки контактов. Подробнее см. раздел Выбор контакта.

Включите флажок в нижней части списка, для того чтобы показывать Только контакты с адресами. Применяется только к тем спискам, в которых есть колонка Адрес. Такая возможность может быть полезна, если в списках много контактов, при этом не все заполнены.

Двойной щелчок мыши по нужному контакту добавит запись о нем в правую часть адресной книги.

Правая часть Адресной книги содержит список контактов, которые с помощью кнопки Выбрать по умолчанию будут добавлены в поле Кому исходящего электронного письма. В колонке Группа можно изменить поле письма, в которое будут добавлены контакты (например, Кому на Копии и Скрытые или Получатели ответа). Для этого дважды щелкните мышью по нужному полю.

С помощью контекстного меню в правой части адресной книги можно Найти в списке, Найти по адресу, Найти по представлению, Выбрать адрес, указанный в контакте, а также разместить адреса в нужные группы.

Если контакт отсутствует в приложении, то его можно ввести в правый список вручную с помощью кнопки Добавить получателя, указав адрес электронной почты и представление контакта. Добавить строку в список можно также клавишей Ins или с помощью команды меню Еще.

Для того чтобы добавить контакты в поля исходящего письма, выделите нужные строки, нажмите кнопку Выбрать.

Список взаимодействий

В панели навигации различных документов, например, Демо: Заказы покупателя и элементов некоторых списков, например, Демо: Партнеры, Демо: Контрагенты или списка Пользователи, доступна ссылка Взаимодействия.

Ссылка открывает списки взаимодействий по предмету или контакту.

Жирным шрифтом в списке выделяются документы к рассмотрению, письма и сообщения SMS с включенным флажком На контроле. После включения флажка Рассмотрено выделение снимается.

Взаимодействия в списке обозначаются значками:

■  Запланированное взаимодействие;

■  Встреча;

■  Телефонный звонок;

■  Сообщение SMS;

■  Электронное письмо входящее;

■  Электронное письмо исходящее.

Значки могут обозначать не только виды документов, но и состояния:

■ документы, помеченные на удаление (для всех документов):  ;

■ черновики (для исходящих писем и сообщений SMS): ;

■ исходящие (для исходящих писем и сообщений SMS): .

В списке можно установить отборы с помощью полей в его верхней части или команд меню Еще (подробнее см. раздел Отборы списка), выполнить основные действия с взаимодействиями (Создать, Установить признак «Рассмотрено» и т.д. – подробнее см. раздел Команды для работы со списком).

Работа со всеми документами взаимодействий производится в списке Взаимодействия.

Список Взаимодействия можно найти на Начальной странице или в разделе Органайзер, состоит из колонок:

■  Вид взаимодействия;

■ Участники;

■ Дата;

■  Наличие вложений – если к письму были приложены файлы, то они отображаются в списке Взаимодействия специальным значком;

■  Важность (по умолчанию – Обычная, обозначаются значком  Низкая,  Высокая);

■ Тема.

Отборы списка

С помощью поля Ответственный можно установить отбор по ответственному, которого можно выбрать из списка Пользователи.

В списке с помощью выпадающего меню по кнопке Показывать можно установить отбор документов взаимодействий по видам, а писем и звонков еще и по статусу. В списке могут отображаться все взаимодействия, все письма электронной почты, только входящие, исходящие, отправленные или удаленные письма, письма из папки Черновики, встречи, все телефонные звонки, исходящие или входящие звонки. Если установлена группировка списка По папкам, кнопка не показывается, т.к. в этом случае письма группируются с помощью папок. Аналогичную команду можно найти в меню Еще.

С помощью выпадающего меню по кнопке Статус можно установить следующие отборы списка:

■ Все – установлен по умолчанию, показывает весь список;

■ Если в поле установлено значение К рассмотрению, то будут отображены взаимодействия, которые необходимо отработать до текущей даты, и с выключенным флажком Рассмотрено (или с включенным флажком На контроле);

■ Если в поле установлено значение Отложенные, то в списке показываются взаимодействия с заполненным полем Рассмотреть после и не включенным флажком Рассмотрено;

■ Если в поле установлено значение Рассмотренные, то в списке показываются взаимодействия с включенным флажком Рассмотрено (с выключенным флажком На контроле).

Аналогичную команду можно найти в меню Еще.

Также предусмотрен поиск по произвольному тексту во всех взаимодействиях или во вложениях.

Группировка взаимодействий

В левой части списка Взаимодействия отображается панель, с помощью которой можно удобно группировать взаимодействия.

Приложение ведет подсчет нерассмотренных документов и писем с флажком На контроле в каждой группе списка. Группы, которые содержат такие документы, выделяются жирным шрифтом.

С помощью кнопки над панелью можно менять группировку взаимодействий. Выбранная группировка выделяется флажком.

В панели доступна следующая группировка:

■ По предметам – все взаимодействия можно сгруппировать по предметам. В панели группировки можно открывать предметы, по которым сгруппированы взаимодействия (двойным щелчком мыши в панели группировки). Подробнее см. раздел Группировка списка по предметам;

■ По контактам – все взаимодействия можно сгруппировать по контактам;

■ По папкам – в этом случае в панели группировки отображаются папки электронной почты в разрезе почтовых ящиков. Двойным щелчком мыши по наименованию электронной почты можно открыть ее. С помощью перетаскивания мышью письма можно перемещать между папками электронной почты в пределах одной электронной почты. Также для этого можно использовать команды контекстного меню по правой кнопке мыши. Подробнее см. раздел Группировка списка по папкам электронных писем;

■ По закладкам – все взаимодействия можно сгруппировать по закладкам. С помощью закладок можно настроить отборы взаимодействий (отбор задается в закладке). Подробнее см. раздел Работа с закладками;

■ Если у какого-либо документа взаимодействия назначен дополнительный реквизит или сведение, то в панели доступна группировка и по такому свойству. Наличие дополнительных реквизитов и сведений возможно, если в приложении используется подсистема Свойства. Подробнее см. раздел документации Свойства.

При этом если один или несколько дополнительных реквизитов или сведений имеют значение типа Булево, то в панели доступна группировка По Категориям. При такой группировке в панели навигации отображаются наименования дополнительных реквизитов, а в списке взаимодействий отображаются взаимодействия, дополнительные реквизиты которых имеют логическое значение Истина.

Если дополнительный реквизит или сведение имеет значение отличное от типа Булево, то в панели навигации доступна группировка под названием дополнительного реквизита. При такой группировке в панели навигации отображаются значения дополнительного реквизита, а в списке взаимодействий отображаются взаимодействия, дополнительные реквизиты которых соответствуют значениям, выделенным в панели навигации. Например, если документам взаимодействий Встреча назначено дополнительное сведение Специалист службы безопасности, то можно сгруппировать все документы взаимодействий по этому признаку.

Например, если документам взаимодействия назначены дополнительные реквизиты Срочность и Перспективный контакт, имеющие тип Булево, то в панели навигации будет доступна группировка По категориям, а при ее установке в панели навигации будут отображены значения Срочность и Перспективный контакт.

При выделении категории Срочность в списке взаимодействий будут отображены документы взаимодействий, у которых включен флажок Срочность, а при выделении категории Перспективный контакт будут отображены документы, у которых включен флажок Перспективный контакт.

Если документам взаимодействия назначен дополнительный реквизит Цветовая метка, то в панели навигации будет доступна группировка По Цветовая метка, а при ее установке в панели навигации будут отображены значения дополнительного реквизита Цветовая метка – цвета Красный, Желтый, Зеленый). При выделении цвета в списке взаимодействий будут отображены документы, у которых в поле Цветовая метка выбран этот цвет.

Если документов взаимодействий в списке много, имеет смысл сочетать разные способы отбора, для того чтобы сузить круг поиска и убыстрить работу с документами.

С помощью ссылки под панелью можно Изменить группировку – включить или отключить учет отборов, например, взаимодействия в списке отобраны по полю Ответственный, и в панели группировки будут видны все контакты или с учетом отбора – только по этому ответственному. Используя данную возможность, можно быстро увидеть все предметы (контакты), не меняя отбор списка. Ссылка предусмотрена только для группировки по предметам или контактам.

Группировка списка по предметам

Все взаимодействия можно сгруппировать по предметам. В панели группировки можно открывать предметы, по которым сгруппированы взаимодействия (двойным щелчком мыши в панели группировки).

С помощью перетаскивания мышью взаимодействия можно перемещать между предметами, при этом в самом взаимодействии меняется предмет.

Возможна также быстрая установка предмета писем (встреч, звонков, SMS и запланированных взаимодействий) посредством перетаскивания писем в окно списка предметов.

Предусмотрена возможность быстро изменить предмет с помощью перетаскивания выделенных взаимодействий в окно списка документов, которые могут являться предметами взаимодействий.

Например, на рисунке параллельно расположены два окна – список Взаимодействия и список Демо: Заказы покупателя. С помощью перетаскивания выделенных взаимодействий в список Демо-заказы покупателя для них установлен новый предмет – документ Демо: Заказ покупателя номер 00-00000003 от 23.03.2012 г.

Если выделить один из предметов в панели группировки, то нажав кнопку Создать, можно ввести новые документы взаимодействий по данному предмету.

Группировка списка по папкам электронных писем

С электронной перепиской в списке Взаимодействия удобно работать при группировке По папкам.

В этом случае вся корреспонденция группируется сначала по электронной почте, затем внутри каждой электронной почты по папкам электронных писем, предопределенным и пользовательским. Предопределенные папки, всегда имеющиеся по умолчанию:

■ Входящие;

■ Исходящие;

■ Нежелательная почта;

■ Отправленные;

■ Удаленные;

■ Черновики.

В каждую папку письма попадают автоматически при получении или смене статуса, а также при применении правил обработки. Подробнее о настройках папок см. разделы Папки электронных писем и Правила обработки электронной почты. Подробнее о статусах писем см. раздел Исходящее электронное письмо.

Жирным шрифтом выделены письма с включенным флажком На контроле, приложение ведет подсчет таких писем для каждой электронной почты и в каждой папке. Подробнее о флажке см. раздел Заполнение документов.

При группировке По папкам и работе в одной из папок Исходящие, Отправленные, Черновики или подчиненных им доступны действия с исходящими письмами:

■ Написать;

■  Переслать;

■  Отправить и получить. В файловой базе с помощью кнопки Отправить и получить или сочетания клавиш Ctrl+F9 предусмотрена возможность проверить свой почтовый ящик. Если за период от последней проверки почтового ящика до текущего момента были получены новые письма, то приложение загрузит их в список, после чего выдаст сообщение о количестве новых писем. С помощью этой кнопки отправляются только письма текущего пользователя. В клиент-серверном варианте регламентным заданием осуществляется отправка и получение писем всех пользователей.

Если для получения писем используется протокол IMAP, то появляются дополнительные возможности обработки писем. Подробнее см. раздел Обработка писем.

При группировке По папкам электронных писем во время работы в папках Входящие, Нежелательная почта, Удаленные, вновь созданных для электронной почты в целом или подчиненных этим папкам доступны кнопки для работы с входящими письмами:

■ Написать;

■ Ответить;

■  Ответить всем;

■  Переслать;

■  Отправить и получить.

В контекстном меню панели группировки доступны команды по работе с папками электронных писем:

■ Применить правила обработки (подробнее см. раздел Правила обработки электронной почты);

■ Перенести в папку – команда доступна только для пользовательских папок (при наличии прав доступа). Для перемещения папок можно также использовать перетаскивание мышью;

■ Создать папку.

Для перемещения писем из одной папки в другую можно пользоваться перетаскиванием мышью. Также можно воспользоваться командой контекстного меню правой части списка Перенести в папку. Можно выбрать нужную папку из списка или создать новую. Нажмите кнопку Выбрать для возврата в список.

С помощью команды контекстного меню по правой кнопке мыши можно Переслать как вложение отправленные и полученные письма. После выполнения команды формируется исходящее письмо с выбранным письмом в качестве вложения.

Работа с закладками

Закладки могут быть только индивидуальными. С помощью закладок можно группировать документы взаимодействий в произвольные группы, например, по отделам предприятия, используя различные условия отбора.

Закладки можно группировать. Для этого выполните команду контекстного меню панели группировки Создать группу.

Введите Наименование группы, выберите Пользователя – владельца группы закладок с помощью кнопки  из списка Пользователи (по умолчанию приложение указывает в поле текущего пользователя, например, Администратор), затем создайте или перетащите с помощью мыши необходимое количество закладок. Поле Группа заполнится автоматически, если эта группа входит в вышестоящую группу. При этом группа и ее содержимое видно только владельцу.

Ввести новую закладку можно с помощью команды Создать контекстного меню панели группировки. Для отбора взаимодействий в закладки используются условия. Условия составляются по аналогии с условиями отбора в папки электронных писем. Подробнее о составлении условий см. раздел Правила обработки электронной почты. Например, можно создать закладку Кадровая служба. Все взаимодействия, в которых принимала участие кадровик Борисова, можно сгруппировать в этой закладке.

С помощью команды контекстного меню Добавить в закладки или с помощью перетаскивания мышью можно выделить документы в отдельные закладки Избранные взаимодействия. Затем такую закладку можно перетащить в одну из групп.

Для работы с закладками также предусмотрены команды контекстного меню:

■ Скопировать,

■ Изменить,

■ Пометить на удаление,

■ Переместить в группу,

■ Перейти на уровень выше,

■ Перейти на уровень ниже.

Все действия с закладками пользователя можно произвести также в карточке пользователя по ссылке панели навигации Закладки взаимодействий. Например, со своими закладками можно поработать, открыв сведения о текущем пользователе с помощью ссылки в персональных настройках приложения (раздел Главное). Подробнее о персональных настройках приложения см. раздел документации Настройки приложения.

Команды для работы со списком

С помощью кнопки Создать можно ввести новый документ, подробнее см. раздел Отражение взаимодействий в приложении.

В нижней части списка Взаимодействия может отображаться описание, текст выделенного в списке взаимодействия или тело письма. Для этого включите флажок Отображать область чтения в меню Еще.

С помощью кнопки  можно Скрыть панель навигации для удобства просмотра сведений о документах. С помощью кнопки  можно Показать панель навигации. Аналогичную команду можно найти в меню Еще.

С помощью кнопки  можно Установить признак рассмотрено, (также можно использовать сочетание клавиш Ctrl+R). У документов с включенным флажком Рассмотрено пропадает выделение жирным шрифтом. У сообщений SMS флажок называется На контроле, поэтому при включении флажка они выделяются жирным шрифтом. Для использования данной возможности необходимо включить флажок Признаки «Рассмотрено» и «На контроле», подробнее см. раздел Настройка приложения.

Для выключения флажка выполните команду Еще – Снять признак рассмотрено (также можно использовать сочетание клавиш Alt+Shift+R).

При получении входящих писем с почтового сервера по протоколу IMAP предусмотрена возможность автоматической синхронизации признака прочтения писем на почтовом сервере и признака Рассмотрено в списке Взаимодействия (для этого необходимо произвести настройки, см. раздел Обработка писем).

Отложить обработку одного или нескольких взаимодействий можно с помощью кнопки  Отложить рассмотрение и при этом указать дату и время, на которое будет отложено рассмотрение документа. Также можно использовать сочетание клавиш Ctrl+B.

С помощью кнопки  можно у одного или нескольких взаимодействий Установить ответственного (также можно использовать сочетание клавиш Ctrl+M). Выберите ответственного из списка Пользователи.

С помощью кнопки  у одного или нескольких взаимодействий можно Установить предмет взаимодействия. Также можно использовать сочетание клавиш Ctrl+G.

Если документов много, можно ограничить свой выбор. Например, включив флажок Не отображать взаимодействия, можно оставить в списке остальные имеющиеся типы документов.

Выберите тип документа, нажмите Выбрать для перехода к выбору документа из списка.

Если список сгруппирован по предметам, то установить предмет у нескольких взаимодействий также можно с помощью перетаскивания мышью (подробнее см. раздел Группировка списка по предметам).

С помощью команды меню Еще можно Установить период. Это имеет смысл, если в приложении накопилось много документов.

Можно отобрать документы взаимодействий только за нужный период, для того чтобы с ними было удобно работать.

Для этого можно написать начало и конец периода или выбрать из календаря, также имеется возможность выбрать нужный период из списка с помощью ссылки Показать стандартные периоды.

Выберите стандартный период с помощью кнопки в правой части окна, затем выберите период из списка. Включив флажок Запомнить выбранный период, можно будет воспользоваться настройками периода и в следующий сеанс работы с приложением.

С помощью кнопки Прочее можно выбрать дополнительные виды периодов.

Включите флажок Запомнить выбранный период, чтобы ограничить список Взаимодействия только этим интервалом дат.

Эти команды можно также найти в контекстном меню по правой кнопке мыши.

С помощью команды Персональные настройки меню Еще можно перейти к настройке электронной почты. Подробнее см. раздел Персональные настройки.
