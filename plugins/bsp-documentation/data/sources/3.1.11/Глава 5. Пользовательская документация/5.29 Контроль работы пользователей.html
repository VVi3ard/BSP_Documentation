5.29 Контроль работы пользователей

Администратор приложения может контролировать работу пользователей и выполнять диагностику работы приложения с помощью группы отчетов Контроль работы пользователей. Кроме того, можно проводить аудит доступа к определенным данным, для того чтобы узнать, кто и когда их просматривал. Отчеты формируются на основе данных журнала регистрации. Включает в себя следующие варианты отчетов:

■ Анализ активности пользователей;

■ Активность пользователя;

■ Анализ активности подразделений;

■ Контроль журнала регистрации;

■ Продолжительность работы регламентных заданий;

■ Изменение учетных записей пользователей;

■ Изменение участников групп пользователей (внешних пользователей);

■ Изменение участников групп доступа;

■ Изменение разрешенных значений групп доступа;

■ Изменение ролей профилей.

Важно! Необходимо учитывать, что представленные отчеты носят информационный характер и не могут служить основанием для оценки эффективности работы сотрудников, расчета заработной платы, а также для принятия кадровых решений.

Время работы в отчетах определяется по косвенным признакам активности на рабочем месте (использование компьютера, посещение ресурсов и т. д.) и не гарантирует, что сотрудник в указанный период непосредственно работал.

Для корректного расчета оплаты труда, оценки эффективности и других процессов в системе должны быть предусмотрены специализированные инструменты учета рабочего времени, соответствующие требованиям трудового законодательства и внутренним регламентам организации.

Для формирования и настройки отчетов должна быть установлена роль Полные права.

К формированию каждого из отчетов можно перейти по ссылке с наименованием отчета в списке Отчеты администратора раздела Администрирование – Отчеты.

Также предусмотрена возможность переключения между вариантами отчетов с помощью кнопки  Варианты отчета. Подробнее см. раздел документации Варианты отчетов.

Анализ активности пользователей

Отчет Анализ активности пользователей предназначен для получения статистической информации по активности пользователей. Данный отчет содержит набор показателей, которые уже сгруппированы и представлены в удобном для анализа виде:

■ Количество подключений (за период);

■ Количество часов работы;

■ Количество документов (введено, изменено);

■ Количество справочников (введено, изменено);

■ Количество проблем;

■ Количество предупреждений;

■ Максимальное количество одновременно работающих пользователей.

Для формирования отчета перейдите по ссылке Анализ активности пользователей в списке Отчеты администратора.

Необходимые настройки отчета выведены в его шапку.

По умолчанию в отчете уже установлен Период (например, С начала этой недели). Для изменения периода нажмите кнопку . Выберите стандартный период. Если он не устраивает, можно выбрать произвольный период и указать нужные даты.

Для того чтобы получить отчет, необходимо заполнить поле Пользователи в шапке отчета. Поле является обязательным. Нажмите кнопку .

Можно Выбрать группу пользователей, одного или несколько пользователей из предложенного списка. После выбора нужных пользователей или групп нажмите кнопку Подобрать и закрыть. Подробнее см. раздел документации Варианты отчетов.

Нажмите кнопку Сформировать. В таблице представлена статистика по выбранным пользователям, за указанный период. Для большей наглядности часть данных представлена в виде диаграмм. Первая диаграмма представляет количество введенных каждым пользователем документов, вторая диаграмма представляет количество введенных каждым пользователем справочников.

Активность пользователя

Отчет Активность пользователя предназначен для получения подробной статистики по активности выбранного пользователя (список созданных и измененных документов/справочников/бизнес-процессов/задач). Для формирования отчета перейдите по ссылке Активность пользователя в списке Отчеты администратора.

Основные параметры настройки выведены в шапку отчета. Период установлен по умолчанию (например, Этот месяц). При необходимости измените Период с помощью кнопки .

С помощью кнопки  выберите из списка Пользователя, по которому будет формироваться отчет (например, Администратор).

Для дальнейшей настройки параметров отчета воспользуйтесь кнопкой Настройки. Например, можно определить, по каким видам объектов приложения формировать отчет (Выводить бизнес-процессы, задачи, справочники, документы – необходимо выбрать Да или Нет). По умолчанию данные выводятся по справочникам и документам. Подробнее см. раздел документации Варианты отчетов. По окончании настройки нажмите кнопку Закрыть и сформировать.

Также можно посмотреть результаты отчета в виде диаграмм: количество введенных и измененных документов. Можно изменить период отчета и получить отчет за период с 05.07.2021 по 14.07.2021.

Последние настройки будут сохранены.

Анализ активности подразделений

Отчет Анализ активности подразделений предназначен для получения статистической информации по активности подразделений. В отчете учитывается количество часов работы, количество подключений, количество введенных/измененных документов/справочников, количество проблем и предупреждений при работе подразделений.

Для формирования отчета перейдите по ссылке Анализ активности подразделений в списке Отчеты администратора – Контроль работы пользователей.

Период установлен по умолчанию (например, Этот месяц). При необходимости измените Период с помощью кнопки .

С помощью кнопки  выберите из списка Подразделение, по которому будет формироваться отчет (например, ИТ-служба). Также можно Выбрать несколько подразделений из предложенного списка. После выбора нужного подразделения нажмите кнопку Подобрать и закрыть.

Для дальнейшей настройки параметров отчета воспользуйтесь кнопкой Настройки. Подробнее см. раздел документации Варианты отчетов.

Нажмите кнопку Сформировать. В таблице представлена статистика по выбранным подразделениям, за указанный период.

Также можно посмотреть результаты отчета в виде диаграмм: количество введенных и измененных документов, а также справочников.

Контроль журнала регистрации

Отчет Контроль журнала регистрации содержит список критичных записей журнала регистрации, (записи о проблемах и предупреждениях) сгруппированных по содержанию и отсортированных по частоте возникновения события. Отчет позволяет быстро проанализировать часто возникающие проблемы и принять решения по их устранению, не прибегая к помощи журнала регистрации. Подробнее о журнале регистрации см. раздел документации Настройки приложения.

Для формирования отчета перейдите по ссылке Контроль журнала регистрации в списке Отчеты администратора.

Поле Период выведено в шапку отчета, заполнено по умолчанию (например, Сегодня).

Для настройки параметра Период нажмите кнопку  Выбрать, введите нужный период (например, Эта неделя), затем нажмите кнопку Выбрать. Нажмите кнопку Сформировать.

Продолжительность работы регламентных заданий

Отчет Продолжительность работы регламентных заданий отображает продолжительность работы сеансов регламентных заданий. Позволяет провести анализ загруженности сервера регламентными заданиями, выявить интервалы с пиковыми нагрузками и затем разгрузить эти интервалы.

Для формирования отчета перейдите по ссылке Продолжительность работы регламентных заданий в списке Отчеты администратора.

Параметры (День и Начало периода) выведены в шапку отчета, установлены значения по умолчанию (например, Начало этого дня). При необходимости можно указать свои параметры.

С помощью кнопки Настройки можно изменить параметры отчета. Подробнее см. раздел документации Варианты отчетов. Нажмите кнопку Сформировать. Настройки будут сохранены.

Сведения о регламентном задании

С помощью двойного щелчка мышью по наименованию фонового задания в отчете Продолжительность регламентных заданий можно перейти к просмотру отчета Сведения о регламентном задании.

Можно ознакомиться со статистическими данными по выбранному регламентному заданию:

■ Общая продолжительность;

■ Количество запусков;

■ Количество отмененных заданий;

■ Количество проблем.

Приводятся также сведения о сеансах регламентного задания, их длительности и времени проведения.

С помощью кнопки панели навигации можно Изменить расписание регламентного задания. Подробнее см. раздел документации Регламентные задания.

Дважды щелкните по нужной ячейке в таблице Сеансы регламентного задания, для того чтобы Перейти к журналу регистрации и просмотреть данные о сеансе регламентного задания в журнале регистрации. Подробнее см. раздел документации Настройки приложения.

Изменение учетных записей пользователей

Отчет Изменение учетных записей пользователей позволяет проанализировать динамику изменений различных свойств пользователей приложения за определенный период, основываясь на записях журнала регистрации.

Отчет открывается из списка Отчеты администратора – Контроль работы пользователей.

Необходимость в отчете возникает, если требуется выполнить групповой анализ изменений в настройках входа (имени для входа, видов аутентификации и других).

В отчете по умолчанию выдаются сведения:

■ Имя (для входа)

■ Полное имя пользователя;

■ Недействителен;

■ Пометка удаления;

■ Адрес электронной почты;

■ Вход в приложение разрешен – поле может принимать значение Да, если пользователю разрешен вход в приложение, или значение Нет в обратном случае;

■ Аутентификация стандартная – поле может принимать значение Да или значение Нет, в обратном случае;

■ Аутентификация OpenID – поле может принимать значение Да или значение Нет, в обратном случае;

■ Аутентификация OpenID-Connect – поле может принимать значение Да или значение Нет, в обратном случае;

■ Аутентификация токеном доступа – поле может принимать значение Да или значение Нет, в обратном случае;

■ Аутентификация ОС – поле может принимать значение Да или значение Нет, в обратном случае;

■ Пользователь ОС – имя, с которым пользователь входит в ОС, если пользователь имеет аутентификацию ОС;

■ Имя политики паролей;

■ Запрещено изменять пароль  –  поле может принимать значение Да или значение Нет, в обратном случае;

■ Запрещено восстанавливать – поле может принимать значение Да или значение Нет, в обратном случае;

■ Пароль изменен – поле может принимать значение Да или значение Нет, в обратном случае;

■ Пароль установлен поле может принимать значение Да или значение Нет, в обратном случае;

■ Дата установки пароля;

■ Потребовать смену пароля при входе - поле может принимать значение Да или значение Нет, в обратном случае;

■ Защита от опасных действий - поле может принимать значение Да или значение Нет, в обратном случае;

■ Срок действия не ограничен - поле может принимать значение Да или значение Нет, в обратном случае, н/д – если данных недостаточно;

■ Срок действия – если поле Срок действия не ограничен принимает значение Да, то указывается срок действия данного пароля;  

■ Запретить вход, если не работает более, дн. - поле может принимать значение Да или значение Нет, в обратном случае;

■ Режим запуска;

■ Язык.

Также с помощью кнопки Настройки можно открыть список полей и при необходимости добавить нужные поля в отчет.  Например, можно добавить в отчет поля Роли (только изменения) и Роли. Для этого перейдите в расширенный вид настроек и на вкладке Поля и сортировки выделите поля с помощью флажков. Настройки запоминаются.

Изменение участников групп пользователей (внешних пользователей)

Отчет Изменение участников групп пользователей (внешних пользователей) выводит изменения состава групп пользователей с учетом иерархии за указанный период по событиям журнала регистрации.

Для того чтобы отчет выводил изменения состава групп пользователей включите флажок Регистрировать изменения участников групп пользователей в разделе Администрирование – Настройки пользователей и прав – Пользователи.

Также с помощью кнопки Настройки можно открыть список полей и при необходимости добавить нужные поля в отчет. Подробнее см. раздел документации Варианты отчетов.

Для формирования и настройки отчетов должна быть установлена роль Полные права.

Изменение участников групп доступа

Отчет Изменение участников групп доступа предназначен для отслеживания изменений по событиям журнала регистрации, происходящих с участниками группы доступа. С помощью данного отчета можно узнать, кто был добавлен в группу доступа, кто был удален, а также изменилась ли активность конкретного пользователя внутри группы за указанный период.

Основные параметры настройки выведены в шапку отчета. С помощью кнопки  выберите из списка Участника, по которому будет формироваться отчет, а также нужную группу доступа, например, Пользователи.

Для дальнейшей настройки параметров и полей отчета воспользуйтесь кнопкой Настройки. Подробнее см. раздел документации Варианты отчетов.

Изменение разрешенных значений групп доступа

Отчет Изменение разрешенных значений групп доступа выводит изменения разрешенных значений групп доступа с учетом изменения групп значений за указанный период по событиям журнала регистрации. Отчет позволяет контролировать и анализировать, какие значения были добавлены, изменены или удалены из соответствующих групп доступа в приложении.

Основные параметры настройки выведены в шапку отчета. Для дальнейшей настройки параметров и полей отчета воспользуйтесь кнопкой Настройки. Подробнее см. раздел документации Варианты отчетов.

Изменение ролей профилей

Отчет Изменение ролей профилей выводит изменения ролей профилей с учетом изменения состава ролей в метаданных на указанный период по событиям журнала регистрации.

           

В отчете по умолчанию предоставляются сведения о предыдущих ролях профилей, а также отображаются измененные роли. Также в отчет выдаются сведения:

■ Дата и время изменения – когда произошли изменения с ролями профилей пользователя;

■ Пользователь – имя пользователя, чьи роли профилей были изменены;

■ Действие – отражает были ли роли профилей добавлены, изменены или удалены.

Основные параметры настройки выведены в шапку отчета. Для дальнейшей настройки параметров и полей отчета воспользуйтесь кнопкой Настройки. Подробнее см. раздел документации Варианты отчетов.

Аудит доступа к данным

Журнал доступа к данным позволяет администратору приложения проводить Аудит доступа к определенным данным, для того чтобы узнать, кто и когда их просматривал.

Предварительно требуется настроить доступ к данным, включив флажок Регистрировать доступ к данным (раздел Администрирование - Настройки пользователей и прав - группа Аудит доступа к данным). Затем перейти по ссылке Настройки.

Далее выберите события, которые необходимо отслеживать. Например, для того чтобы администратору узнать кто и когда поменял важные реквизиты ИНН, Договор по умолчанию и КПП у контрагента, нужно предварительно в настройках регистрации событий выбрать объекты метаданных Справочники.Демо:Контрагенты, а в Поле таблицы отметить флажками ИНН, КПП, Договор по умолчанию.

После выполнения данных действий приложение будет автоматически фиксировать информацию кто и когда осуществлял доступ к этим данным и отображать ее красным цветом в Журнале доступа к данным.

Также если таблицы или их поля с настройкой контроля доступа были удалены или переименованы в Конфигураторе приложения, (подробнее см. книгу «1С:Предприятие 8.3. Руководство разработчика».) тогда у администратора появляется текущее дело по актуализации настроек.
