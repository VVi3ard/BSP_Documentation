# Варианты отчетов

Источник: https://infostart.ru/1c/articles/1411756/ (БСП 3.1.4, сверено с 3.1.11)

##### Пользовательская документация

##### Настройка и использование

## ВариантыОтчетов.ОписаниеВарианта(Настройки, Отчет, КлючВарианта)

> 3.1.11: есть, контекст С, вызовов в типовых: 1948

Находит настройки варианта отчета. Используется для настройки размещения. Для использования в ВариантыОтчетовПереопределяемый.НастроитьВариантыОтчетов.

Подсистема "Варианты отчетов". Используете ли Вы ее правильно?

```bsl
Результат = ВариантыОтчетов.ОписаниеВарианта(Настройки, Отчет, КлючВарианта)
```

## ВариантыОтчетов.ОписаниеОтчета(Настройки, Отчет)

> 3.1.11: есть, контекст С, вызовов в типовых: 618

Возвращает настройки указанного отчета. Используется для настройки размещения и общих параметров отчета в ВариантыОтчетовПереопределяемый.НастроитьВариантыОтчетов.

```bsl
Результат = ВариантыОтчетов.ОписаниеОтчета(Настройки, Отчет)
```

## ВариантыОтчетов.НастроитьОтчетВМодулеМенеджера(Настройки, ОтчетМетаданные)

> 3.1.11: есть, контекст С, вызовов в типовых: 306

Вызывает модуль менеджера отчета для заполнения его настроек. Для вызова из процедуры ВариантыОтчетовПереопределяемый.НастроитьВариантыОтчетов.

```bsl
ВариантыОтчетов.НастроитьОтчетВМодулеМенеджера(Настройки, ОтчетМетаданные)
```

## ОтчетыСервер.ПодключитьСхему(Отчет, Контекст, Схема, КлючСхемы)

> 3.1.11: есть, контекст С, вызовов в типовых: 142

Устанавливает отчету переданную схему и на основании нее, инициализирует компоновщик настроек.

```bsl
// В обработчике объекта отчета ПередЗагрузкойНастроекВКомпоновщик компоновщик настроек
// инициализируется на основании схемы из общих макетов:
Если КлючСхемы <> "1" Тогда
    КлючСхемы = "1";
    Схема = ПолучитьОбщийМакет("МояОбщаяСхемаКомпоновки");
    ОтчетыСервер.ПодключитьСхему(ЭтотОбъект, Контекст, Схема, КлючСхемы);
КонецЕсли;

//
Процедура ПередЗагрузкойНастроекВКомпоновщик(Контекст, КлючСхемы,
                                             КлючВарианта, НовыеНастройкиКД,
                                             НовыеПользовательскиеНастройкиКД) Экспорт

    Если ТипЗнч(Контекст) = Тип("ФормаКлиентскогоПриложения") Тогда
        НастроитьПараметрыОтчетаПоВариантуОтчета(Контекст.НастройкиОтчета, НовыеНастройкиКД, НовыеПользовательскиеНастройкиКД);
        ОтчетыСервер.ПодключитьСхему(ЭтотОбъект, Контекст, СхемаКомпоновкиДанных, КлючСхемы);
    КонецЕсли;

КонецПроцедуры
```
