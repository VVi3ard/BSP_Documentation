# Даты

Источник: https://infostart.ru/1c/articles/1398340/ (БСП 3.1.4, сверено с 3.1.11)

## ОбщегоНазначенияКлиент.ДатаСеанса()

> 3.1.11: есть, контекст К, вызовов в типовых: 1104

Возвращает текущую дату, приведенную к часовому поясу сеанса. Предназначена для использования вместо функции ТекущаяДата() в клиентском коде в тех случаях, когда нет возможности перевести выполнение алгоритма в серверный код.

О времени и 1С

```bsl
Результат = ОбщегоНазначенияКлиент.ДатаСеанса()
```

## ОбщегоНазначения.ТекущаяДатаПользователя(ИмяПользователя)

> 3.1.11: есть, контекст С, вызовов в типовых: 210

Возвращает значение настройки рабочей даты для пользователя или текущей даты сеанса, если рабочая дата пользователя не задана.

```bsl
Результат = ОбщегоНазначения.ТекущаяДатаПользователя()
```

## ОбщегоНазначения.РабочаяДатаПользователя(ИмяПользователя)

> 3.1.11: есть, контекст С, вызовов в типовых: 35

Возвращает значение настройки рабочей даты для пользователя.

```bsl
Результат = ОбщегоНазначения.РабочаяДатаПользователя(ИмяПользователя)
```

## ОбщегоНазначенияКлиент.ДатаУниверсальная()

> 3.1.11: есть, контекст К, вызовов в типовых: 26

Возвращает универсальную дату сеанса, получаемую из текущей даты сеанса.

```bsl
Результат = ОбщегоНазначенияКлиент.ДатаУниверсальная()
```

## ОбщегоНазначения.ИнтервалВремениСтрокой(ВремяНачала, ВремяОкончания)

> 3.1.11: есть, контекст С, вызовов в типовых: 15

Возвращает строковое представление интервала между переданными датами или относительно переданной даты и текущей даты сеанса.

```bsl
Результат = ОбщегоНазначения.ИнтервалВремениСтрокой(ВремяНачала, ВремяОкончания)

// Адресный классификатор был загружен 24 дня назад.
РазностьДней = ОбщегоНазначения.ИнтервалВремениСтрокой(ВремяНачала, ВремяОкончания);
Сообщенеие = НСтр("ru = 'Адресный классификатор был загружен %1 назад.'");
Представление = СтроковыеФункцииКлиентСервер.ПодставитьПараметрыВСтроку(Сообщенеие, РазностьДней);
```

## ОбщегоНазначенияКлиент.ПредставлениеЛокальнойДатыСоСмещением(ЛокальнаяДата)

> 3.1.11: есть, контекст К, вызовов в типовых: 2

Преобразует локальную дату к формату "YYYY-MM-DDThh:mm:ssTZD"

```bsl
Результат = ОбщегоНазначенияКлиент.ПредставлениеЛокальнойДатыСоСмещением(ЛокальнаяДата)
```
