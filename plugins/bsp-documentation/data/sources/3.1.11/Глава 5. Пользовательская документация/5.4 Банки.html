Оглавление

5.4 Банки

Приложение позволяет загружать Справочник БИК с сайта 1С. Справочник БИК содержит основные сведения о кредитных организациях и УФК. При обновлении учитывается ситуация, когда участник расчетов прекратил деятельность (в карточке такого участника расчетов включен флажок Деятельность прекращена). Предусмотрены необходимые данные для международных платежей.

Обновление Справочника БИК выполняется автоматически. Также предусмотрено и обновление вручную. В случае, если по каким-то причинам обновление не выполнялось длительное время, выводится соответствующее предупреждение.

Справочник БИК

Справочник БИК можно открыть с помощью команды меню функций раздела Справочники. Участники расчетов сгруппированы по регионам РФ.

После запуска приложения производится проверка актуальности Справочника БИК и при необходимости обновления выводится сообщение с предложением Обновить классификатор. Перейдите по ссылке, для того чтобы начать загрузку.

Также можно Загрузить классификатор в списке Справочник БИК с помощью кнопки панели навигации.

 Выберите вариант загрузки с помощью переключателя:

■ Загрузить обновление через Интернет (возможно, понадобится ввести регистрационные данные пользовательского сайта 1С);

■ Загрузить обновления из файла. Укажите путь к файлу на устройстве, например, E:\Классификаторы\classifiers.zip. Получить файл со Справочником БИК можно со страницы релиза приложения (для доступа потребуются логин и пароль от ИТС).

Нажмите кнопку Далее, следуйте инструкциям приложения.

Подробнее см. раздел документации Работа с классификаторами Библиотеки интернет-поддержки пользователей https://its.1c.ru/db/uisldoc#content:307:hdoc .

После успешной загрузки приложение выводит соответствующее сообщение. Нажмите кнопку Закрыть, для того чтобы продолжить работу в приложении.

При повторной загрузке перезаписываются только измененные сведения участников расчетов. При этом если был изменен БИК или Корр. счет, то будет создан новый элемент списка. Если были изменены другие поля, то они при повторной загрузке будут перезаписаны.

Участники расчетов, прекратившие деятельность:

■ В списке Справочник БИК и в окне выбора становятся неактивными;

■ В карточке такого участника расчетов включен флажок Деятельность прекращена. При обновлении классификатора приложение производит проверку сведений об участниках расчетов, и флажок проставляется автоматически. Если до обновления классификатора стало известно, что деятельность участника расчетов прекращена, то можно включить флажок вручную;

■ Автоматически скрываются в окне выбора. Для отображения таких участников расчетов необходимо воспользоваться командой меню Еще.

Для автоматической загрузки Справочника БИК по определенному расписанию используется регламентное задание Обновление классификаторов. Для его работы потребуется подключить в приложении Интернет-поддержку (раздел Администрирование – Интернет-поддержка и сервисы). Подробнее о работе с регламентными заданиями см. раздел документации Регламентные задания.

Следует учитывать, что обновление выполняется через Интернет, поэтому может потребоваться настройка прокси-сервера по команде Демо: Мои настройки на странице Главное (подробнее см. раздел документации Настройки приложения). Подробнее о настройке прокси-сервера см. раздел документации Получение файлов из интернета.

Использование справочника БИК

Если в приложении загружается Справочник БИК и ведется список банковских счетов, то при заполнении различных документов эту информацию можно выбирать из списков, что снижает трудоемкость ввода информации и сокращает количество ошибок. Для выбора информации из данных списков потребуются права на чтение этих списков.

Список банковских счетов предназначен для хранения сведений о банковских счетах юридических и физических лиц, как собственных, так и сторонних. При использовании списка банковских счетов заполнение поля Банковский счет в различных документах сводится к выбору из списка нужного счета, что существенно облегчает ввод и снижает количество ошибок в документах и отчетности.

При вводе банковского счета введите данные участника расчетов. Как правило, достаточно ввести БИК участника расчетов, для того чтобы найти его в списке.

Особенности работы с банками в разных моделях использования приложения

В приложении в Интернете загрузка Справочника БИК осуществляется автоматически и ручные изменения в нем не предусмотрены.

При работе в автономном рабочем месте классификатор банков загружается при синхронизации с приложением в Интернете.

В приложении в Интернете и при работе в автономном рабочем месте справочник БИК отдельно не выводится, его можно открыть во время работы с банковскими счетами.
