5.67 Формат параметров

При работе в приложении бывают ситуации, когда пользователю требуется выводить число или дату в каком-либо особенном виде, например, можно отформатировать дату, указав месяц прописью, или получить форматированное число, с двумя знаками после запятой. Для этого можно применить Формат параметров. Для форматирования значений в приложении предназначено окно – Конструктор форматной строки, которое открывается при подготовке рассылки отчетов, шаблонов сообщений, печатных форм и в дополнительных реквизитах. В Конструкторе форматной строки, в зависимости от выбранного типа параметра, можно вывести отличный от стандартного типы (Число, Дата, Булево).

Формат даты                 

ДЛФ - локальный формат даты. Указывается вариант отображения частей даты. Рекомендуется использовать данный формат, т.к. локальный формат для чисел и дат зависит от языка. Если выбрать нужный язык из списка, то локальный формат числа и даты будет указываться в соответствии с выбранным языком. В ином случае – будет использоваться текущий язык.

● D - дата (цифрами);

● DD - длинная дата (месяц прописью);

● T - полное время, дата может объединяться со временем;

● DT - дата время.

Пример для параметра [Дата]

Исходное значение

Результат

ДЛФ = DD

10.10.2022 18:10:05

10 октября 2022 г.

ДЛФ = DDT

10.10.2022 18:10:05

10 октября 2022 г. 18:10:05

ДЛФ = D

10.10.2022 18:10:05

10.10.2022

ДЛФ = T

10.10.2022 18:10:05

18:10:05

                       

ДФ – задает произвольный шаблон даты с помощью подстановочных символов.

● d - день месяца (цифрами) без лидирующего нуля;

● dd - день месяца (цифрами) с лидирующим нулем;

● ddd - краткое название дня недели;

● dddd - полное название дня недели;

● M - номер месяца (цифрами) без лидирующего нуля;

● MM - номер месяца (цифрами) с лидирующим нулем;

● MMM - краткое название месяца;

● MMMM - полное название месяца;

● q - номер квартала в году;

● y - номер года без века и лидирующего нуля;

● yy - номер года без века с лидирующим нулем;

● yyyy - номер года с веком;

● h - час в 12 часовом варианте без лидирующих нулей;

● hh - час в 12 часовом варианте с лидирующим нулем;

● H - час в 24 часовом варианте без лидирующих нулей;

● HH - час в 24 часовом варианте с лидирующим нулем;

● m - минута без лидирующего нуля;

● mm - минута с лидирующим нулем;

● s - секунда без лидирующего нуля;

● ss - секунда с лидирующим нулем;

● tt - отображение половины дня AM/PM

Пример для параметра [Дата документа]

Исходное значение

Результат

ДФ = d.M.yy

01.01.2022 18:10:05

1.1.22

ДФ = HH:mm:ss

01.01.2022 18:10:05

18:10:05

ДФ = yyyy-MM-dd

2022-10-10

Формат параметров в рассылке отчетов

При создании Рассылки отчетов заходим во вкладку Доставка, в Теме письма укажем нужную нам функцию формата Даты с помощью Параметра форматной строки, также укажем Формат даты рассылки. (При желании прописать формулу можно и вручную. Это не повлияет на результат) см. раздел Администрирование – Печатные формы, отчеты, обработки – Рассылки отчетов.

Формат параметров в макетах печатных форм

Создадим новый Макет печати с помощью Конструктора печатных форм, в поле списка доступных реквизитов укажем нужный формат, нажмем на кнопку  (настройка формата поля) и выберем формат Процента оплаты, отличный от стандартного см. раздел Администрирование – Печатные формы, отчеты, обработки – Макеты печатных форм.

Формат параметров в шаблонах сообщений

Создадим новый Шаблон сообщений. Выберем нужный Параметр и зададим формат отображения реквизита (вызовем контекстное меню) см. раздел Администрирование – Органайзер – Заметки, напоминания, анкетирование, шаблоны сообщений – Шаблоны сообщений.

Формат параметров в дополнительных реквизитах

Создадим Дополнительные реквизиты Срок оплаты и Согласован с клиентом (да/нет) для документа Счет на оплату покупателю. Далее, применим соответствующие параметры формата для типа Даты и Булево. Включить возможность создавать дополнительные реквизиты и сведения и настроить их можно в разделе Администрирование — Общие настройки.
