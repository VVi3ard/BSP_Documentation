# Многофайловая документация БСП 3.1.11

## Цель

Перевести MCP-сервер с одного неполного HTML на полную многофайловую документацию БСП 3.1.11 и пересоздать индекс совместимости 3.1.

## Отбор файлов

Корпус строится рекурсивно из `data/sources/3.1.11`. Обычные HTML-страницы включаются всегда. `index.html` включается только тогда, когда в его каталоге и подкаталогах нет других HTML-страниц; это сохраняет самостоятельные крупные главы и исключает сводные дубли детализированных страниц.

## Разбиение и метаданные

Каждая страница получает иерархию из относительного пути каталогов. Внутренние `h1`–`h5` дополняют эту иерархию без повторения одинакового заголовка. Крупные разделы делятся по блочным элементам с максимальным размером 8000 символов. Каждый фрагмент хранит относительный путь исходной страницы, HTML-якорь, заголовок, полный breadcrumb, текст, номер части и признаки рекомендаций/предупреждений.

## Версии

Полная версия источника — `3.1.11`; четвертая компонента поставки игнорируется. Все запросы `3.1.x.x` используют индекс семейства `3.1`, как и раньше.

## Индекс и поиск

Схема SQLite расширяется полем `source_path`. Индекс `data/indexes/3.1/index.sqlite` пересоздается атомарно с embeddings `qwen/qwen3-embedding-8b`; старый индекс заменяется только после успешного завершения всех запросов OpenRouter.

## Проверка

Автотесты покрывают отбор `index.html`, файловую иерархию, отсутствие повторов заголовков, сохранение source path и построение индекса из каталога. После переиндексации обязательный запрос `Как программно получить присоединенный файл?` должен вернуть страницу конкретного программного интерфейса в первой тройке.
