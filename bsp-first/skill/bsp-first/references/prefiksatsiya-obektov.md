# Префиксация объектов

Источник: https://infostart.ru/1c/articles/1411756/ (БСП 3.1.4, сверено с 3.1.11)

##### Пользовательская документация

##### Настройка и использование

## ПрефиксацияОбъектовКлиентСервер.НомерНаПечать(НомерОбъекта, УдалитьПрефиксИнформационнойБазы, УдалитьПользовательскийПрефикс)

> 3.1.11: есть, контекст КС, вызовов в типовых: 1007

Получает номер документа для вывода на печать; из номера удаляются префиксы и лидирующие нули.

```bsl
Результат = ПрефиксацияОбъектовКлиентСервер.НомерНаПечать(НомерОбъекта, УдалитьПрефиксИнформационнойБазы, УдалитьПользовательскийПрефикс)

//
НомерДокумента = ПрефиксацияОбъектовКлиентСервер.НомерНаПечать(Реквизиты.Номер, Истина, Ложь);
```

## ПрефиксацияОбъектовКлиентСервер.УдалитьЛидирующиеНулиИзНомераОбъекта(НомерОбъекта)

> 3.1.11: есть, контекст КС, вызовов в типовых: 24

Удаляет лидирующие нули из номера объекта.

```bsl
Результат = ПрефиксацияОбъектовКлиентСервер.УдалитьЛидирующиеНулиИзНомераОбъекта(НомерОбъекта)
```
