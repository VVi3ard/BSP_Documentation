5.3 Базовая функциональность (Прочие сервисные возможности)

Приложение предоставляет ряд сервисных возможностей:

■ публикация приложения;

■ подтверждение закрытия приложения;

■ предупреждения при закрытии приложения.

Публикация приложения

Настройки публикации приложения предназначены для сценариев, связанных с формированием ссылок на списки и документы приложения в зависимости от вида подключения пользователей к приложению. Например, если такой адрес включить в рассылку писем, то из письма за одно нажатие можно перейти к окну списка или документа в самом приложении.

Адреса публикации предназначены для формирования ссылок на списки и документы приложения для пользователей:

■ Адрес в Интернете – введите адрес приложения в интернете, например, http://myserver.com;

■ Локальный адрес – введите локальный адрес приложения, например, http://localnet/mydatabase.

Производительность

В клиент-серверном варианте работы приложения можно ускорить некоторые длительные операции, настроив их выполнение в несколько потоков: например, загрузку адресного классификатора. Для этого в разделе Администрирование – Общие настройки – Производительность можно установить максимальное количество одновременно работающих потоков.

Рекомендуемое значение:

■ для штатной работы до 50–75% от количества ядер, доступных кластеру серверов;

■ для форсированного выполнения в период минимальной активности пользователей – равно количеству ядер, доступных кластеру серверов.

В клиент-серверном варианте работы приложения при использовании кластера серверов для корректной работы отдельных функций приложения в разделе Администрирование – Общие настройки – Производительность необходимо ввести общий сетевой путь к Каталогу временных файлов. Тем самым, это обеспечит доступ со всех серверов кластера к этому каталогу, например, для многопоточной загрузки адресного классификатора.

Подтверждение закрытия приложения

Для предотвращения случайного закрытия главного окна приложения перед завершением работы предусмотрен запрос подтверждения. Для подтверждения нажмите кнопку Завершить работу, если попытка выхода из приложения была сделана случайно, нажмите кнопку Продолжить работу.

Запрос подтверждения завершения работы можно включить (рекомендуется) или выключить в персональных настройках приложения.

Для этого в разделе Главное выполните команду Демо: Мои настройки, на вкладке Главное выключите или включите флажок Запрашивать подтверждение при завершении приложения. По умолчанию флажок включен.

При завершении работы приложение позволяет выводить предупреждения (например, может выводиться приглашение выполнить резервное копирование приложения перед выходом или открыть список редактируемых файлов, которые необходимо поместить в приложение перед выходом).

Предупреждения при закрытии приложения могут быть от следующих подсистем:

■ Обновление конфигурации;

■ Резервное копирование;

■ Синхронизация данных с приложением в Интернете (АРМ);

■ Работа с файлами – список занятых файлов.

В этом случае перед завершением работы приложения будет открыто окно со списком предупреждений и запросом подтверждения завершения работы.

Нажмите кнопку Продолжить работу, в этом случае в нижней части окна выводится сообщение со ссылкой Выполнить дополнительные действия и завершить работу.

Нажмите на сообщение, для того чтобы просмотреть список дополнительных действий.

В случае если предупреждение одно, то окно предупреждения может иметь другой вид. Для того чтобы просмотреть список файлов, занятых для редактирования, нажмите кнопку Продолжить работу, в сообщении в нижней части окна перейдите по ссылке Открыть список редактируемых файлов. Настройку этого предупреждения можно выполнить по команде Демо: Мои настройки, выбрав вкладку Работа с файлами.

Расширения

В приложении предусмотрена возможность администрирования расширений конфигурации. С помощью расширений можно подключать новые разделы командного интерфейса, отчеты и обработки в дополнение к предусмотренным в приложении. Данная технология позволяет добавлять новые возможности в приложение без ее прямого изменения, упрощает ее дальнейшее сопровождение. Подробнее см. документацию на сайте.

Для того чтобы установить расширение конфигурации, в разделе Администрирование – Печатные формы, отчеты и обработки перейдите по ссылке Расширения.

Важно! Требуется лицензия ПРОФ или КОРП (недоступно в базовой версии).

В списке можно:

■ С помощью флажка в первой колонке включить или выключить установленные расширения. Также это можно сделать с помощью кнопки панели навигации .Если расширение хранит данные в приложении, то при выключении приложение выводит предупреждение. Необходимо учитывать, что отключение расширения может сделать недоступными данные, которые хранились в приложении и относились к расширению, поэтому после отключения расширения будет невозможно изменить эту часть данных. Для подтверждения нажмите Отключить.

■ С помощью флажка в колонке или с помощью кнопки панели навигации  Передавать расширения в подчиненные узлы РИБ. По умолчанию флажок выключен, т. е. расширения не передаются в подчиненные узлы.

■ включить Безопасный режим  – у добавленного расширения флажок включается автоматически, администратор может выключить флажок или указать имя профиля безопасности.

■ Установить ответственного  - с помощью кнопки панели навигации можно установить ответственного за расширение.

В поле Комментарий можно указать любую дополнительную информацию для выбранного расширения.

Для того чтобы установить расширение конфигурации, нажмите кнопку Добавить из файла. Перед установкой расширений приложение выводит предупреждение. Если расширение получено из надежного источника, нажмите кнопку Продолжить.

Укажите путь к файлу  с расширением конфигурации формата .cfe.

Приложение добавляет расширение. Это занимает некоторое время.

После добавления выводится список Расширения. У добавленного расширения автоматически включается флажок Безопасный режим. Администратор может выключить флажок или указать имя профиля безопасности.

В списке с помощью значков отражается состояние расширений. Расширение может быть:

■  – подключено;

■  – не подключено;

■  – установлено (после перезапуска будет либо подключено, либо не подключено).

После добавления расширения в список выводится предупреждение о необходимости перезапустить приложение. Для того чтобы продолжить работу с учетом сделанных изменений, нажмите ссылку перезапустить. В приложении в Интернете этой ссылки нет, т. к. для неразделенных пользователей, например, для администраторов сервиса, при входе в область данных расширения области данных не подключаются, а остается подключенным тот состав расширений, который был до входа в область данных, т. е. при запуске сеанса.

Расширения могут содержать роли пользователей, в том числе стандартные (имя оканчивается на Общие права, Базовые права или Полные права). Стандартные роли расширений автоматически добавляются в соответствующие профили групп доступа при добавлении расширений и удаляются при их удалении (и отключении). См. также раздел документации Управление доступом.

После перезапуска расширение будет подключено к приложении, и список установленных расширений примет обычный вид.

Для удобства управления большим количеством расширений в списке можно производить действия (обновить, выгрузить в каталог на компьютере или удалить) с несколькими выделенными расширениями.

Если расширение больше не нужно в приложении, выделите его, нажмите кнопку Удалить.

Если расширение хранит данные в приложении, то при удалении они будут безвозвратно утеряны, в этом случае перед удалением приложение выводит предупреждение. Рекомендуется перед удалением расширения произвести резервное копирование приложения.

Удаленные расширения больше не показываются в списке. Выводится предупреждение о необходимости перезапустить приложение. Удаление расширения не отключает его. Все сеансы, запущенные после добавления расширения и до его удаления, продолжат работу с удаленным расширением. В новых сеансах удаленное расширение более не подключится.

Обновить из файла – нажмите кнопку для установки новой версии расширения. Также следует использовать эту возможность для возврата к предыдущей версии, если новая версия содержит проблему (однако не рекомендуется устанавливать расширение меньшей версии, т. к. это может привести к потере сделанных настроек). Укажите путь к файлу с расширением на компьютер.

Если обновить расширение на новую версию, в которой изменено его имя, то все прежние настройки этого расширения будут сохранены, например, созданные варианты отчетов. Кроме того, при случайном удалении и повторном добавлении этого же расширения в приложение через короткий промежуток времени также возможно продолжить работу без потери его настроек. Приложение при попытке обновления на расширение с другим именем выводит сообщение, подтвердить свое действие необходимо с помощью кнопки Заменить.

Если при запуске расширение не удалось подключить к приложению, тогда выводится сообщение о проблеме.

В контекстном меню по правой кнопке мыши или в меню Еще списка Расширения доступны команды:

■ Обновить – список расширений не является динамическим, для того чтобы учесть недавно произошедшие изменения, воспользуйтесь этой командой.

■ Сохранить как – воспользуйтесь командой, для того чтобы сохранить расширение на компьютере или другом носителе. Укажите путь для сохранения файла.

■ Проверить возможность применения всех расширений – воспользуйтесь командой, для того чтобы проверить добавленные расширения, возможно они добавлены уже давно и уже не актуальны.

■ в меню Еще предусмотрена команда Установленные исправления (патчи). Можно воспользоваться ею, если получено расширение, содержащее исправление (патч) для его установки в приложение. Открывается список, в котором можно просмотреть уже установленные исправления и с помощью кнопки панели навигации Установить исправление. Подробнее см. раздел документации Обновление конфигурации.

Базовые роли приложения

В состав приложения входят следующие базовые роли:

Роль

Краткое описание

Администратор системы

Права на выполнение административных функций.

Администрирование

Права на выполнение административных функций (работа в Конфигураторе), просмотр списка активных пользователей и т.п.

Базовые права БСП

Назначается всем пользователям и дает права доступа к документам, спискам и функциям приложения, которые должны быть всегда доступны всем пользователям. Также дает право на чтение классификаторов (Адресный классификатор, Валюты, Банки, Производственные календари).

Базовые права внешних пользователей БСП

Назначается всем внешним пользователям и дает права доступа к документам, спискам и функциям приложения, которые должны быть всегда доступны всем пользователям. Также дает право на чтение классификаторов (Адресный классификатор, Валюты, Банки, Производственные календари).

Вывод на принтер, в файл, в буфер обмена

Дает право выводить информацию на печать, сохранять в файл, копировать в буфер обмена.

Запуск Automation

Служебная роль, назначается служебному пользователю. Дает право работать с приложением с помощью технологии Automation.

Запуск веб-клиента

Дает возможность запускать приложение в веб-клиенте.

Запуск внешнего соединения

Служебная роль, назначается служебному пользователю. Дает право работать с приложением с помощью COM-соединения. Например, при подключении посредством COM из одного приложения ко второму, во втором приложении необходимо завести служебного пользователя с установленной ролью Запуск внешнего соединения, а само подключение – выполнять от имени этого пользователя.

Запуск мобильного клиента

Дает возможность запускать приложение в мобильном клиенте.

Запуск толстого клиента

Дает возможность запускать приложение в толстом клиенте.

Запуск тонкого клиента

Дает возможность запускать приложение в тонком клиенте.

Интерактивное открытие внешних отчетов и обработок

Дает право на интерактивное открытие внешних отчетов и обработок.

Обновление конфигурации базы данных

Дает право на обновление конфигурации базы данных.

Полные права

Дает право на неограниченный доступ ко всем данным приложения. Содержит все права доступа, кроме права интерактивного удаления. В многопользовательских приложениях применяется для администрирования, в частности для настройки приложения и удаления помеченных объектов. В однопользовательских приложениях применяется для «обычной» работы с приложением.

Просмотр журнала регистрации

Дает право на просмотр журнала регистрации.

Режим технического специалиста

Дает право на использование в главном меню команды Функции для технического специалиста. Роль рекомендуется назначать только администраторам приложения.

Сохранение данных пользователя

Дает право на сохранение настроек пользователя в приложении. Например, настроек отчетов, форм, персональных настроек и т.д. Роль рекомендуется назначать всем пользователям приложения, кроме внешних.

Удаленный доступ (Базовая функциональность)

Для неинтерактивного взаимодействия других приложений или сервисов с приложением через веб-сервис InterfaceVersion (в частности, для синхронизации данных с другими приложениями через веб-сервис).
