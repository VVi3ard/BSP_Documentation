# Сценарий разработки с БСП

Используйте plugin прогрессивно: в контекст попадает только необходимая информация.

## 1. Найти API

Определите версию БСП через `detect_bsp_version`. Для задачи разработки вызовите `discover_bsp_api_sections`, затем изучите одну выбранную подсистему через `get_bsp_api_section_map`.

## 2. Проверить метод

Ищите только внутри выбранной группы:

```text
search_bsp(version, query, mode="development", subsystem, api_group)
```

Для extension callbacks используйте `mode="override"`. Перед написанием вызова обязательно получите `get_bsp_section`.

## 3. Найти практический пример

Вызовите `get_bsp_demo_location(version)` и найдите в возвращённом каталоге полное имя метода, например:

```text
РаботаСФайлами.ДобавитьФайл
```

Читайте всю процедуру, содержащую вызов, а не только найденную строку. В UI-сценарии проследите:

- команду формы и обработчик;
- callback из `ОписаниеОповещения`;
- клиент-серверные переходы;
- вызываемые процедуры общих модулей;
- связанные файлы управляемой формы.

Демо может содержать специфичную подготовку. Используйте его для понимания потока и адаптируйте реализацию к целевой конфигурации.
