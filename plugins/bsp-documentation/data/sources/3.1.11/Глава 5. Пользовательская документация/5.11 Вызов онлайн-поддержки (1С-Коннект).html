5.11 Вызов онлайн-поддержки (1С-Коннект)

Онлайн-поддержка (1С-коннект) – это сервис для комплексной поддержки пользователя.

Приложение предоставляет возможность пользователям инфраструктуры 1С-Коннект запускать приложение прямо с Начальной страницы с помощью кнопки быстрого запуска и мгновенно связаться со специалистом поддержки обслуживающего Партнера или Вендора.

Настройка приложения

Для того чтобы использовать кнопку запуска онлайн-поддержки в приложении, включите флажок Онлайн-поддержка в разделе Администрирование – Интернет-поддержка и сервисы – Онлайн-поддержка. По умолчанию флажок выключен.

После этого становится доступной ссылка Настройка онлайн-поддержки. С помощью ссылки можно настроить параметры запуска онлайн-поддержки. Подробнее см. раздел Настройка онлайн-поддержки.

Настройка онлайн-поддержки

Перед тем как использовать онлайн-поддержку, необходимо произвести настройки. Настройки хранятся для каждого пользователя с привязкой к рабочему месту. Воспользуйтесь ссылкой Настройка онлайн-поддержки на вкладке Главное в персональных настройках приложения, которые можно открыть по команде Демо: Мои настройки в разделе Главное.

Для настройки администратору также можно перейти по ссылке Настройка онлайн-поддержки в разделе Администрирование – Интернет-поддержка и сервисы – Онлайн-поддержка.

Запуск одного и того же приложения под веб-клиентом и тонким клиентом потребует две процедуры настройки.

Для настройки и использования онлайн-поддержки необходимо скачать исполняемый файл с сайта компании «1С-Коннект» https://1c-connect.com. Перейдите по гиперссылке Скачать приложение для скачивания приложения в браузере, установленном по умолчанию. Полученный архив распакуйте в удобный для вас каталог на компьютере. Прямая ссылка на архив приложения:

https://1c-connect.com/media/uploads/distribs/1c-connectsfx.zip.

Также необходимо зарегистрироваться в качестве пользователя (получить аккаунт) на сайте https://1c-connect.com. Для этого воспользуйтесь гиперссылкой Зарегистрироваться в сервисе онлайн-поддержки (1С-Коннект).

После скачивания приложения и прохождения регистрации (получения аккаунта) на сайте продукта можно перейти к основным настройкам.

Для того чтобы вывести кнопку запуска приложения на начальную страницу приложения, включите флажок Отображать кнопку запуска приложения для соединения со специалистом онлайн-поддержки на начальной странице. После этого становятся доступными остальные настройки.

С помощью кнопки  Выбрать укажите Путь к исполняемому файлу приложения. Если при запуске файл по указанному пути не будет найден, то приложение предложит указать его повторно. Скачать приложение необходимо с помощью гиперссылки с сайта продукта.

Для того чтобы приложение автоматически запускалась с аккаунтом пользователя, включите флажок Подставлять логин и пароль при запуске приложения. После этого введите Логин и Пароль (данные авторизации пользователя на сайте) в поля, которые становятся доступными. Если данные не заполнены или заполнены неверно, приложение предложит ввести логин и пароль повторно при запуске.

Нажмите Сохранить, для того чтобы внесенные изменения вступили в силу. После этого ссылка Связаться со специалистом онлайн-поддержки станет доступной на начальной странице. Подробнее см. раздел Работа с онлайн-поддержкой.

Для удобства работы с приложением выведены гиперссылки на сайт компании «1С-Коннект» для получения поддержки. Для того чтобы ознакомиться с требованиями к компьютеру и списком необходимых настроек, перейдите по гиперссылке Технические требования.

Работа с онлайн-поддержкой

Для мгновенного соединения со специалистом поддержки воспользуйтесь ссылкой Связаться со специалистом онлайн-поддержки на Начальной странице. Для того чтобы ссылка стала доступной, необходимо произвести настройки. Имеется также возможность автоматического ввода данных регистрации при нажатии кнопки, в этом случае окно приложения открывается сразу. Подробнее см. разделы Настройка приложения и Настройка онлайн-поддержки.
