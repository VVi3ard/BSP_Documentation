Выгрузка объектов в файлы

Подсистема Выгрузка объектов в файлы предназначена для выгрузки объектов на основе настраиваемых макетов выгрузки. Список макетов выгрузки задается индивидуально для каждого объекта в разделе Администрирование - Печатные формы, отчеты и обработки - Макеты файлов выгрузки. Для создания макетов выгрузки используется визуальный редактор табличных макетов печатных форм. В макет можно включить любое поле или табличную часть в нужном порядке, указать формат формируемого файла: DBF, XML, JSON, HTML, TXT, XLS, XLSX или MXL. Работа подсистемы возможна только при совместном использовании подсистемы Печать.

Настройка

Необходимо принять решение по поводу состава объектов конфигурации (справочников, документов), которые требуется выгружать в файлы и подключить их к подсистеме Печать, если они не подключены (см. Подключение объектов конфигурации). Для возможности формирования выгрузки справочников и документов не нужно выполнять никаких действий по настройке команд. Команды выгрузки автоматически выводятся в списках и карточках объектов, для которых пользователем созданы макеты выгрузки.
