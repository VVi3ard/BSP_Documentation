# Выгрузка документации БСП 3.1.11 в очищенный HTML

## Цель

Выгрузить авторизованную документацию с `https://its.1c.ru/db/bsp3111doc` в
локальный набор очищенных HTML-страниц. Результат должен сохранять иерархию
оглавления, изображения, таблицы, фрагменты кода, якоря и переходы между
разделами, но не содержать интерфейс сайта 1С:ИТС.

Каталог результата:

`bsp-docs-mcp/data/sources/3.1.11/`

Существующий файл
`bsp-docs-mcp/data/sources/3.1.11.155/Документация.html` не изменяется.

## Источник и авторизация

Парсер начинает работу со страницы `https://its.1c.ru/db/bsp3111doc` и
использует уже авторизованную сессию встроенного браузера Codex. Парсер не
извлекает, не выводит и не сохраняет логин, пароль или cookies.

Если страница документации вместо содержимого показывает форму входа или
сообщение об ограничении доступа, выгрузка завершается с явной ошибкой.

## Структура результата

Каждый элемент дерева оглавления получает каталог с русским названием и файл
`index.html`. Иерархия каталогов повторяет иерархию оглавления. Недопустимые для
Windows символы заменяются безопасными, завершающие точки и пробелы удаляются.
При совпадении имён к каталогу добавляется стабильный идентификатор страницы.

В корне результата создаются:

- `index.html` — локальное оглавление всей документации;
- `assets/` — изображения и другие локально используемые ресурсы;
- `manifest.json` — соответствие исходных URL, идентификаторов и локальных путей;
- `export-errors.json` — ошибки отдельных страниц и ресурсов, если они возникли.

## Обход документации

Полное дерево извлекается из оглавления авторизованной страницы. В очередь
выгрузки попадают только URL документации `bsp3111doc`; повторяющиеся URL и
якорные ссылки не создают дубликаты страниц. Внутристатейные якоря сохраняются
как якоря соответствующей локальной страницы.

Повторный запуск использует `manifest.json`: уже успешно сохранённые страницы
можно пропустить, а отсутствующие или ошибочные — загрузить повторно. Для
сервера применяется последовательный либо ограниченный по частоте обход без
агрессивного параллелизма.

## Очистка и преобразование HTML

Из исходной страницы берётся содержимое документации во вложенном документе.
Удаляются навигация и профиль 1С:ИТС, отзывы, избранное, поиск, рекламные блоки,
аналитика и скрипты сайта. Сохраняются семантические элементы статьи, включая
заголовки, абзацы, списки, таблицы, изображения, примечания, предупреждения,
ссылки и форматированные фрагменты кода.

Каждая локальная страница получает минимальный общий CSS для читаемого
автономного просмотра и навигационные ссылки на родительский раздел и корневое
оглавление.

Внутренние ссылки на `bsp3111doc` переписываются в относительные локальные
пути. Ссылки на материалы вне этой базы остаются абсолютными внешними ссылками.
Изображения и другие необходимые ресурсы скачиваются один раз, получают
стабильные имена и подключаются относительными путями из `assets/`.

## Ошибки и восстановление

Ошибки отдельной страницы или ресурса записываются в `export-errors.json` с
исходным URL и причиной. Они не маскируются пустым HTML. После завершения
парсер возвращает ненулевой код, если остались ошибки страниц или битые
внутренние ссылки.

Временные файлы записываются отдельно и атомарно переименовываются после
успешной обработки, чтобы прерванный запуск не оставлял готовые страницы
частично записанными.

## Проверка результата

Автоматическая проверка должна подтвердить:

- наличие корневого оглавления и всех страниц из манифеста;
- отсутствие форм входа и сообщений об ограничении доступа в сохранённом HTML;
- разрешимость всех локальных ссылок, якорей и ресурсов;
- уникальность локальных путей;
- корректное UTF-8-кодирование русских заголовков и имён каталогов;
- сохранение репрезентативных таблиц, блоков кода и изображений.

Дополнительно выполняется выборочная визуальная проверка корневого оглавления,
обычной статьи, страницы с таблицей и страницы с изображениями.

## Границы задачи

Выгружается только документация `bsp3111doc` версии 3.1.11. Материалы других
баз 1С:ИТС не копируются. Полная визуальная копия оболочки 1С:ИТС, автономный
поиск и экспорт авторизационных данных в задачу не входят.
