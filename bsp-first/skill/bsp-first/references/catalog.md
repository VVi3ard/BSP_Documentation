# Каталог методов БСП из статей

Одна строка на метод: `Модуль.Метод(параметры)`, контекст, число вызовов в 5 типовых конфигурациях, описание. Контекст: С - сервер, К - клиент, КС - клиент и сервер.
Подробности и примеры - в файле раздела.
