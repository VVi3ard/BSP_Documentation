# BSP Documentation

`BSP Documentation` — плагин Codex для разработки на 1С. Он объединяет MCP с версионной документацией БСП, компактную навигационную карту программного интерфейса и демо-конфигурацию EDT с примерами использования.

## Возможности

Для задачи разработки на 1С Codex может:

1. определить версию БСП целевого проекта;
2. найти подходящую подсистему и группу API;
3. найти и прочитать официальную документацию метода;
4. получить каталог соответствующей демо-конфигурации;
5. изучить реальные вызовы BSL, callbacks, клиент-серверный поток и код форм.

Официальная документация БСП является нормативным источником. Демо-конфигурация — практический пример реализации.

## Включённые данные

| Компонент | Версия |
| --- | --- |
| Документация и навигация БСП | 3.1.11 |
| Семейство векторного индекса | 3.1 |
| Демо-конфигурация EDT | 3.1.11.115 |

Связь версий записана в [manifest.json](plugins/bsp-documentation/data/manifest.json). Исходники демо поставляются компактным ZIP без двоичных внешних компонент и при первом обращении распаковываются в `%CODEX_HOME%\bsp\<версия>\src`.

## Установка из GitHub

Требования: Codex с поддержкой plugins, Python 3.11 или новее и доступ к сети при первом старте MCP. При первом старте создаётся личное виртуальное окружение и в него устанавливается bundled Python MCP.

```powershell
codex plugin marketplace add VVi3ard/BSP_Documentation --ref main
codex plugin add bsp-documentation@bsp-documentation
```

После установки откройте новую задачу Codex, чтобы загрузились skill и MCP плагина.

Включите **BSP Documentation** в Codex и начните новую задачу. Имя bundled MCP-сервера — `bsp_documentation`.

Для семантического `search_bsp` нужен действующий ключ OpenRouter с доступом к embeddings:

```powershell
setx OPENROUTER_API_KEY "sk-or-v1-..."
```

Не сохраняйте ключ в Git, `.mcp.json`, README или других файлах проекта. После установки или замены ключа полностью перезапустите Codex: plugin MCP получает `OPENROUTER_API_KEY` из окружения при запуске процесса. Навигация, чтение секций и получение каталога демо ключа не требуют.

Поставляемый индекс построен моделью `qwen/qwen3-embedding-8b`. Модель, создающая embedding поискового запроса, обязана **точно совпадать** с моделью построения SQLite-индекса. Сервер проверяет идентификатор модели из metadata индекса и останавливает поиск при несовпадении; совпадение одной лишь размерности векторов недостаточно. Не меняйте `BSP_EMBEDDING_MODEL` для готового индекса. Смена модели требует полной переиндексации документации и поставки нового совместимого `index.sqlite`.

Перед первым `search_bsp` после запуска MCP сервер выполняет пять коротких canary-запросов из разных подсистем. Их embeddings и embedding пользовательского запроса отправляются одним batch. Ожидаемые секции должны попасть в top-8; иначе поиск останавливается с сообщением о возможной несовместимости embedding-пространства. Успешная проверка действует 24 часа и повторяется при смене модели или metadata индекса.

## Примеры и оценка

Пять прикладных задач, проверенные ответы и комментарии к качеству поиска собраны в [benchmark BSP Documentation](docs/plugin-benchmark.md).

## Обычный сценарий

1. Используйте skill `bsp-development` для задачи BSL.
2. Вызовите `detect_bsp_version` для проекта.
3. Вызовите `discover_bsp_api_sections` с формулировкой задачи.
4. Вызовите `get_bsp_api_section_map` для выбранной подсистемы.
5. Вызовите `search_bsp` с `mode="development"`, `subsystem` и `api_group`.
6. Прочитайте выбранный метод через `get_bsp_section`.
7. Вызовите `get_bsp_demo_location`. MCP при необходимости распакует демо и вернет стабильный каталог `%CODEX_HOME%\bsp\<версия>\src`; найдите в нем полное имя метода.
8. Прочитайте содержащую вызов процедуру и её прямые UI/callback-зависимости.

Подробности: [сценарий разработки](docs/development-workflow.md) и [архитектура](docs/architecture.md).

Плагин содержит документацию и демо-конфигурацию БСП. Перед публичной публикацией или распространением проверьте, соответствует ли предполагаемое использование условиям лицензирования 1С и условиям получения этих материалов.
