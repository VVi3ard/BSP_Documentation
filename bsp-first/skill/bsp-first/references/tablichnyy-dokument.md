## ОбщегоНазначенияКлиентСервер.УстановитьСостояниеПоляТабличногоДокумента(ПолеТабличногоДокумента, Состояние)

> 3.1.11: есть, контекст КС, вызовов в типовых: 2854

Процедура управляет состоянием поля табличного документа.

```bsl
ОбщегоНазначенияКлиентСервер.УстановитьСостояниеПоляТабличногоДокумента(ПолеТабличногоДокумента, Состояние)

//
&НаКлиенте
Процедура СформироватьОтчет(Команда)

    РезультатВыполнения = СформироватьОтчетНаСервере();
    Если Не РезультатВыполнения.ЗаданиеВыполнено Тогда
        ДлительныеОперацииКлиент.ИнициализироватьПараметрыОбработчикаОжидания(ПараметрыОбработчикаОжидания);
        ПодключитьОбработчикОжидания("Подключаемый_ПроверитьВыполнениеЗадания", 1, Истина);
        ОбщегоНазначенияКлиентСервер.УстановитьСостояниеПоляТабличногоДокумента(Элементы.Результат, "ФормированиеОтчета");
    КонецЕсли;

КонецПроцедуры

//
&НаКлиенте
Процедура ДнейПланированияПриИзменении(Элемент)
    ОбщегоНазначенияКлиентСервер.УстановитьСостояниеПоляТабличногоДокумента(Элементы.Результат, "НеАктуальность");
КонецПроцедуры
```
