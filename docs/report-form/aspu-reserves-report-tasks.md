открывается в общей форме БСП `ФормаОтчета`. Общую форму не меняем.

Почему сделано именно так и где проверено — [overview.md](overview.md); общие шаблоны — [recipes.md](recipes.md).
Код не запускался: точки входа проверены по коду БСП 3.1.11 и демо, синтаксис и поведение проверить локально.

## Пункт 1. Свой элемент на форме (флажок, поле выбора)

Элемент на общей форме не создаем кодом: у программного поля не может быть своего `ПриИзменении`
(обработчик должен жить в модуле общей формы), его значение не доходит до фонового формирования и не
сохраняется в варианте. Делаем параметр СКД — БСП сама нарисует элемент в шапке.

**Флажок `ВРазрезеПризнакаУдержания`** (используется в пункте 2):

1. Схема → вкладка «Параметры» → добавить:
   - Имя: `ВРазрезеПризнакаУдержания`;
   - Заголовок: «В разрезе признака удержания»;
   - Тип: `Булево`; значение: `Истина`;
   - «Ограничение использования» — снять; «Использование» — «Всегда».

   В тексте запроса параметр не используется — это нормально.
2. Вкладка «Настройки», вариант `Основной` → «Параметры» → `ВРазрезеПризнакаУдержания`:
   - включить флажок использования, значение `Истина`;
   - «Свойства элемента пользовательских настроек» → «Включать в пользовательские настройки», режим
     «Быстрый доступ».
3. Итог: в шапке отчета — флажок «В разрезе признака удержания». Булев параметр БСП показывает одним флажком
   (`ОтчетыСервер.НайтиЗначенияКакФлажки`).

**Поле выбора** (пример на будущее) — тот же путь: параметр нужного типа.

- Ссылочный тип — поле со штатной формой выбора. Ограничить выбор: колонка «Параметры редактирования» →
  «Параметры выбора» (фиксированный отбор) или «Связи параметров выбора» (отбор по другому параметру).
- Фиксированный список — «Доступные значения» у параметра. Список из кода — recipes.md, рецепт 1,
  раздел «Список выбора» (нужна регистрация).

**Кнопка** на форме — только кодом: recipes.md, рецепт 2 (нужна регистрация).

## Пункт 2. Флажок «В разрезе признака удержания» включает и выключает поле

Сейчас в варианте две группировки детальных записей: `СРазбивкой` (выбор: Дата, Стратегия,
ПризнакУдержания, СЧА…; выключена) и `БезРазбивки` (то же без ПризнакУдержания), каждая со своим флажком
в быстрых настройках. Заменяем на одну группировку и один флажок из пункта 1.

**Шаг 2.1. Схема, вариант `Основной`, вкладка «Структура»:**

1. Удалить группировку `БезРазбивки`.
2. Группировку `СРазбивкой` (детальные записи) оставить с этим же именем — код ищет ее по имени; включить ее
   использование и **снять** «Включать в пользовательские настройки» (флажок использования группировки в
   шапке больше не нужен).

## Пункт 3. Период ровно 1 день, если выводится лицевой счет без отбора по нему

Правило: если поле лицевого счета выбрано для вывода (в колонках или группировках) и отбора по лицевому
счету нет — период должен быть одним днем, иначе предупреждение и отказ от формирования. Если отбор по
счету установлен — ограничения нет.

Точка — платформенное событие `ОбработкаПроверкиЗаполнения` модуля объекта. Общая форма вызывает его из
`ПроверитьЗаполнение()` до запуска фонового задания: сообщение показывается пользователю, отчет не
формируется. Рассылка и снимки проверяют то же самое.

**Про этот отчет.** Сейчас лицевой счет в нем не выводится (требования: «Отчет не выводит лицевые счета»),
у поля `ЛицевойСчет` в наборе — ограничение «Условие», отбор сделан отдельным полем `ОтборЛицевойСчет`
(D-0025). Проверка ниже написана под общий случай: имена полей — в константах в начале. Если
пользователь не может вывести счет, проверка просто не срабатывает.

```bsl
#Область ПроверкаПериода

Процедура ПроверитьПериодПриВыводеЛицевогоСчета(Отказ)
	
	ИмяПоляВывода = "ЛицевойСчет";       // поле, которое может выводиться
	ИмяПоляОтбора = "ОтборЛицевойСчет";  // поле, по которому в этом отчете отбирают счет
	ИмяПараметраПериода = "ПериодОтчета";
	
	Настройки = КомпоновщикНастроек.ПолучитьНастройки(); // с учетом пользовательских настроек
	
	Если Не ПолеВыводится(Настройки, Новый ПолеКомпоновкиДанных(ИмяПоляВывода)) Тогда
		Возврат;
	КонецЕсли;
	Если ОтборПоПолюУстановлен(Настройки.Отбор.Элементы, Новый ПолеКомпоновкиДанных(ИмяПоляОтбора)) Тогда
		Возврат;
	КонецЕсли;
	
	ПараметрПериод = Настройки.ПараметрыДанных.НайтиЗначениеПараметра(
		Новый ПараметрКомпоновкиДанных(ИмяПараметраПериода));
	Если ПараметрПериод = Неопределено Тогда
		Возврат;
	КонецЕсли;
	Период = ПараметрПериод.Значение; // СтандартныйПериод
	
	Если Не ЗначениеЗаполнено(Период.ДатаНачала)
		Или НачалоДня(Период.ДатаНачала) <> НачалоДня(Период.ДатаОкончания) Тогда
		ОбщегоНазначения.СообщитьПользователю(
			НСтр("ru = 'При выводе лицевых счетов без отбора по счету период отчета должен быть один день.'"),
			, , , Отказ);
	КонецЕсли;
	
КонецПроцедуры

// Поле выбрано в колонках или группировках итоговых настроек (с учетом флажков использования).
Функция ПолеВыводится(Настройки, Поле)
	Возврат ПолеЕстьВВыборе(Настройки.Выбор.Элементы, Поле)
		Или ПолеЕстьВСтруктуре(Настройки.Структура, Поле);
КонецФункции

Функция ПолеЕстьВВыборе(ЭлементыВыбора, Поле)
	Для Каждого ЭлементВыбора Из ЭлементыВыбора Цикл
		Если Не ЭлементВыбора.Использование Тогда
			Продолжить;
		КонецЕсли;
		Если ТипЗнч(ЭлементВыбора) = Тип("ГруппаВыбранныхПолейКомпоновкиДанных") Тогда
			Если ПолеЕстьВВыборе(ЭлементВыбора.Элементы, Поле) Тогда
				Возврат Истина;
			КонецЕсли;
		ИначеЕсли ТипЗнч(ЭлементВыбора) = Тип("ВыбранноеПолеКомпоновкиДанных")
			И ЭлементВыбора.Поле = Поле Тогда
			Возврат Истина;
		КонецЕсли;
	КонецЦикла;
	Возврат Ложь;
КонецФункции

Функция ПолеЕстьВСтруктуре(Коллекция, Поле)
	Для Каждого Элемент Из Коллекция Цикл
		Если Не Элемент.Использование Тогда
			Продолжить;
		КонецЕсли;
		ТипЭлемента = ТипЗнч(Элемент);
		Если ТипЭлемента = Тип("ТаблицаКомпоновкиДанных") Тогда
			Если ПолеЕстьВВыборе(Элемент.Выбор.Элементы, Поле)
				Или ПолеЕстьВСтруктуре(Элемент.Строки, Поле)
				Или ПолеЕстьВСтруктуре(Элемент.Колонки, Поле) Тогда
				Возврат Истина;
			КонецЕсли;
		ИначеЕсли ТипЭлемента = Тип("ДиаграммаКомпоновкиДанных") Тогда
			Если ПолеЕстьВСтруктуре(Элемент.Точки, Поле)
				Или ПолеЕстьВСтруктуре(Элемент.Серии, Поле) Тогда
				Возврат Истина;
			КонецЕсли;
		Иначе // группировка отчета, таблицы или диаграммы
			Для Каждого ПолеГруппировки Из Элемент.ПоляГруппировки.Элементы Цикл
				Если ТипЗнч(ПолеГруппировки) = Тип("ПолеГруппировкиКомпоновкиДанных")
					И ПолеГруппировки.Использование
					И ПолеГруппировки.Поле = Поле Тогда
					Возврат Истина;
				КонецЕсли;
			КонецЦикла;
			Если ПолеЕстьВВыборе(Элемент.Выбор.Элементы, Поле)
				Или ПолеЕстьВСтруктуре(Элемент.Структура, Поле) Тогда
				Возврат Истина;
			КонецЕсли;
		КонецЕсли;
	КонецЦикла;
	Возврат Ложь;
КонецФункции

// Включенный отбор «Равно» / «В списке» с заполненным значением. Группы «ИЛИ» / «НЕ» не считаются.
Функция ОтборПоПолюУстановлен(ЭлементыОтбора, Поле)
	Для Каждого ЭлементОтбора Из ЭлементыОтбора Цикл
		Если Не ЭлементОтбора.Использование Тогда
			Продолжить;
		КонецЕсли;
		Если ТипЗнч(ЭлементОтбора) = Тип("ГруппаЭлементовОтбораКомпоновкиДанных") Тогда
			Если ЭлементОтбора.ТипГруппы = ТипГруппыЭлементовОтбораКомпоновкиДанных.ГруппаИ
				И ОтборПоПолюУстановлен(ЭлементОтбора.Элементы, Поле) Тогда
				Возврат Истина;
			КонецЕсли;
		ИначеЕсли ЭлементОтбора.ЛевоеЗначение = Поле
			И (ЭлементОтбора.ВидСравнения = ВидСравненияКомпоновкиДанных.Равно
				Или ЭлементОтбора.ВидСравнения = ВидСравненияКомпоновкиДанных.ВСписке)
			И ЗначениеЗаполнено(ЭлементОтбора.ПравоеЗначение) Тогда
			Возврат Истина;
		КонецЕсли;
	КонецЦикла;
	Возврат Ложь;
КонецФункции

#КонецОбласти
```

**Нюансы:**
- `ОбработкаПроверкиЗаполнения` — без `Экспорт`, это событие платформы.
- Пустой период тоже отклоняется: выражение параметра `КонецПериода(&ПериодОтчета.ДатаОкончания, "День")`
  при пустой дате дает 01.01.0001 и молча пустой отчет.
- Поле в корневом `Настройки.Выбор` считается выведенным: детальные записи с автополями берут колонки оттуда.
- Если отбор по счету в другом отчете сделан параметром, а не полем, проверять параметр
  (`Настройки.ПараметрыДанных.НайтиЗначениеПараметра`, `Использование` и `Значение`).

**Проверить:** период из нескольких дней + счет в колонках без отбора → сообщение, отчет не сформирован;
тот же период + отбор по счету → формируется; один день → формируется.

## Пункт 4. Обработка табличного документа после вывода

Точка — тот же `ПриКомпоновкеРезультата`, сразу после `СкомпоноватьВДокумент` (пункт 2). Объект —
`ДокументРезультат` (`ТабличныйДокумент`). Работает в форме, рассылке и снимках, выполняется в фоновом
задании на сервере — без формы и диалогов.

```bsl
#Область ДоработкаРезультата

// Пример: заменить своей логикой.
Процедура ДоработатьРезультат(ДокументРезультат)
	
	// 1. Оформить ячейки по тексту.
	Область = ДокументРезультат.НайтиТекст("СЧА (РППО)");
	Если Область <> Неопределено Тогда
		Область.Шрифт = Новый Шрифт(Область.Шрифт, , , Истина);
	КонецЕсли;
	
	// 2. Дописать пояснение в конец.
	НомерСтроки = ДокументРезультат.ВысотаТаблицы + 2;
	Ячейка = ДокументРезультат.Область(НомерСтроки, 1, НомерСтроки, 1);
	Ячейка.Текст = НСтр("ru = 'СЧА рассчитана по цене пая на дату строки.'");
	
	// 3. Гиперссылка: e1cib/... форма отчета откроет сама.
	Ячейка = ДокументРезультат.Область(НомерСтроки + 1, 1, НомерСтроки + 1, 1);
	ОтчетыСервер.ВывестиГиперссылку(Ячейка, "e1cib/list/РегистрСведений.ЦеныПаев", НСтр("ru = 'Цены паев'"));
	
КонецПроцедуры

#КонецОбласти
```

**Правила:**
- менять значения и оформление ячеек, дописывать в конец; не вставлять строки внутрь или выше таблицы
  результата — может разъехаться с данными расшифровки и контекстным меню формы (не проверено);
- не обращаться к форме и не показывать диалоги — это фоновое задание;
- нужно только визуально и только в форме — `ОтчетыКлиентПереопределяемый.ПослеФормирования(ФормаОтчета, ОтчетСформирован)`,
  объект `ФормаОтчета.ОтчетТабличныйДокумент`; в рассылку это не попадет.

## Пункт 5. Расшифровка: открыть другой отчет с параметрами из ячейки

Пример: щелчок по строке отчета о резервах открывает `Отчет.ОтчетОбОстаткахВРазрезеСчетов` (остатки по
лицевым счетам) на дату строки, по стратегии строки и, если строка с разбивкой, по признаку удержания.

У целевого отчета: параметр данных `Период` (дата), отборы `Стратегия`, `ПризнакУдержания` в варианте
`Основной`.

**«В то же окно» сделать нельзя.** Стандартная расшифровка БСП тоже открывает новую форму отчета
(`ВариантыОтчетовСлужебныйКлиент.ОткрытьФормуОтчета`). Другой отчет внутри текущей формы открыть нельзя:
форма привязана к объекту своего отчета. Ближайшая альтернатива — открыть штатную форму расшифровки того же
отчета с другой схемой СКД (recipes.md, вариант 6Б); для готового отдельного отчета — способ ниже.

**Шаг 5.1. Общий модуль `ОтчетыКлиентПереопределяемый`** (сейчас пустой) — только вызов:

```bsl
Процедура ОбработкаРасшифровки(ФормаОтчета, Элемент, Расшифровка, СтандартнаяОбработка) Экспорт
	ОтчетыАСПУКлиент.ОбработкаРасшифровки(ФормаОтчета, Элемент, Расшифровка, СтандартнаяОбработка);
КонецПроцедуры
```

**Шаг 5.2. Новый клиентский общий модуль** (имя условное — по соглашениям проекта; «Клиент», «Сервер» = Ложь):

```bsl
#Область ПрограммныйИнтерфейс

// См. ОтчетыКлиентПереопределяемый.ОбработкаРасшифровки.
Процедура ОбработкаРасшифровки(ФормаОтчета, Элемент, Расшифровка, СтандартнаяОбработка) Экспорт
	
	Если ФормаОтчета.НастройкиОтчета.ПолноеИмя = "Отчет.ОтчетОбОстаткахВРазрезеСтратегийИРезервов" Тогда
		РасшифровкаОстатковПоСтратегиямИРезервам(ФормаОтчета, Расшифровка, СтандартнаяОбработка);
	КонецЕсли;
	
КонецПроцедуры

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

Процедура РасшифровкаОстатковПоСтратегиямИРезервам(ФормаОтчета, Расшифровка, СтандартнаяОбработка)
	
	Если Не ЭтоАдресВременногоХранилища(ФормаОтчета.ОтчетДанныеРасшифровки) Тогда
		Возврат;
	КонецЕсли;
	
	ЗначенияПолей = ОтчетыАСПУВызовСервера.ЗначенияПолейРасшифровки(
		ФормаОтчета.ОтчетДанныеРасшифровки, Расшифровка);
	
	Стратегия = ЗначенияПолей.Получить("Стратегия");
	Дата = ЗначенияПолей.Получить("Дата");
	Если Не ЗначениеЗаполнено(Стратегия) Или Не ЗначениеЗаполнено(Дата) Тогда
		Возврат; // не строка данных - оставляем стандартную обработку
	КонецЕсли;
	
	СтандартнаяОбработка = Ложь;
	
	// Ключ = имя параметра данных целевого отчета -> установится параметр;
	// ключ = имя поля -> установится отбор «Равно» (недоступный для изменения).
	Отбор = Новый Структура;
	Отбор.Вставить("Период", Дата);
	Отбор.Вставить("Стратегия", Стратегия);
	ПризнакУдержания = ЗначенияПолей.Получить("ПризнакУдержания");
	Если ЗначениеЗаполнено(ПризнакУдержания) Тогда // в режиме без разбивки поля нет
		Отбор.Вставить("ПризнакУдержания", ПризнакУдержания);
	КонецЕсли;
	
	ПараметрыФормы = Новый Структура;
	ПараметрыФормы.Вставить("Отбор", Отбор);
	ПараметрыФормы.Вставить("КлючВарианта", "Основной");
	ПараметрыФормы.Вставить("СформироватьПриОткрытии", Истина);

	ОткрытьФорму("Отчет.ОтчетОбОстаткахВРазрезеСчетов.Форма", ПараметрыФормы, ФормаОтчета);
	
КонецПроцедуры

#КонецОбласти
```

**Шаг 5.3. Новый серверный общий модуль с вызовом сервера** («Сервер», «Вызов сервера» = Истина):

```bsl
#Область СлужебныйПрограммныйИнтерфейс

// Значения полей ячейки и всех группировок над ней.
//
// Параметры:
//   АдресДанныхРасшифровки - Строка - ФормаОтчета.ОтчетДанныеРасшифровки.
//   Расшифровка - ИдентификаторРасшифровкиКомпоновкиДанных - из события ОбработкаРасшифровки.
//
// Возвращаемое значение:
//   Соответствие из КлючИЗначение:
//   * Ключ - Строка - имя поля.
//   * Значение - Произвольный - значение; ближайшее к ячейке побеждает.
//
Функция ЗначенияПолейРасшифровки(Знач АдресДанныхРасшифровки, Знач Расшифровка) Экспорт
	
	ДанныеРасшифровки = ПолучитьИзВременногоХранилища(АдресДанныхРасшифровки); // ДанныеРасшифровкиКомпоновкиДанных
	Результат = Новый Соответствие;
	ЗаполнитьЗначенияПолей(Результат, ДанныеРасшифровки.Элементы[Расшифровка]); // индекс как есть, без "- 1"
	Возврат Результат;
	
КонецФункции

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

Процедура ЗаполнитьЗначенияПолей(ЗначенияПолей, ЭлементРасшифровки)
	
	Если ТипЗнч(ЭлементРасшифровки) = Тип("ЭлементРасшифровкиКомпоновкиДанныхПоля") Тогда
		Для Каждого ЗначениеПоля Из ЭлементРасшифровки.ПолучитьПоля() Цикл
			Если ЗначенияПолей[ЗначениеПоля.Поле] = Неопределено Тогда
				ЗначенияПолей.Вставить(ЗначениеПоля.Поле, ЗначениеПоля.Значение);
			КонецЕсли;
		КонецЦикла;
	КонецЕсли;
	
	Для Каждого Родитель Из ЭлементРасшифровки.ПолучитьРодителей() Цикл
		ЗаполнитьЗначенияПолей(ЗначенияПолей, Родитель);

```

Образец этого приема в БСП — `УправлениеДоступомСлужебныйКлиент.ПриОбработкеРасшифровкиОтчета` и
`Отчеты.АнализПравДоступа.ПараметрыРасшифровки` (демо). В АСПУ похожий помощник уже есть, но не подключен:
`ОтчетыАванкорСервер.ЗначениеГруппировкиРасшифровки` (поиск значения по типу вверх по родителям).

**Как целевой отчет применит `Отбор`** (`ОтчетыСервер.УстановитьФиксированныеОтборы`): `Период` — параметр
данных: `Использование = Истина`, значение из ячейки, режим «Недоступный»; `Стратегия`, `ПризнакУдержания` —
отборы «Равно», тоже недоступные для изменения. Применяется, если открыт начальный вариант (`КлючВарианта`).

**Нюансы:**
- `ПризнакУдержания` в целевом отчете считается срезом последних на конец выбранного дня, а в отчете о
  резервах — на дату строки. Для одной даты они совпадают; проверить на данных.
- Строка «без признака» (пустое значение) в отбор не передается — откроются все счета стратегии.
- Несколько вариантов перехода — меню `ФормаОтчета.ПоказатьВыборИзМеню(ОписаниеОповещения, СписокЗначений, Элемент)`.
- Меню ячейки (правая кнопка) — `ОтчетыКлиентПереопределяемый.ОбработкаДополнительнойРасшифровки`, та же сигнатура.

**Проверить:** щелчок по ячейке строки → открывается отчет по счетам с нужными датой и стратегией,
формируется сразу; щелчок по шапке → стандартное поведение; другие отчеты — расшифровка не изменилась.
