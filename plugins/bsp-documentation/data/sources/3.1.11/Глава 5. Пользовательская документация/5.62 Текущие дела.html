5.62 Текущие дела

Приложение позволяет выводить список текущих дел пользователя (внешнего пользователя) на рабочем столе: новые письма, задачи, заявки, несогласованные заказы и т.п. Список дел может включать в себя важные и обычные дела, однострочные и многострочные, с количественными показателями и без. Список дел сгруппирован по разделам командного интерфейса, предусмотрена возможность настраивать видимость и порядок отображения, автоматическое обновление через заданный интервал. Важные дела выделяются цветом.

В списке текущих дел на рабочем столе выводятся напоминания о необходимости обновления ряда классификаторов (Адресный классификатор, классификатор банков, курсы валют), индекса полнотекстового поиска, о настройке резервного копирования, обновлении приложения (в подчиненном узле РИБ), предупреждения при синхронизации данных, уведомление о редактируемых файлах и новых электронных письмах.

Дела отображаются в виде ссылок, перейдя по которым, можно открыть списки, документы или другие объекты приложения.

Список Текущие дела

При первом открытии приложение производит поиск текущих дел. Процесс может занимать некоторое время.

По умолчанию текущие дела отображаются в свернутом виде – в виде разделов. При этом важные дела отображаются и в свернутом разделе: значком  отображаются свернутые разделы, в которых имеются важные дела.

Нажав на значки или , можно развернуть разделы.

С помощью кнопки в нижней части списка можно Настроить список дел. Подробнее см. раздел Настройка списка Текущие дела.

С помощью кнопки  можно Обновить список дел.

На начальной странице внешнего пользователя также отображаются текущие дела – выводятся новые задачи, анкеты и другие предметы, требующие внимания, при этом доступна только кнопка  Обновить.

Настройка списка Текущие дела

С помощью кнопки Настроить в нижней части списка текущих дел можно управлять списком дел и разделов. Список состоит из вкладок:

■ Отображаемые дела – предназначена для настройки списка текущих дел (подробнее см. раздел Отображаемые дела);

■ Другое – предназначена для настройки обновления списка текущих дел (подробнее см. раздел Обновление списка дел).

Отображаемые дела

На этой вкладке настройки текущих дел с помощью флажков можно управлять видимостью списка дел.

С помощью кнопки  Установить флажки можно сделать видимыми все разделы и дела.

С помощью кнопки  Снять флажки можно скрыть все разделы и дела.

С помощью кнопок  и  можно менять очередность дел и разделов в списке.

С помощью кнопки  можно включить дополнительное оповещение о выбранном текущем деле в центр уведомлений приложения. Рядом с таким делом появляется значок .

Для подтверждения нажмите кнопку ОК.

Если было настроено дополнительное оповещение о текущих делах, то при обновлении списка текущих дел и при запуске приложения оповещения о таких делах появляются в списке оповещений, загорается зеленым светом "колокольчик" .

Также оповещения о таких текущих делах появляются во всплывающих уведомлениях.

Обновление списка дел

На вкладке Другое можно отрегулировать частоту обновления списка текущих дел.

Включите флажок Обновлять автоматически каждые 5 минут (по умолчанию). При необходимости укажите другое число минут – доступны значения 5, 10 или 30 минут.

Также Обновить список дел можно на начальной странице в любой момент с помощью кнопки .

Исключение дублирования информации

Если какое-то из дел дублирует информацию, отображаемую на рабочем столе, то следует выбрать только одну из возможностей приложения: отключить дело из списка Текущие дела или скрыть информацию с рабочего стола.
