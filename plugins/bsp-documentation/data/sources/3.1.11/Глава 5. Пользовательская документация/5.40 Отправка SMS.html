5.40 Отправка SMS

В приложении предусмотрена отправка SMS.

Посредством SMS возможно:

■ Информирование технических специалистов о неполадках баз данных 1С;

■ Автоматическое подтверждение совершенных клиентом платежей и других операций;

■ Информирование клиента о событиях: день рождения, дата очередного платежа и прочее;

■ Массовое оповещение клиентов о товарах, услугах, акциях и специальных предложениях.

Для возможности отправки SMS необходимо:

■ Заключить договор с любым из поддерживаемых поставщиков услуги;

■ Получить логин и пароль у поставщика услуги;

■ Произвести настройки, см. раздел Настройка приложения.

Поддерживаемые провайдеры:

■ SMS-4B (https://www.sms4b.ru);

■ SMS.RU (https://sms.ru);

■ SMS-ЦЕНТР (https://smsc.ru);

■ Билайн (https://moskva.beeline.ru/business/sms-rassylki/pryamie-sms-rassilki);

■ МТС (https://marketolog.mts.ru);

■ СМС-Услуги (https://sms-uslugi.ru).

Для настройки отправки SMS необходимы права администратора. Для отправки SMS необходимо назначить роль  Отправка SMS.

Настройка приложения

Перед началом использования возможности отправки SMS необходимо настроить параметры отправки. Для этого перейдите по ссылке Настройка отправки SMS раздела Администрирование – Органайзер – Отправка SMS.

Выберите с помощью кнопки  из списка Провайдера, с которым заключен договор, например, Билайн.

Выберите Способ авторизации, указанный в договоре с провайдером, например, для Билайн можно выбрать a2p-sms.beeline.ru (рекомендуется).

В полях Логин и Пароль укажите данные, указанные в договоре с провайдером. Подробнее об этой услуге провайдера можно узнать на его сайте. В частности, для отправки SMS через Билайн см. http://a2p-sms.beeline.ru (https://a2p-sms.beeline.ru/auth/login).

В настройках отправки SMS также можно указать Имя отправителя (поддерживается только латиница), например, SysAdmin. В этом случае SMS будут приходить с указанного имени, а не с номера телефона отправителя.

Для МТС предусмотрена авторизация по Логину и Паролю из личного кабинета провайдера. Имя отправителя - согласованное с МТС.

Подробнее об этой услуге провайдера можно узнать на сайте (https://marketolog.mts.ru).

Также можно перейти по ссылке Нужна помощь? По ссылке отображаются рекомендации по подключению услуги, а также сайт нужного провайдера.

Отправка SMS

В списке Демо: Контрагенты имеется возможность отправки SMS.

Нажав кнопку , выберите команду Отправить SMS. SMS будет отправлено выбранному контрагенту.

Для того чтобы была возможность отправки SMS, необходимо произвести настройки (см. раздел Настройка приложения).

Заполните необходимые данные:

■ Текст сообщения – максимальная длина текста одного сообщения составляет 140 символов (160 символов в латинице или 70 символов в кириллице). Провайдеры могут поддерживать отправку «длинных SMS» (несколько склеенных между собой SMS). Максимальная длина таких SMS определяется оператором, например, Билайн – 480 символов (в латинице), МТС – 1000 символов (в латинице). Необходимо учитывать, что некоторые модели телефонов не умеют склеивать длинные SMS;

■ Под текстом сообщения в поле Длина сообщения приложение выводит количество символов;

■ Отправлять в транслите – включите флажок, для того чтобы использовать эту возможность;

■ Имя отправителя – включите флажок, для того чтобы показывать имя отправителя, укажите (поддерживается только латиница), от кого сообщение (если данная услуга предоставляется выбранным провайдером), например, Otdel prodaj. Если не указывать этот параметр, то имя отправителя будет взято из настроек отправки SMS.

Нажав кнопку Настройка отправки SMS, можно изменить параметры отправки SMS. Подробнее см. раздел Настройка приложения.

С помощью кнопки можно Отправить сообщение.

В случае ошибки состояние отправки можно посмотреть в журнале регистрации. Подробнее см. раздел документации Настройки приложения.

Возможные статусы доставки:

■ Не отправлялось;

■ Отправляется;

■ Отправлено;

■ Не отправлено;

■ Доставлено;

■ Не доставлено;

■ Ошибка.

В приложении предусмотрен ввод документа Сообщение SMS с последующей рассылкой сообщений одному или нескольким адресатам, а также хранение таких документов. Подробнее см. раздел документации Взаимодействия.
