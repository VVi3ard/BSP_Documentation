## ОбщегоНазначения.СократитьСтрокуКонтрольнойСуммой(Строка, МаксимальнаяДлина)

> 3.1.11: есть, контекст С, вызовов в типовых: 27

Сокращает строку до нужной длины, при этом обрезанная часть хешируется, обеспечивая уникальность строки. Проверяет длину строки на входе и, в случае превышения максимальной длины, преобразует ее конец по алгоритму MD5 в уникальную строку из 32 символов.

```bsl
Результат = ОбщегоНазначения.СократитьСтрокуКонтрольнойСуммой(Строка, МаксимальнаяДлина)

// Было
ХешСумма = "16497FA0C8E13CE8FAB874D959DB91B916497FA0C8E13CE8FAB874D959DB91B9";
// Резульат "16497FA041ED169C2C86D5FDAD6D05CB1D42CA1C"
ОбщегоНазначения.СократитьСтрокуКонтрольнойСуммой(ХешСумма, 40);
```
