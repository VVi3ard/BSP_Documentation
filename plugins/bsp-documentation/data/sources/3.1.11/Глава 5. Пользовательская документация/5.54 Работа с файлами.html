5.54 Работа с файлами

Приложение предоставляет возможность хранения файлов произвольного формата. В отличие от хранения файлов на серверах или в корпоративных приложениях документооборота, файлы связываются с данными приложения. Так удобно хранить файлы, непосредственно связанные с данными.

Например, в файле, присоединенном к элементу списка Демо: Партнеры, можно хранить подлинник договора с этим партнером. Также в приложении можно хранить шаблоны договоров с партнерами, создавать договоры по этим шаблонам и хранить их в присоединенных файлах конкретных партнеров.

Приложение позволяет подписывать файлы электронной подписью.

Поддерживается асимметричное шифрование файлов. Информацию об электронной подписи и шифровании можно найти в разделе документации Электронная подпись.

Объекты-хранители файлов в приложении:

Списки:

■ Папки файлов;

■ Демо: Номенклатура;

■ Демо: Партнеры;

■ Демо: Проекты.

Документы:

■ Демо: Заказы покупателя;

■ Демо: Счета на оплату покупателя.

Бизнес-процессы:

■ Демо: Задания.

Приложение позволяет сократить объем данных, занимаемый «ненужными» файлами. Под ненужными понимаются файлы, потерявшие свою актуальность (например, по истечении определенного времени).

В приложении предусмотрен механизм, который позволяет настраивать правила удаления «ненужных» файлов по свойствам самих файлов и свойствам, типам их владельцев, а также удалять эти файлы регламентным заданием. Также предусмотрена возможность удаления устаревших версий файлов. Подробнее см. раздел Настройка очистки файлов.

Работу с файлами, хранящимися в приложении, можно организовать в публичном или корпоративном (приватном) облачном сервисе – Яндекс Диск, Dropbox и т. д. Предусмотрена возможность синхронизировать файлы в приложении с облачным сервисом. Подробнее см. раздел Настройка синхронизации файлов.

Файлы можно синхронизировать как вручную, так и с помощью регламентного задания. Подробнее о настройке регламентных заданий см. раздел документации Регламентные задания.

Для использования работы с файлами в приложении необходимо произвести настройки (подробнее см. разделы Настройка приложения, Персональные настройки). Настройки приложения выполняются администратором. Персональные настройки могут выполняться также с помощью администратора.

В приложении предусмотрена возможность:

■ Хранить файлы в томах и информационной базе;

■ Хранить файлы в томах в разрезе объектов-владельцев;

■ Хранить файлы в томах в разрезе расширений файлов;

■ Обеспечить централизованное хранение файлов в томах для приложения в Интернете (подробнее см. раздел Хранение файлов в томах на сервере).

Работу с файлами осуществляют пользователи приложения. Для работы с томами файлов и списком Файлы необходима роль Добавление и изменение папок и файлов. С файлами могут работать и внешние пользователи приложения. Для работы с присоединенными файлами достаточно прав на изменение объектов, к которым присоединяется файл на компьютере. Для работы с папками файлов необходимы настройки (подробнее см. раздел Настройка прав для доступа к папкам и файлам).

Настройка приложения

Настройка приложения для работы с файлами осуществляется по команде раздела Администрирование.

Для того чтобы задать структуру папок файлов и прав доступа к ним, а также разместить шаблоны файлов нажмите на ссылку Файлы для перехода в список.

В поле Хранить файлы – можно указать вариант хранения файлов:

■ в информационной базе;

■ в томах на сервере;

■ в информационной базе и томах на сервере.

Бывают ситуации, когда один и тот же файл загружается несколько раз разными пользователями. Это приводит к увеличению нагрузки информационной базы и использованию дополнительного пространства для хранения копий одного и того же файла. Поэтому с помощью ссылки Выполнить дедупликацию можно сэкономить место в информационной базе. Подробнее см. раздел Уменьшение размера информационной базы.

Хранение файлов в томах позволяет вынести файлы из информационной базы и хранить их внешним образом в сетевом каталоге. Имеет смысл, если объем файлов большой. Подробнее см. раздел Хранение файлов в томах на сервере.

■ Перенос файлов – нажмите на ссылку, для того чтобы перейти к настройкам и перенести файлы. При смене способа хранения файлов автоматический перенос файлов из приложения в тома и обратно не происходит. Подробнее см. раздел Перенос файлов в тома и обратно.

Если хотя бы часть файлов хранится в томах, то становятся доступными команды:

■ Тома хранения файлов – нажмите на ссылку для перехода к списку. Подробнее см. раздел Список Тома хранения файлов.

■ Создавать подкаталоги с именами справочников-владельцев файлов – если флажок включен, то файлы в томах будут размещены в подкаталогах с именами списков, документов и т. д., к которым присоединены файлы. Например, для точной настройки правил резервного копирования файлов в томах. Подробнее о возможностях использования см. раздел Хранение файлов в томах на сервере.

Если выбран вариант Хранить файлы в информационной базе и томах на сервере, можно указать, какие типы файлов будут храниться в информационной базе:

■ Изображения (перечислены типы файлов);

■ Офисные документы (перечислены типы файлов).

Размер файла не превышает - если это число задано, то невозможно будет загрузить файлы большего размера.

Остальные настройки не зависят от способа хранения файлов:

■ Запретить загрузку файлов с расширениями – включите флажок, при необходимости в список через пробел можно добавить расширения файлов, которые нельзя загружать в приложение;

■ Максимальный размер файла (по умолчанию в приложение можно загрузить файлы размером не более 50 Мб);

■ Настройка очистки файлов – переход к настройке очистки ненужных файлов. Подробнее см. раздел Настройка очистки файлов;

■ Расширения текстовых файлов – через пробел можно перечислить расширения текстовых файлов, которые можно использовать в приложении;

■ Синхронизировать файлы с облачными сервисами – включите флажок, для того чтобы получить возможность синхронизации файлов с сервисами Яндекс Диск, Box и т. д. для упрощения редактирования файлов. После этого становится доступной ссылка:

■ Настройки синхронизации – перейдите по ссылке для настройки синхронизации файлов с облачными сервисами Яндекс Диск, Box. Для пользователей группы доступа Настройка синхронизации файлов после этого в списках присоединенных файлов становится доступной команда Еще – Синхронизация с облаком. Подробнее см. раздел Настройка синхронизации файлов.

Персональные настройки

Персональные настройки для работы с файлами предусмотрены по команде Демо: Мои настройки раздела Главное. Выберите вкладку Работа с файлами.

Также администратор может найти команду Демо: Мои настройки в панели действий раздела Администрирование.

Доступны следующие настройки:

■ Действие при выборе файла – можно указать, что делать приложению при выборе файла двойным нажатием мыши в списках: Открывать файл или Открывать его карточку. По умолчанию задано Открывать файл. Нажмите кнопку  Выбрать из списка для изменения;

■ Выбор режима открытия при выборе файла – если флажок включен, то перед открытием файла приложение задаст вопрос, в каком режиме открывать файл: в режиме просмотра или в режиме редактирования;

■ Показывать подсказки при редактировании файлов (только веб-клиент) – если флажок включен, то при работе через веб-клиент будут выводиться подсказки о том, как удобнее открыть файл для просмотра или редактирования и как обновить его в приложении;

■ Показывать занятые файлы при завершении работы – если флажок включен и во время работы в приложении для редактирования были открыты один или несколько файлов, то при завершении работы приложения показывается список этих файлов (подробнее см. раздел Редактирование файлов). Также этот флажок можно выключить при завершении работы приложения;

■ Показывать колонку «Размер» в списках файлов – если флажок включен, то в списках файлов указывается Размер файлов в Кб;

■ Показывать информацию, что файл не был изменен – если флажок включен, то при завершении редактирования файла, в который не было внесено изменений, приложение выводит сообщение. Сообщение можно отключить с помощью флажка;

■ Сравнивать версии при помощи – приложение позволяет сравнивать версии файлов формата ODT, DOC, RTF, TXT между собой. Можно задать по умолчанию текстовый редактор, который будет использоваться для сравнений версий файлов. Для выбора предусмотрены Microsoft Office Word и OpenOffice.org Writer. Если поле не заполнено, то выбирать текстовый редактор нужно каждый раз при сравнении версий. Подробнее см. раздел Список версий;

■ Настройки открытия файлов – в таблице можно указать Способ открытия текстовых файлов с перечисленными Расширениями. Файлы можно открыть стандартным приложением или во встроенном редакторе приложения. Указав способ открытия Во встроенном редакторе, можно открывать текстовые файлы, не имея специальных приложений. По умолчанию текстовые файлы открываются во встроенном редакторе;

■ Настройка сканирования – с помощью этой ссылки можно перейти к настройке параметров сканирования. Подробнее см. раздел Настройка сканирования;

■ Настройка основного рабочего каталога – с помощью этой ссылки можно указать путь к основному рабочему каталогу и произвести необходимые для работы с каталогом настройки. Подробнее см. раздел Настройка основного рабочего каталога.

Настройка основного рабочего каталога

Файлы, полученные из приложения для просмотра или редактирования, временно хранятся в рабочем каталоге. С помощью ссылки Настройка основного рабочего каталога можно указать параметры для работы с каталогом:

■ Расположение основного рабочего каталога – устанавливается приложением автоматически. При необходимости путь каталога может быть изменен. Для возврата к настройкам по умолчанию нажмите кнопку  Восстановить значение по умолчанию;

■ Максимальный размер – предел суммарного объема всех файлов в основном рабочем каталоге (по умолчанию 100 Мб). Если максимальный размер равен нулю, то объем файлов не ограничен;

■ Удалять файлы при завершении редактирования – если флажок включен, то после переноса файла в приложение он удаляется из основного рабочего каталога. Это можно использовать, например, для экономии места на жестком диске или в целях повышения безопасности;

■ Подтверждать при удалении из основного рабочего каталога – если флажок включен, то перед удалением каждого файла будет выдаваться запрос на удаление файла;

■ приложение показывает Текущее состояние основного рабочего каталога – количество Файлов, содержащихся в нем и их Общий объем (Мб);

■ Открыть список файлов – нажмите кнопку, для того чтобы открыть список файлов основного рабочего каталога, т. е. редактируемых в приложении. Подробнее см. раздел Список файлов в основном рабочем каталоге;

■ Очистить основной рабочий каталог – нажмите кнопку, для того чтобы удалить файлы в основном рабочем каталоге, кроме тех, которые используются в настоящий момент.

Список файлов в основном рабочем каталоге

В списке перечислены файлы, занятые для редактирования. Флажками в колонке  Файл занят для редактирования помечены файлы, открытые в настоящий момент. Подробнее см. раздел Редактирование файлов.

В данном списке файлов с помощью кнопок панели навигации можно:

■ Удалить ненужные файлы;

■ Закончить редактирование – если файл открыт для редактирования, то завершить редактирование и сохранить внесенные изменения;

■ Отменить редактирование и не сохранять изменения в файле;

■ Открыть каталог файла в Проводнике Windows.

С помощью команд контекстного меню по правой кнопке мыши или меню Еще также можно:

■ Открыть карточку файла для просмотра или изменения. Подробнее см. раздел Карточка файла.

Настройка сканирования

Приложение позволяет хранить файлы, полученные напрямую со сканера. Сканирование возможно с любых устройств, драйвера которых поддерживают одну из технологий SANE, WIA, TWAIN, на операционных системах Microsoft Windows и Linux. Подробнее о версиях операционных систем см. Системные требования «1С:Предприятия 8».

Для того чтобы правильно настроить сканер, нажмите ссылку Настройка сканирования на вкладке Работа с файлами в персональных настройках приложения (см. также раздел Персональные настройки).

Перед выполнением дальнейших настроек к компьютеру необходимо подключить сканер, при этом в зависимости от возможностей подключенного сканера будут доступны те или иные параметры:

■ Сканер – выберите сканер из списка доступных устройств, подключенных к компьютеру.

■ Задать настройки – с помощью выпадающего списка выберите настройки диалога сканера перед сканированием. Основные в приложении – диалог сканера не открывается, а применяются настройки, заданные в приложении. Расширенные в диалоге сканера – открывается диалог сканера для расширенной настройки (например, в диалоге можно задать область сканирования).

В разделе Основное сгруппированы самые важные параметры сканирования, которые зависят от возможностей подключенного сканера, некоторые могут быть недоступны:

■ Разрешение – выберите из выпадающего списка, например, 600 dpi;

■ Цветность – выберите из выпадающего списка, например, Цветное;

■ Поворот – выберите значение из выпадающего списка, например, 90 градусов;

■ Размер бумаги – выберите формат бумаги, например, А4;

■ Если необходимо отсканировать документ с двух сторон, включите флажок Двустороннее сканирование. Данная функция доступна не во всех моделях устройств;

■ Если необходимо в автоматическом режиме отсканировать файлы, а не вручную размещать каждый лист, включите флажок Автоматическая подача документов. Данная функция доступна не во всех моделях устройств;

■ Перейдите по ссылке Номера отсканированных файлов для просмотра списка номеров отсканированных файлов. Подробнее см. раздел Список номеров отсканированных файлов.

В разделе Для одностраничных изображений сгруппированы настройки:

■ Сохранить как – выберите формат для сохранения изображений:

● PNG – подходит для большинства документов и изображений. Изображения без потери качества, файлы небольших размеров;

● JPG – подходит для большинства документов и изображений. Предоставляет возможность настройки степени сжатия, но при этом сжимает изображение с потерей качества;

● TIF – позволяет сохранять изображения без потери качества, используется для хранения изображений для дальнейшей печати. Возможно хранение многостраничных изображений;

● GIF – устаревший формат для хранения изображений в низком качестве. Файлы небольшого размера;

■ Преобразовать в PDF – включите флажок, для того чтобы сразу после сканирования преобразовывать файлы в формат PDF.

■ Качество – понадобится указать, если выбран формат JPG;

■ Сжатие – выберите из списка, если выбран формат TIF.

В разделе Для многостраничных изображений с помощью выпадающего списка в поле Сохранить как выберите формат TIF или PDF. Получать многостраничные документы в формате PDF также можно, как и встроенными средствами, так и с помощью приложения ImageMagick, предварительно установив его на компьютер.

С помощью переключателя выберите:

■ Преобразовать в PDF Встроенными средствами – позволяет поместить отсканированные изображения в PDF-файл.

■ Преобразовать в PDF С помощью ImageMagick – может выполняться быстрее и формировать файлы изображений меньшего размера, чем встроенными средствами. При выборе этого способа на рабочем компьютере должно быть предварительно установлено бесплатное приложение ImageMagick.

■ Укажите Путь к приложению преобразования - путь к исполняемому файлу приложения ImageMagick (по умолчанию "convert.exe"). Если это имя конфликтует с другими приложениями, с помощью кнопки Выбрать нужно указать полный путь вида "C:\Program Files\ImageMagick-6.6.3-Q8\convert.exe".

При работе в клиент-серверном варианте Преобразование с помощью ImageMagick не требует дополнительной передачи изображений на сервер 1С:Предприятие.        

Если произведенные настройки по каким-то причинам не устраивают или настраивать сканирование нет времени, можно установить настройки по умолчанию.

Для этого выполните команду Еще – Установить стандартные параметры.

Для подтверждения настроек и возврата к остальным настройкам работы с файлами нажмите кнопку ОК.  

После настройки сканирования в списке файлов в подменю Добавить появится пункт Со сканера. Подробнее см. раздел Получение файла со сканера.

Для того чтобы автоматически сохранять сведения для диагностики, включите флажок Сохранять информацию для технической поддержки. Это необходимо, например, в случае аварийного завершения приложения. Укажите путь для сохранения журнала диагностики сканирования, где будет собрана вся техническая информация по проблеме.

Также с помощью ссылки Требуется помощь откроется окно с вариантами решения типовых проблем при работе со сканированием. В иных случаях можно обратиться в службу поддержки фирмы «1С».

Также с помощью гиперссылки Информация для технической поддержки можно выгрузить техническую информацию вручную. Данные действия помогут специалистам поддержки значительно сократить время на поиск проблемы и пути ее решения.

Настройка очистки файлов

Для очистки места на компьютере и в томах хранения файлов, занимаемого «ненужными» файлами (устаревшими, добавленным случайно, а также удаленными) предусмотрена ссылка Настройка очистки файлов в разделе Администрирование – Настройки работы с файлами:

■ Ненужные файлы – это файлы, которые больше не нужно хранить в приложении согласно заданным настройкам очистки. Для просмотра информации о них следует нажать на ссылку Ненужные файлы, подробнее см. раздел Отчет «Объем ненужных файлов»;

■ Удаленные файлы – это файлы, сведения о которых удалены из приложения, но их данные еще остались в томе хранения. Посмотреть объем удаленных файлов для конкретного тома можно, перейдя в его карточку: нажать на ссылку Удаляемые файлы и дальше нажать на кнопку Проверить целостность, подробнее см. раздел Список Тома хранения файлов.

Очистку можно производить как вручную, так и автоматически по расписанию. Можно задавать произвольные правила очистки файлов. Например, можно настроить удаление вложений с низкой важностью для документов Электронное письмо входящее, созданных более года назад.

Для настройки очистки удаленных и «ненужных файлов» предусмотрено несколько способов.

С помощью кнопки Настройки очистки и команд выпадающего меню можно Добавить или Удалить настройки, например, можно добавить очистку файлов для присоединенных файлов элементов списка Демо: Партнеры.

С помощью кнопки панели навигации можно Установить действие приложения с «ненужными файлами»:

■ Очистить файлы и версии;

■ Очистить файлы;

■ Очистить версии;

■ Не очищать.

С помощью кнопки Установить период можно выбрать срок, начиная с которого файлы будут очищаться:

■ Старше месяца;

■ Старше шести месяцев;

■ Старше года.

Имеется также возможность разработать свои правила очистки файлов. Для этого в колонке Период очистки с помощью кнопки выберите значение По правилу. После этого в колонке Правило становится доступной кнопка  Изменить. Нажав ее, можно задать более точное правило отбора «ненужных» файлов. Нажмите кнопку Добавить, в выпадающем меню выберите команду Добавить новый элемент.

Например, для папки Счета можно настроить очистку файлов и их версий, которые были созданы до начала 2018 года. Для этого в окне Настройка очистки файлов: Счета с помощью кнопки Добавить введите отбор. Из списка полей выберите поле Дата Создания. Вид сравнения выберите Меньше. В колонке Значение выберите Произвольная дата, с помощью календаря выберите дату, например, 01.01.2018.

Если у объекта есть реквизит с типом Дата, то появляется возможность настройки правила очистки относительно этого реквизита, в этом случае по кнопке Добавить следует выбрать команду Добавить условие по дате. Для этого выберите нужную дату из предлагаемого списка дат документа.

Например, можно задать правило очистки файлов исходящих электронных писем с датой актуальности отправки больше 360 дней.

После подтверждения выбора и сохранения нового условия в строке списка Настройки очистки файлов становится активной ссылка Изменить, с помощью которой можно менять введенные условия отбора.

В зависимости варианта хранения файлов (подробнее см. раздел Настройка приложения) в нижнем углу таблицы настроек доступны ссылки:

■  Удаляемые файлы – открывается список Тома хранения файлов для просмотра удаляемых файлов в томах, подробнее см. раздел Список Тома хранения файлов;

■ Ненужные файлы – с помощью ссылки можно сформировать отчет Объем ненужных файлов. Подробнее см. раздел Отчет «Объем ненужных файлов».

Можно произвести очистку ненужных файлов в соответствии с настроенными правилами (Подробнее см. раздел Очистка «ненужных» файлов).

Настройка синхронизации файлов

В приложении работают и мобильные пользователи, которые постоянно синхронизируют свои устройства с учетными записями облачных сервисов.

Возможности облачных сервисов можно использовать при работе с файлами, хранящимися в приложении.

Предусмотрено использование облачных сервисов для хранения и обработки файлов, присоединенных к различным объектам приложения, а также хранящихся в списке Файлы.
Приложение позволяет видеть свои файлы в своей папке проводника или на своем сервере (там же и редактировать), а также синхронизировать их. Для этого в приложении необходимо включить возможность синхронизации файлов. Подробнее см. раздел Настройка приложения.

Настройки синхронизации проводит только администратор или пользователь группы доступа Настройка синхронизации файлов (это не персональная настройка пользователя).

Синхронизация регламентным заданием по умолчанию происходит каждые 600 секунд. Администратор при необходимости также может произвести синхронизацию вручную в любой момент времени.

Список облачных сервисов не ограничен приложением, однако используемый сервис должен соответствовать требованиям протокола WEBDAV.

В приложении доступны готовые настройки синхронизации с:

■ Яндекс.Диск;

■ Box.com;

■ Dropbox (через платный сервис dropdav).

Внимание! Для использования возможности синхронизации файлов необходимо зарегистрироваться на выбранном облачном сервисе и произвести на устройстве рекомендуемые этим сервисом настройки (подробнее см. инструкцию на выбранном облачном сервисе).

Принципы синхронизации файлов

В облачном сервисе можно наладить работу с файлами нескольких подразделений. Каждое подразделение при этом может иметь свой облачный ресурс. Необходимо убедиться, что правила отбора файлов для одного подразделения не пересекаются с правилами отбора файлов для другого подразделения. Затем администратор настраивает для каждого подразделения отдельную синхронизацию, в каждой настройке независимо задавая отбор файлов в облачный ресурс-получатель.

Редактирование и создание файлов в самом приложении будет недоступно во избежание конфликтов. Можно возобновить редактирование файлов в приложении, если отключить синхронизацию с облаком.

В облачном сервисе файлы хранятся в каталоге по шаблону <Общий путь учетной записи>\Представление объекта приложения\Представление элемента данных>:

\YandexDisk\БСП 2.3.3\Демо Заказ покупателя (Документ)\Демо Заказ Покупателя 00-00000001 от 17.12.2010 17 46 36.

Синхронизация выполняется регламентным заданием каждые 600 секунд. Также можно синхронизировать файлы вручную в любой момент времени.

При создании новых файлов или изменении существующих, файлы автоматически захватываются Автором файлов, указанным в учетной записи. Подробнее см. раздел Учетная запись синхронизации файлов.

После выполнения синхронизации освобождаются файлы, которые не были обработаны во время синхронизации (например, после изменения настроек синхронизации: раньше синхронизировали папки Счета и Шаблоны файлов, теперь только Шаблоны).

После выполнения синхронизации проверяются все неиспользуемые учетные записи. Если они захватили файлы, то файлы освобождаются. Например, если необходимо полностью отключить синхронизацию, то следует отключить все настройки с флажком Синхронизировать и при следующем выполнении регламентного задания все файлы освобождаются.

Не поддерживается механизм RLS (возможность ограничивать права доступа пользователей на уровне записей). Например, если настроить синхронизацию списка Демо: Проекты, то в облачный сервис перейдут присоединенные файлы всех элементов списка, или ограниченные настроенным правилом. Но в рамках данного проекта можно будет настроить несколько синхронизаций для одного типа объектов приложения. Условный аналог RLS – например, две учетные записи для разных проектов БСП, БП.

Настройка синхронизации

Синхронизацию с облаком для файлов, хранящихся в каталогах, или присоединенных к объекту приложения, непосредственно в списках файлов может настроить администратор или пользователь группы доступа Настройка синхронизации файлов (это не персональная настройка пользователя).

В таком случае отпадает необходимость в операциях захвата на редактирование и освобождения файлов, которые могут вызывать затруднения у неподготовленных пользователей.

Например, можно настроить синхронизацию с облаком для файлов, хранящихся в каталогах (раздел Органайзер – Файлы, команда Синхронизация с облаком в контекстном меню папки).

Для файлов, присоединенных к объекту приложения, например, к демо: проекту БСП, можно настроить синхронизацию с помощью команды Еще – Синхронизация с облаком.

Включите флажок Синхронизировать файлы с облачным сервисом, с помощью кнопки  выберите из списка учетную запись облачного сервиса, с которым будет производиться синхронизация файлов. Если нужной учетной записи в списке нет, введите новую учетную запись. Подробнее см. раздел Учетная запись синхронизации файлов.

Учетная запись синхронизации файлов

Ввести новую учетную запись можно во время настройки синхронизации файлов с помощью кнопки  Создать.

Напишите Наименование учетной записи, например, Синхронизация БСП.

В поле Сервис выберите из списка, с каким облачным сервисом будут синхронизироваться файлы данной учетной записи, например, Яндекс.Диск, в поле отобразится URL-адрес облачного сервиса.

Укажите Логин и Пароль – данные для доступа, полученные при регистрации на выбранном облачном сервисе.

В поле Корневая папка напишите папку, в которой будут храниться все файлы для этой учетной записи, например, Синхронизация БСП. Ее необходимо создать самостоятельно на облачном сервисе.

В разделе Автор новых и отредактированных файлов с помощью переключателя выберите, кто будет указываться в качестве автора файлов.

По умолчанию выбран Автор новых и отредактированных файлов.

Если файлы в облаке редактирует только один пользователь, рекомендуется указать его в качестве автора новых и измененных файлов.

В этом случае с помощью переключателя выберите Пользователь, с помощью кнопки  выберите тип пользователей, например Пользователь, нажмите ОК. Затем выберите нужного пользователя из списка, например, Администратор (подробнее см. раздел документации Пользователи).

С помощью кнопки Проверить настройки можно проконтролировать правильность заполнения данных учетной записи. В случае успешного завершения проверки выводятся данные о размере свободного места в облачном сервисе и объеме, занятом файлами. В случае неудачной проверки заполнения данных  выводятся рекомендации по устранению данной проблемы (например, можно выбрать другой сервис для синхронизации файлов или обратиться в поддержку сервиса) и технические подробности, которые можно отправить в поддержку сервиса.

Синхронизироваться могут все файлы папки или другого объекта приложения. Также при необходимости можно отбирать файлы по различным признакам.

Ссылка в каждой строке списка показывает, какие файлы будут синхронизироваться. По умолчанию синхронизируются Все файлы. Нажав на ссылку, перейдите к настройке синхронизации файлов конкретного владельца, например, Папки.

По умолчанию включен флажок Синхронизировать файлы с облачным сервисом.

В поле ниже укажите учетную запись облачного сервиса, с которым будет производиться синхронизация файлов. Нажмите кнопку , для того чтобы Выбрать учетную запись. Если нужной учетной записи в списке нет, можно ввести новую. Подробнее см. раздел Учетная запись синхронизации файлов.      

В разделе Что синхронизировать с помощью переключателя можно выбрать одно из значений:

■ Файлы, присоединенные к (по умолчанию выбран владелец файлов, указанный ранее);

■ Файлы (указывается выбранный список) по заданным правилам синхронизации.

По умолчанию выбрано второе значение, при этом в таблице ниже можно добавить новый отбор и задать правила, в соответствии с которыми должны синхронизироваться файлы. Примеры настройки правил можно посмотреть в разделе Настройка очистки файлов.

Нажмите кнопку Добавить, выполните команду Добавить новый элемент (нажмите клавишу Ins) и добавьте условия для отбора файлов. Для быстрого добавления отбора файлов по периоду выполните команду Добавить условие по дате.

После того как правило добавлено, можно указать Краткое описание правила.

Подробнее об отборах см. книгу 1С:Предприятие 8.3. Руководство пользователя. Также об отборах можно узнать в разделе документации Варианты отчетов.

После окончания настройки синхронизации краткое описание правила выводится в списке Настройки синхронизации файлов.

Также можно указать других владельцев файлов и в списке Настройки синхронизации впоследствии. Для разных владельцев файлов могут быть указаны разные учетные записи.

Можно настроить автоматическую синхронизацию файлов. Для этого включите флажок Автоматически синхронизировать файлы, после этого становится доступной ссылка Настроить расписание. Перейдите по ссылке для настройки расписания. Подробнее см. раздел документации Регламентные задания. После подтверждения расписания оно отражается под флажком. Синхронизация регламентным заданием по умолчанию происходит каждые 600 секунд.

Синхронизацию файлов также можно произвести вручную в любой момент времени с помощью кнопки Синхронизировать.

Можно настроить синхронизацию и в карточке объекта-владельца, например, в списке Файлы. Подробнее см. раздел Настройка синхронизации.

Работа с использованием синхронизации файлов с облачными сервисами

Работа с файлами в облачном сервисе проводится как в Проводнике: «отредактировал и закрыл». В таком случае отпадает необходимость в операциях захвата на редактирование и освобождения файлов, которые могут вызывать затруднения у неподготовленных пользователей. Для того чтобы изменить файл, надо его скачать из облачного сервиса, отредактировать, и не забыть закачать обратно.

Файлы, настроенные на синхронизацию, редактируются только в облачном сервисе. Список файлов в приложении также становится недоступным и обновляется только с помощью синхронизации с облачным сервисом.

Присоединить новые файлы к такому объекту также можно только в облачном сервисе.

Перейдите по ссылке, для того чтобы открыть облачный сервис для работы с файлами. Ссылка принимает наименование учетной записи синхронизации файлов, например, Синхронизация БСП (подробнее см. раздел Учетная запись синхронизации файлов).

В списке Файлы все папки, которые синхронизируются с облачным сервисом, отмечены значком .

Список файлов

Как было сказано выше (см. раздел Список Присоединенные файлы), файлы можно связать с объектами приложения. Но существует возможность хранить файлы без привязки к конкретному объекту. Для этих целей в приложении используется список Файлы (открывается командой в разделе Органайзер).

Работа с файлами в списке организована таким же образом, как и работа с файлами в объектах приложения. В список можно добавлять новые файлы, копировать, изменять или удалять их. Подробнее см. разделы Команды для работы с файлами в списке и Карточка файла.

Работа со списком организована аналогично работе в Проводнике Windows. Левая часть списка содержит иерархическую структуру папок. В правой части отображаются файлы выделенной папки.

С помощью команды Еще – Настройки – Использовать иерархию можно изменить вид списка и увидеть все файлы, находящиеся в разных папках, в одном списке.

Зеленым цветом в списке отображаются файлы, занятые текущим пользователем, а серым – файлы, занятые другими пользователями приложения.

В списке можно создать необходимое количество папок и хранить в них файлы, непривязанные к конкретным объектам приложения. Создать папку можно с помощью кнопки  или команды контекстного меню левой части списка.

Создание файла из имеющегося файла на компьютере

После этого приложение сохранит файл и откроет для заполнения Карточку файла (см. раздел Карточка файла).

Наименование заполняется автоматически, заполните описание шаблона, поле Папка по умолчанию заполнено – Шаблоны файлов. После сохранения новый шаблон можно использовать для создания файлов.

Создание файла по шаблону

Для создания файла По шаблону (см. раздел Шаблоны файлов) нажмите кнопку  или Добавить, выберите команду из выпадающего меню. Для выбора предлагается папка Шаблоны файлов. Выделите шаблон файла в списке, затем нажмите кнопку Выбрать.

Приложением будет автоматически создана и открыта карточка файла. Подробнее см. раздел Карточка файла.

Получение файла со сканера

Для того чтобы был доступен вариант получения файла путем сканирования изображения, необходимо подключить сканер к компьютеру (подробнее см. документацию к сканеру), а также настроить сканирование (см. раздел Настройка сканирования).

Если все условия соблюдены и настройки выполнены, можно Добавить файл Со сканера. Для этого необходимо выбрать вариант добавления файла и следовать инструкциям приложения.

После того как документ отсканирован, нажмите кнопку Сохранить, после этого файлу автоматически присваивается код и он появляется в списке.

Создается Карточка файла, которую можно просмотреть с помощью команды меню Еще (подробнее см. раздел Карточка файла).

Можно нажать кнопку Сканировать, если необходимо отсканировать сразу несколько документов. Также можно Пересканировать документ, если качество сканирования не устраивает.

Для того чтобы изменить параметры сканирования, выполните команду Настройка меню Еще, установите новые параметры и нажмите кнопку ОК.

Если отсканировано несколько изображений, то становятся доступными кнопки Сохранить как один файл (т. е. создать многостраничный документ) и Сохранить как отдельные файлы.

Карточка файла

Карточка файла содержит различные сведения о файле (автор файла и дата его создания, кто и когда начал редактировать файл и т. д.) и его текущей версии, об объекте приложения – владельце файла, а также команды основных действий с файлом.

Карточка создается автоматически при создании файла, при этом приложение по умолчанию заполняет все поля, кроме поля Описание.

При создании файла из шаблона или из другого файла на компьютере поле Наименование по умолчанию заполняется именем шаблона или файла-оригинала.

При получении файла со сканера приложение по умолчанию заполняет поле Наименование файла числовым кодом, который совпадает с номером файла в списке отсканированных файлов, (подробнее см. раздел Список номеров отсканированных файлов).

При необходимости наименование можно изменить.

Также можно заполнить Описание, указав подробную информацию о файле.

Открыть карточку можно в списке файлов, используя клавишу F2 или команду меню Еще.

Над файлами можно выполнить следующие действия:

■ Просмотреть – открыть файл внешним приложением для просмотра или редактирования, в зависимости от того, помечен или нет файл как занятый для редактирования;

■ Редактировать – открыть файл в режиме редактирования, при этом производится захват файла в приложении. Захваченный файл будет недоступен для редактирования другим пользователям приложения (подробнее см. раздел Редактирование файлов);

■ Закончить редактирование – освободить файл, сохранить его в приложении и снять пометку занятости для редактирования. Если включен флажок Хранить версии (см. ниже), то приложение предложит сохранить очередную версию файла (подробнее см. раздел Список версий);

■ Сохранить изменения – сохранить версию редактируемого файла в приложении, но оставить его занятым для редактирования;

■ Сохранить как – сохранить файл в указанный каталог на жестком или сетевом диске;

■ Если включить флажок Хранить версии, то после завершения редактирования файла будет сохраняться очередная его версия. Необходимость данного флажка для объектов приложения определяется разработчиком, его может и не быть в карточке файла. Об использовании флажка см. раздел Список версий.

Остальные команды для работы с файлами размещены в меню Еще:

■ Занять – пометить файл в приложении как занятый для редактирования, не открывая внешнее приложение. Приступить непосредственно к редактированию можно позже;

■ Отменить редактирование – снять с файла пометку занятости для редактирования;

■ Обновить из файла на компьютере – заново загрузить файл из оригинального файла на компьютере (из которого изначально был создан файл в приложении). Укажите путь к файлу;

■ Открыть каталог файла в Проводнике Windows.

Если в приложении используется электронная подпись и шифрование, то для файлов становятся доступными ряд команд и вкладок в карточке файла. Подробнее см. раздел документации Электронная подпись.

При этом набор команд карточки зависит от установленных ролей, например, в карточке файла, присоединенного внешним пользователем, отсутствуют некоторые предусмотренные команды, скрыты поля Автор, Изменил и другие, содержащие персональные данные или данные о подписании.

Размещение файлов в папках

Файлы можно перемещать в различные папки списка Файлы с помощью перетаскивания мышью.

В карточке файла можно присоединить файл к одному из объектов приложения или поместить в одну из папок списка файлов.

В поле Папка нажмите кнопку  Выбрать.

Для того чтобы присоединить файл к одному из объектов приложения, выберите его из списка типов данных (например, Партнер), нажмите кнопку ОК, выберите из списка (например, Демо: Партнеры) нужный элемент (например, Закрытое акционерное общество "Дальстрой"), в карточке файла нажмите кнопку Записать и закрыть.

Для того чтобы поместить файл в одну из папок списка Файлы, выберите в списке значение Папка, нажмите кнопку ОК. Выделите нужную папку, нажмите кнопку  Выбрать.

Таким образом, владельцем файла в приложении может быть как конкретный объект, так и папка списка Файлы.

Папкам можно назначать различные права доступа (подробнее см. раздел документации Управление доступом).

В списке имеются предопределенные папки, которые нельзя удалить, например, папка Шаблоны файлов (подробнее см. раздел Шаблоны файлов).

Загрузка файлов и папок

С помощью команды Загрузить файлы меню Еще можно разместить файлы с компьютера в одной из папок списка.

Укажите путь к каталогу для загрузки файла, нажмите кнопку Открыть.

В открывшемся окне Загрузка файлов приводится список выбранных файлов.

Если список файлов не устраивает, нажмите кнопку Выбрать, для того чтобы обнулить список и выбрать новые файлы. Предыдущий выбор не сохраняется. Нельзя выбрать файлы в несколько приемов.

В поле Папка автоматически проставляется текущая папка списка.

Можно изменить Папку, в которую будут загружаться файлы, с помощью кнопки  Выбрать из списка.

Включите флажок, для того чтобы Удалять файлы после добавления.

Напишите Описание для создаваемых файлов.

Включите флажок, для того чтобы Хранить версии файлов.

Нажмите ссылку, для того чтобы Выбрать кодировку текстовых файлов.

Выберите кодировку из списка, нажмите Выбрать. По умолчанию включен флажок Показывать только основные кодировки.

После завершения выбора ссылка показывает выбранную кодировку. Для загрузки файлов после установки всех необходимых параметров нажмите кнопку Загрузить файлы.

При загрузке приложение проверяет размер файлов и их расширения. Если размер файла больше указанного ограничения в поле Максимальный размер файла или его расширение перечислено в списке запрещенных для загрузки (см. раздел Настройка приложения), то такой файл загружен не будет. Приложение выводит список таких файлов. Можно продолжить загрузку, нажав кнопку Продолжить импорт, в этом случае файлы, удовлетворяющие условиям, будут загружены.

После попытки загрузки приложение выводит список тех файлов, которые не были загружены.

Загрузка папки

Для того чтобы поместить каталог с компьютера в одну из папок списка Файлы, выполните команду Загрузить папку контекстного меню по правой кнопке мыши, укажите путь к каталогу, нажмите кнопку Выбор папки.

Загрузка каталога немного отличается от описанной выше загрузки файлов.

В открывшемся окне Загрузка папки приложение по умолчанию заполняет поле Каталог на компьютере. С помощью кнопки  можно Выбрать другой Каталог на компьютере. После указания необходимых параметров нажмите кнопку Загрузить папку.

Загрузка файлов и папок с помощью перетаскивания

Также можно перетащить файл (папку) или несколько выбранных файлов (папок) из Проводника Windows в нужную папку списка Файлы с помощью мыши.

Один перетаскиваемый файл сразу помещается в список файлов, автоматически создается карточка файла.

При перетаскивании нескольких файлов, папки или нескольких папок необходимо заполнить сведения о файлах или папках.

Файлы, которые перетаскивались мышью для загрузки, выводятся в виде списка.

Папки, которые перетаскивались мышью для загрузки, выводятся в виде дерева. При этом можно раскрыть каждую папку и просмотреть файлы, которые в нее входят.

С помощью флажков можно указать папки и файлы, которые будут загружены в приложение.

В остальном загрузка аналогична предыдущим способам.

Сохранение папки на компьютер

Команда Сохранить папку (расположена в контекстном меню папки) позволяет скопировать выбранную папку с файлами из приложения на компьютер. При этом копируются только активные версии файлов. Укажите путь к каталогу для загрузки файлов, затем нажмите кнопку Сохранить папку.

Если включить флажок Транслитерировать имена папок и файлов, то сохраненные файлы будут иметь имена, содержащие только латинские буквы и цифры. Это полезно для возможности переноса файлов между различными операционными системами, в которых не поддерживается кириллица. Например, файл Отчет.mxl будет сохранен с именем Otchet.mxl.

Настройка прав для доступа к папкам и файлам

Для использования данной возможности пользователям необходимо установить роль Добавление и изменение папок и файлов, также должен быть включен флажок Ограничивать доступ на уровне записей.

Для работы внешних пользователей в списке файлов им необходимо установить роль Добавление и изменение папок и файлов внешними пользователями.

К конкретной папке файлов или файлу можно Настроить права с помощью кнопки панели навигации. В открывшемся окне Права доступа можно указать, какие пользователи (или группы пользователей) должны иметь доступ к папке. Для этого нажмите Добавить,  Выберите нужный список пользователей, подберите нужных пользователей или внешних пользователей из списка.

Установка прав осуществляется с помощью значений Да или Нет в колонках таблицы. Настройку могут выполнять пользователи с установленным правом администрирования (Да в колонке Управление правами) для этого объекта. Установив значение Нет в колонке Для подпапок, можно отказаться от наследования настроек прав доступа, заданных для родительской папки файлов.

В колонках таблицы можно включить права на чтение, добавление, изменение и установку пометки удаления для папки и файлов в ней:

■ Чтение;

■ Изменение папок;

■ Изменение файлов;

■ Пометка удаления.

Подробнее см. раздел документации Управление доступом.

Редактирование файлов

Выделите файл в списке, нажмите кнопку Редактировать. Редактирование файлов табличных документов (формата MXL) осуществляется во встроенном редакторе табличных документов. Подробнее о редактировании табличных документов см. раздел документации Печать.

Для редактирования файлов других форматов на компьютере должны быть установлены внешние приложения, например, для редактирования файлов в формате Microsoft Word должно быть установлено это приложение.

После окончания редактирования сохраните файл, закройте внешнее приложение. Для сохранения файла в приложении нажмите кнопку Закончить.

Список Редактируемые файлы

Список файлов, занятых для редактирования, обычно выводится приложением при завершении работы. Можно прекратить вывод этого сообщения, выключив флажок Показывать занятые файлы при завершении работы. Подробнее см. раздел Персональные настройки.

Для того чтобы увидеть список только захваченных для редактирования файлов, можно также воспользоваться командой Редактируемые файлы в разделе Органайзер. В списке отображаются файлы, захваченные вами для редактирования.

В списке Редактируемые файлы доступны кнопки для просмотра файлов и завершения редактирования:

■ Просмотреть файл;

■ Закончить редактирование;

■ Открыть карточку файла (подробнее см. раздел Карточка файла).

Удаление файлов без возможности восстановления

Во время работы с файлами может возникнуть необходимость удалить их безвозвратно и быстро (например, к объекту случайно присоединена конфиденциальная информация, которую никто не должен видеть). Для того чтобы удалить выделенные файлы без возможности восстановления, можно воспользоваться командой Удалить контекстного меню по правой кнопке мыши. Также команду можно найти:

■ В списках файлов – в меню Еще – Дополнительно.

■ В карточке файла в меню Еще.

Файл, который был удален скрывается из списка (показывается по команде Еще – Показать помеченные на удаление, подробнее см. раздел Команды для работы с файлами в списке). Если файл версионируется (подробнее о настройке хранения версий см. раздел Карточка файла), версии файла также удаляются.

Операция удаления является необратимой. При попытке просмотреть или отредактировать файл, удаленный без восстановления, выводится сообщение, что файл открыть не удалось. Даже если снять с такого файла пометку на удаление, его уже нельзя будет просмотреть или редактировать.

Если нет необходимости удалять файл безвозвратно следует использовать функцию Удаление помеченных объектов.

При использовании команды Удалить имеются некоторые ограничения:

■ Удалить файл безвозвратно может только его автор.

■ Занятые для редактирования файлы удалить невозможно.

■ Если файл версионируется (подробнее см. раздел Карточка файла) и есть версии за авторством другого пользователя (т. е. файл редактировался, и в него вносили изменения другие пользователи), то по команде Удалить будут удалены только версии автора. Дальнейшая работа с таким файлом по его удалению проводится в списке версий.

Список версий

После редактирования и сохранения файла приложение может хранить его предыдущие версии. Для того чтобы воспользоваться этой функцией, необходимо включить флажок Хранить версии в карточке файла. Функция может быть недоступна для некоторых объектов приложения. Список версий открывается с помощью ссылки Версии файла на панели навигации карточки файла. Подробнее см. раздел Карточка файла.

В списке с помощью кнопок панели навигации можно:

■ Просмотреть – открыть версию файла соответствующим приложением для просмотра (также можно это сделать двойным щелчком мыши);

■ Открыть карточку – просмотреть данные о версии файла;

■ Сделать активной – установить выбранную версию файла текущей. Кнопка доступна только для незанятых файлов;

■ Показать отличия – сравнить две любые версии файла, предварительно выделив их. Сравнение версий поддерживается для файлов формата HTML, TXT, RTF, DOC, DOCX, ODT (можно настроить приложение, с помощью которой производить сравнение, см. раздел Персональные настройки).

С помощью команды Сохранить как меню Еще в списке версий (или с помощью кнопки в карточке версии) также можно записать версию файла на компьютер. Укажите путь на компьютере для сохранения версии файла.

Автор может безвозвратно Удалить файлы с помощью команды контекстного меню или меню Еще – Дополнительно в списке файлов. Эта функция полезна, если возникает ситуация, когда файл или одну из его версий нужно удалить безвозвратно и быстро из-за того, что, например, к документу случайно была присоединена конфиденциальная информация или при редактировании файла в одну из версий были добавлены конфиденциальные данные. При этом если у файла хранятся версии и среди них есть версии за авторством других пользователей, то удаляются только версии автора. Для полного удаления файла необходимо, чтобы соавторы также удалили свои версии. В списке версий файла их можно пометить на удаление с помощью команды Удалить. При этом:

■ первую версию нельзя удалить отдельно от файла;

■ если удаляется активная версия файла, версия файла автоматически переключается на максимальную, не помеченную на удаление.

Для удобства помеченные на удаление версии файлов скрываются в списке. Однако их можно показать с помощью команды Показывать помеченные файлы.

После удаления всех версий файл уже не подлежит восстановлению, при попытке открыть его в списке файлов приложение выводит соответствующее сообщение. Подробнее см. раздел Удаление файлов без возможности восстановления. Окончательно удалить такие файлы, как и любые другие объекты, помеченные на удаление, может администратор приложения. Подробнее см. раздел документации Удаление помеченных объектов.

Хранение файлов в томах на сервере

Для использования данной возможности выберите этот способ хранения файлов (подробнее см. раздел Настройка приложения).

Хранение файлов в томах позволяет вынести файлы из приложения и хранить их внешним образом в сетевом каталоге. Рекомендуется для "разгрузки" больших баз. Подробнее о переносе файлов в тома см. раздел Перенос файлов в тома и обратно.

Преимущества хранения файлов в томах на сервере:

■ уменьшается объем приложения. Файлы могут занимать существенный объем, значительно превышающий объем всех остальных данных приложения. В таком случае работа приложения существенно замедляется;

■ объем тома ограничен только объемом жесткого диска;

■ можно организовать проверку файлов на наличие вирусов;

■ простой способ организации резервного копирования файлов.

Преимущества хранения файлов в информационной базе:

■ все данные находятся в одном месте – в информационной базе;

■ для резервного копирования достаточно стандартных средств платформы 1С:Предприятие или СУБД.

Необходимо помнить, что хранение файлов в информационной базе подходит только для баз с небольшим количеством (объемом) файлов.

Предусмотрена возможность хранения файлов в томах и в информационной базе, сочетая преимущества обоих способов хранения (выбрать способ хранения можно с помощью переключателя Хранить файлы в разделе Администрирование – Настройки работы с файлами). Можно раздельно хранить наиболее важные файлы в информационной базе, а менее важные – в томах на сервере. Можно указать расширения файлов, которые должны храниться в информационной базе, а также установить ограничение на их максимальный размер, подробнее см. раздел Настройка приложения.

Изменение выбора способов хранения файлов обратной силы не имеет. Например, если хранение файлов в томах отключили, то новые файлы добавляются в само приложение, а старые файлы остаются в томах. При этом каталог с томом будет продолжать использоваться до того, пока в базе есть хотя бы один старый файл. Перенести файлы обратно в приложение можно с помощью кнопки в панели навигации тома хранения файлов или с помощью команды раздела Администрирование – Настройки работы с файлами.

Если сохранить файл в томе, а потом удалить том (внешними средствами), то при открытии из приложения файл будет отсутствовать, даже если выбран способ, при котором файлы хранятся в приложении. Изменение способа хранения файлов не вернет пропавшие файлы.

Поэтому если приложение не находит файлы, которые хранились в томах, следует в сообщениях о проблеме в журнале регистрации посмотреть путь к каталогу с томом, проверить местонахождение этого каталога, наличие в ней нужного файла, и при необходимости восстановить каталог. Для осуществления такой возможности необходимо периодически проводить резервное копирование папок с томами файлов внешними средствами (подробнее см. раздел Работа с томами хранения файлов).

Если включить флажок Создавать подкаталоги с именами справочников-владельцев файлов (см. раздел Настройка приложения), в томах будут создаваться дополнительные подкаталоги, в которых размещаются файлы. Например, файлы, находящиеся в папках в списке Файлы в приложении, будут размещаться в томе в подкаталоге Папки, а присоединенные файлы к счетам на оплату – в подкаталогах СчетаНаОплату. Это позволяет настраивать резервное копирование файлов в томах раздельно для важных файлов, которые принадлежат к нужным документам. Изменение данной настройки распространяется только на вновь добавляемые файлы и не имеет обратной силы для уже существующих файлов в томах.

Тома хранения файлов в распределенной информационной базе (РИБ)

При работе в распределенной информационной базе (РИБ) способ хранения файлов настраивается независимо в каждом узле. Например, в главном узле могут быть включены тома, а в подчиненных узлах файлы хранятся в информационной базе, или наоборот.

Напротив, если настраивать в разных узлах одни и те же тома хранения файлов (сетевые каталоги), то это приведет к конфликтам. Также файлы в томе, относящиеся к другим узлам, будут считаться «лишними» и могут быть очищены.

Если в главном узле файлы хранятся в томах, то при создании нового узла РИБ вместе с созданием начального образа будет выгружен архив с хранимыми файлами (для этого необходимо указать полное имя архива с файлами томов). Затем в подчиненном узле для того, чтобы получить файлы из архива, необходимо в Настройках синхронизации данных выполнить синхронизацию с главным узлом. Для этого нужно нажать на кнопку Синхронизировать . Подробнее см. раздел документации Обмен данными (Синхронизация данных с другими приложениями и РИБ).

Особенности заполнения поля Полный путь для Linux

Поля Полный путь для сервера 1С:Предприятия под управлением Microsoft Windows и Полный путь для сервера 1С:Предприятия под управлением Linux должны ссылаться на один и тот же физический сетевой каталог. Нужно заполнять в том случае, если в кластере есть сервера как под управлением Microsoft Windows, так и Linux.

Если сервер 1С:Предприятия работает под Linux, то путь к тому хранения файлов можно указать только локальный, например /home/path. Для того чтобы использовать UNC путь, нужно сделать на него ссылку. Для этого под правами администратора сделайте следующее:

■ выполните команду вида mkdir folder, где вместо "folder" напишите имя своего каталога. Например, в каталоге /home выполните команду mkdir shared – будет создан каталог shared с полным путем /home/shared;

■ выполните команду вида mount -t cifs //server/share folder -o //domain/user, password=pwd, где //server/share – UNC путь к другому компьютеру, folder – путь к каталогу на Linux компьютере, например \home\shared, //domain/user – имя домена/пользователя, если необходимо, pwd – пароль пользователя (если необходимо). Если имя и пароль не нужны, команда выглядит так: mount -t cifs //server/share folder;

■ после этого в пути к тому указываем folder, например /home/shared.

Особенности при работе в приложении в Интернете

■ Тома хранения файлов поддерживают виртуальные URL, задаваемые в профилях безопасности.

В случае, когда для приложения не могут быть использованы профили безопасности, можно использовать параметр «%z» в абсолютном пути к тому хранения. Для повышения безопасности и организации хранения файлов при работе приложения в Интернете (технология 1С:Fresh http://v8.1c.ru/fresh/whatis.htm) можно настроить раздельное хранение файлов каждого абонента (области данных) в подкаталогах. Для этого в полном пути тома необходимо указать %z. Например, \\server\files\user%z.

Работа с томами хранения файлов

При создании нового тома автоматически проверяется доступ к каталогу, указанному в поле Полный путь, в случае некорректной настройки выводится сообщение. Уже созданному тому нельзя поменять пути.

Заполнение томов осуществляется по порядку (по возрастанию) до полного заполнения тома. Эту особенность можно использовать для временного отключения тома путем увеличения ему порядка заполнения.

Созданный том (т. е. объект приложения) нельзя удалить до тех пор, пока на него ссылаются какие-либо версии файлов.

Однако необходимо помнить, что физически тома представляют собой каталоги на компьютере, которые можно удалить средствами Windows в любой момент или перенести в другое место, тогда файлы из этого тома уже невозможно будет найти.

Проблемы доступа к томам помещаются в журнал регистрации и могут быть просмотрены администратором приложения. Подробнее см. раздел документации Настройки приложения.

После переключения режима хранения файлов (например, в значение В томах на сервере) все ранее накопленные файлы не перемещаются в тома – только вновь добавленные файлы будут размещаться в соответствии с настройкой. Для того чтобы перенести ранее накопленные файлы из информационной базы в тома, нажмите кнопку Перенести файлы в списке Тома хранения файлов (подробнее см. раздел Перенос файлов в тома и обратно).

Если используется синхронизация данных между приложением-источником и приложением-приемником и при этом в приложении-источнике используется хранение файлов в томах на серверах, то в процессе создания начального образа необходимо будет создать архивный файл с томами хранимых файлов.

В процессе получения начального образа в приложение-приемник необходимо будет указать и расположение архивного файла с томами хранимых файлов. Для получения файлов в томах из архива выполните команду Разместить файлы начального образа панели действий раздела Органайзер.

Для использования томов, расположенных на сетевых дисках, сервер 1С:Предприятия 8 нужно запускать от лица доменного пользователя вида domain1\user1, имеющего права доступа к тому, указанному в виде UNC пути. Этот пользователь должен входить в группу Users локального компьютера, иметь права Run as service и Run as batch job и права на каталоги, в которых сервер 1С:Предприятия 8 хранит служебные файлы – журнал регистрации, каталог временных файлов и пр.

Просмотр списка файлов в томе

В каждом томе файлы хранятся в подкаталогах. На каждую дату создания версии файла создается свой подкаталог. Все файлы хранятся с оригинальным именем и расширением, между ними добавляется номер версии, например Приказ.2.txt.

Для того чтобы просмотреть список файлов в томе, перейдите по ссылке Файлы в томе на панели навигации тома.

Типовые проблемы и их решение

Проблема при создании каталога (файла)

При добавлении нового файла или изменении существующего возникает Проблема при создании каталога. В томах файлы хранятся в подкаталогах. Они создаются автоматически, например, приложение в данном случае пыталась создать каталог \\Storage\Volume2\20210805\.

Необходимо проверить наличие полных прав на каталог тома (например \\Storage\Volume2) у пользователей, от имени которых запущена службы 1С:Предприятия и веб-сервера (при его наличии). См. также Ввод тома хранения файлов.

Изменился путь к тому хранения файлов / Том хранения файлов перенесен на другой компьютер

В приложении настроено хранение файлов в томах, указан путь к сетевому каталогу с томом хранения файлов. Затем произошел сбой компьютера, покупка нового или смена компьютера. После чего каталог с файлами перенесли в другое расположение, например, на другой компьютер.

Для того чтобы продолжать работу с файлами, перенесенными в другой сетевой каталог, необходимо изменить путь в томах хранения файлов на новое месторасположение. Подробнее см. раздел Ввод тома хранения файлов.

При этом неправильно добавлять новый том с новым месторасположением, а старый помечать на удаление. Это вызовет ситуацию, описанную в разделе: Файл не существует в хранилище файлов.

Файл не существует в хранилище файлов

При открытии файла возникает сообщение «Файл не существует в хранилище файлов. Возможно, файл удален антивирусным приложением. Обратитесь к администратору» или «Не удалось открыть файл ххх по причине: двоичные данные файла были удалены. Возможно, файл очищен как ненужный или удален антивирусным приложением. Обратитесь к администратору».

Подробности проблемы следует искать в журнале регистрации на момент времени, соответствующий неудачной попытке открытия файла. В сообщении о проблеме в журнале регистрации указан полный путь к разыскиваемому файлу в томе.

Возможно, была некорректно удален или перенесен сетевой каталог с томом (см. например раздел Изменился путь к тому хранения файлов /Том хранения файлов перенесен на другой компьютер).

Для того чтобы подобных ситуаций не возникало, рекомендуется ответственно относиться к тому хранения файлов, организовать его резервное копирование и своевременное восстановление утерянных файлов.

Перенос файлов в тома и обратно

Для переноса файлов в том хранения большего размера или для создания тома хранения архивных файлов предусмотрена команда Перенос файлов в разделе Администрирование – Настройка работы с файлами. Для редких случаев, когда необходимо отказаться от хранения файлов в томах на сервере, с помощью этой же команды можно перенести файлы из томов на сервере в приложение. Можно перенести файлы только указанного владельца или определенного типа.

При переносе файлов можно указать дополнительные условия, например, для того чтобы перенести только часть файлов из тома хранения в архив, или перенести из приложения в тома только файлы большого объема.

С помощью переключателя можно указать, куда Перенести файлы (недоступно, если файлы хранятся в приложении):

■ Между томами;

■ Из информационной базы в тома;

■ Из томов в информационную базу.

В разделе Настройки с помощью флажков можно указать:

■ В указанный том – выберите том из списка, например, Основной том;

■ Из указанного тома – выберите том из списка, например, Резервный том.

■ Файлы указанного владельца – можно перенести только часть файлов, например, файлы, присоединенные к элементам списка Демо: Организации. Для этого выберите владельца из списка;

■ Созданные – укажите дату, для того чтобы перенести файлы только за указанный период.

■ С указанным расширением – выберите тип файлов для переноса (изображения или электронные документы) – это может быть полезно, например, если необходимо проводить резервное копирование электронных документов или организовать архив. Документы можно собирать в одну папку по определенному признаку. Можно хранить на компьютере файлы изображений, которые будут занимать много места в приложении, при этом остальные документы можно оставить в приложении;

■ По дополнительным условиям, например, Автор равно Администратор – с помощью этого условия будут перенесены только файлы, автором которых является администратор. Или, например, чтобы перенести файлы за нужный период, можно задать условие вида: Дата создания.Части Дат.Год Равно "2019" И Дата создания.Части дат.Год Равно "2020".

При смене способа хранения файлов автоматический перенос файлов из приложения в тома и обратно не происходит. Если сначала было принято решение хранить файлы в томах на сервере и какое-то время файлы хранились в томах, а потом было решено отыграть всё назад, можно перенести файлы из томов обратно в приложение с помощью команды Перенос файлов.

Перенос файлов занимает некоторое время, которое зависит от их объема.

При переносе приложение может не уменьшится сразу. В таком случае необходимо уменьшить размер приложения. Подробнее см. раздел Уменьшение размера приложения.

Уменьшение размера приложения

Дедупликация файлов

Для того чтобы сэкономить место в приложении можно выполнить дедупликацию файлов. Дедупликация файлов позволяет экономить до 30% места в приложении за счет устранения дублей файлов, хранящихся в приложении.

Для дедупликации файлов предусмотрена ссылка Выполнить дедупликацию в разделе Администрирование – Настройки работы с файлами.

Дедупликация занимает от нескольких минут до нескольких часов в зависимости от объема файлов в приложении. В любой момент ее можно будет приостановить с помощью кнопки Прервать и возобновить позднее в более подходящий момент времени, при этом все вновь добавленные файлы автоматически будут сохраняться в одном экземпляре.

Во время дедупликации файлов размер приложения может существенно вырасти, поэтому перед запуском рекомендуется убедиться, что имеется достаточно свободного места на компьютере, где размещено приложение (не менее 19,87 Мб).

Также необходимо сделать резервную копию приложения.

После завершения выполнить сжатие информационной базы, для того чтобы дедупликация вступила в силу. 

Сжатие информационной базы

Для уменьшения информационной базы следует выполнить сжатие таблиц информационной базы. При сжатии система осуществляет пересоздание таблиц баз данных. Таким образом, физический размер информационной базы уменьшится и приложение будет работать быстрее за счет оптимизации размещения всех компонентов базы.

Для того чтобы сжать информационную базу запустите приложение в режиме Конфигуратор, далее в меню Администрирование выберите Тестирование и исправление. В форме Тестирование и исправление информационной базы следует установить флажок Сжатие информационной базы - Выполнить.

Важно! Перед выполнением процедуры сжатия ИБ следует создать резервную копию рабочей информационной базы.

Данный способ сжатия подходит только для файлового приложения.

Если приложение - клиент-серверное, то при правильной настройке сервера база всегда находится в сжатом виде и дополнительных действий со стороны пользователя не требует (подробнее см. в Регламентные операции на уровне СУБД для MS SQL Server :: MS SQL Server :: Методическая поддержка для разработчиков и администраторов 1С:Предприятия 8 (1c.ru)).
