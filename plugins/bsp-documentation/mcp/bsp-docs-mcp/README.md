# Внутренний компонент MCP БСП

Этот каталог — внутренний компонент Codex plugin `BSP Documentation`.

Используйте установку plugin из корневого README. Runner plugin сам передаёт каталог данных и создаёт runtime-окружение.

`search_bsp` требует `OPENROUTER_API_KEY`; остальные навигационные и read-only методы могут работать без него. В установленном plugin ключ передаётся из пользовательского окружения через `.mcp.json` и не должен храниться в репозитории.

Поставляемый SQLite-индекс построен моделью `qwen/qwen3-embedding-8b`. Query-time модель должна точно совпадать с полем `model` в metadata индекса. Runtime проверяет это до поиска. Смена `BSP_EMBEDDING_MODEL` допустима только вместе с полной пересборкой и заменой индекса.
