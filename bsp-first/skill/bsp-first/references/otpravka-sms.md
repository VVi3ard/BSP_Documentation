##### Настройка и использование

## ОтправкаSMS.НастройкаОтправкиSMSВыполнена()

> 3.1.11: есть, контекст С, вызовов в типовых: 23

Проверяет правильность сохраненных настроек отправки SMS.

```bsl
Результат = ОтправкаSMS.НастройкаОтправкиSMSВыполнена()

//
Если Не ОтправкаSMS.НастройкаОтправкиSMSВыполнена() Тогда
    РезультатОтправки.Ошибка = Истина;
    РезультатОтправки.ТекстОшибки = НСтр("ru = 'Ошибка при отправке SMS: не выполнена настройка отправки.'");
    Возврат РезультатОтправки;
КонецЕсли;
```

## ОтправкаSMSКлиент.ОтправитьSMS(НомераПолучателей, Текст, ДополнительныеПараметры)

> 3.1.11: есть, контекст К, вызовов в типовых: 12

Для вызова с клиента: Открывает форму для отправки нового SMS. Для вызова с сервера: Отправляет SMS через настроенного поставщика услуги, возвращает идентификатор сообщения.

```bsl
ОтправкаSMSКлиент.ОтправитьSMS(НомераПолучателей, Текст, ДополнительныеПараметры)
```

## ОтправкаSMS.СтатусДоставки(ИдентификаторСообщения)

> 3.1.11: есть, контекст С, вызовов в типовых: 4

Запрашивает статус доставки сообщения у поставщика услуг.

```bsl
Результат = ОтправкаSMS.СтатусДоставки(ИдентификаторСообщения)
```

## ОтправкаSMS.ДоступнаОтправкаSMS()

> 3.1.11: есть, контекст С, вызовов в типовых: 0

Проверяет возможность отправки SMS для текущего пользователя.

```bsl
Результат = ОтправкаSMS.ДоступнаОтправкаSMS()
```
