## ОбщегоНазначенияКлиентСервер.РаспределитьСуммуПропорциональноКоэффициентам(РаспределяемаяСумма, Коэффициенты, Точность)

> 3.1.11: есть, контекст КС, вызовов в типовых: 38

Выполняет пропорциональное распределение суммы в соответствии с заданными коэффициентами распределения

```bsl
Коэффициенты = Новый Массив;
Коэффициенты.Добавить(1);
Коэффициенты.Добавить(2);
Результат = ОбщегоНазначенияКлиентСервер.РаспределитьСуммуПропорциональноКоэффициентам(1, Коэффициенты); // Результат = [0.33, 0.67]
```
