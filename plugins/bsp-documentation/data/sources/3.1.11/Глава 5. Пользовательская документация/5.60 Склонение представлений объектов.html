5.60 Склонение представлений объектов

С помощью приложения можно обеспечить склонение представления, в том числе сложносоставного названия любого объекта в нужном падеже, например, при заполнении печатной формы.

Приложение позволяет хранить склонения представлений, а также исправлять некорректные склонения.

Настройки приложения

По умолчанию в приложении склонение представлений проводится собственными средствами.

При необходимости можно использовать альтернативный сервис склонения «Морфер». Для того чтобы можно было использовать в приложении склонение представлений с помощью внешнего сервиса склонений, включите флажок Использовать альтернативный сервис склонения «Морфер» в разделе Администрирование – Интернет-поддержка и сервисы – Склонения представлений объектов. После этого становится доступной ссылка Настройка доступа к сервису «Морфер».

Внимание! Для использования внешнего сервиса склонений необходимо постоянное подключение к Интернету.

С помощью ссылки Настройка доступа к сервису «Морфер» можно ввести параметры авторизации на сервисе склонения http://www.morpher.ru/.

По умолчанию используется Анонимный вход, который обеспечивает базовые возможности использования сервиса Морфер. Анонимное использование сервиса склонений имеет ограничения. Перейдите по ссылке, для того чтобы узнать о них.

Если уже имеется регистрация на сайте Морфер, с помощью переключателя выберите Вход для зарегистрированных пользователей, введите Токен.

Перейдите по ссылке, для того чтобы в личном кабинете узнать об условиях доступа к сервису склонений Морфер и регистрации на сайте.

Возможно, для доступа на сервис склонения потребуется настройка прокси-сервера. Подробнее см. раздел документации Получение файлов из Интернета.

Склонение представлений

В приложении необходимо склонять не только ФИО физических лиц, но и представления других элементов списков. Однако иногда при автоматическом склонении возникают проблемы, и представления выводятся в печатных формах с неправильным склонением.

Например, не склоняются в приемлемом виде наименования должностей, подразделений, номенклатуры и т. д., особенно сложные сочетания:

■ Артист ансамбля песни и танца;

■ Мастер по ремонту бетонных насосов.

В приложении предусмотрен механизм склонения сложных названий , состоящих из нескольких слов:

■ Склонение фраз;

■ Хранение просклоненных фраз в приложении.

По умолчанию приложение склоняет представления автоматически, для этого необязательно использование сервиса склонений morpher.ru. В карточке объекта нажмите на ссылку Склонения.

Возможны неточности автоматического склонения.

Поэтому предоставляется возможность исправить неточные склонения и сохранить правильный вариант в карточке объекта, для того чтобы в печатные формы выводились правильные варианты склонения.

Исправьте склонения вручную, нажмите кнопку ОК. Для сохранения склонений в карточке элемента списка нажмите кнопку Записать и закрыть.

Если исправленный вариант склонения не устраивает, нажмите кнопку  Просклонять повторно.

При необходимости предусмотрена возможность автоматического склонения с использованием сервиса Морфер. Для этого необходимо произвести настройки (подробнее см. раздел Настройки приложения).

Получив результат, можно также поправить склонения. После исправления нажмите кнопку ОК. Для сохранения склонений в карточке объекта приложения нажмите кнопку Записать и закрыть. Будет сохранен исправленный вариант склонения.
