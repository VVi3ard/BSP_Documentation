# Временные файлы

Источник: https://infostart.ru/1c/articles/1398340/ (БСП 3.1.4, сверено с 3.1.11)

## ФайловаяСистема.СоздатьВременныйКаталог(Расширение)

> 3.1.11: есть, контекст С, вызовов в типовых: 119

Создает временный каталог. После окончания работы с временным каталогом его необходимо удалить с помощью ФайловаяСистема.УдалитьВременныйКаталог.

Доступ к файловой системе из кода конфигурации

```bsl
Результат = ФайловаяСистема.СоздатьВременныйКаталог(Расширение)
```

## ФайловаяСистема.УдалитьВременныйКаталог(Путь)

> 3.1.11: есть, контекст С, вызовов в типовых: 152

Удаляет временный каталог вместе с его содержимым, если возможно.

```bsl
ФайловаяСистема.УдалитьВременныйКаталог(Путь)
```

## ФайловаяСистема.УдалитьВременныйФайл(Путь)

> 3.1.11: есть, контекст С, вызовов в типовых: 334

Удаляет временный файл.

```bsl
ФайловаяСистема.УдалитьВременныйФайл(Путь)
```

## ФайловаяСистема.УникальноеИмяФайла(ИмяФайла)

> 3.1.11: есть, контекст С, вызовов в типовых: 0

Формирует уникальное имя файла в указанной папке, при необходимости добавляя к имени файла порядковый номер, например: "файл (2).txt", "файл (3).txt" и т.п.

```bsl
Результат = ФайловаяСистема.УникальноеИмяФайла(ИмяФайла)
```
