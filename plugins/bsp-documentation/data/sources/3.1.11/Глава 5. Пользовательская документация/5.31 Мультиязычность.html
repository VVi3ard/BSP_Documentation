5.31 Мультиязычность

Примечание для технического писателя: дополняет подсистему «Печать» для вывода печатных форм на разных языках (см. раздел документации Печать), а также позволяет автоматически переводить представления мультиязычных реквизитов. При наличии подсистемы «Перевод текста» имеется возможность подключения автоматического перевода текстов (подробнее см. раздел Сервис автоматического перевода).

Приложение позволяет использовать несколько языков одновременно. Подробнее см. раздел Региональные настройки.

Приложение позволяет формировать печатные формы на разных языках (подробнее см. раздел Как сформировать печатную форму на другом языке). Это может быть полезно, например, если необходимо предоставить какие-либо документы иностранному контрагенту: прайс-лист, счет на оплату и т. д.

Для этого необходимо предварительно произвести настройки:

■ Добавить дополнительный язык печатных форм;

■ Добавить перевод макета печатной формы на дополнительный язык;

■ Ввести на дополнительном языке наименования, выводимые в печатной форме.

Региональные настройки

В работе приложения можно использовать одновременно три языка – один основной и два дополнительных. На основном языке ведется работа в приложении, на дополнительных языках могут формироваться печатные формы и отчеты. Приложение позволяет сменить основной язык. Настроить использование языка можно в разделе Администрирование – Региональные настройки.

В разделе Региональные настройки можно:

■ Выбрать Часовой пояс приложения – все операции в приложении будут выполняться во времени этого часового пояса;

■ Посмотреть с помощью ссылки Время в приложении;

■ Настроить основной и дополнительный языки.

При необходимости для формирования печатных форм можно добавить еще несколько языков. Подробнее см. раздел Как добавить дополнительный язык печатной формы.

Также если используется несколько языков, то при начальном заполнении приложения на Начальной странице выходит всплывающее окно с региональными настройками.

После выбора основного и дополнительных языков следует нажать кнопку Изменить. В приложении существуют предопределенные и поставляемые элементы. При смене языков с помощью кнопки Изменить вызывается механизм начального заполнения этих элементов. Через некоторое время приложение готово к работе.

Если строка на дополнительном языке отсутствует, то заполняется значением основного языка (реквизита). Мультиязычные строки хранятся в шапке объекта. Если строка на дополнительных языках отсутствует, то заполняется на основном языке.

Если меняются местами основной и дополнительный языки, то значения также меняются местами:

■ Наименование (ru) <-> НаименованиеЯзык1 (en).

Если основной язык (ru) меняется на другой язык (не дополнительный, например, польский – pl):

■ Предопределенные и поставляемые элементы перезаполняются;

■ Старые значения (ru), введённые пользователем, сохраняются для нового языка (pl).

При добавлении новых данных: если интерактивно данные на дополнительных языках не были введены, то реквизиты на дополнительных языках заполняются значениями основного языка.

Отключить основной язык нельзя. При отключении доп. языков данные не очищаются.

На нескольких языках заполняются поля в следующих объектах приложения:

■ Виды контактной информации (поле Наименование);

■ Свойства (поле Наименование);

■ Варианты отчетов.

Просмотреть или заполнить поле Наименование на разных языках можно с помощью кнопки .

Как добавить дополнительный язык печатной формы

Перейдите по ссылке Языки печатных форм в разделе Администрирование – Печатные формы, отчеты и обработки.

С помощью кнопки Добавить язык выберите из списка нужный, при необходимости уточните регион. Для некоторых языков доступен выбор региональных настроек (указаны в скобках рядом с названием языка). Выбор региональных настроек влияет на вывод дат и чисел. Например, дата 24.12.2020 на языке «французский» будет выводиться 24/12/2020, а на языке «французский (Канада)» – 2020-12-24.

Как перевести макет на другой язык

После добавления других языков (см. раздел Как добавить дополнительный язык печатной формы) при редактировании макета появляется кнопка выбора языка (подробнее см. раздел документации Печать). Для перевода макета можно использовать сервис автоматического перевода, подробнее см. раздел Сервис автоматического перевода. В этом случае в макете можно нажать кнопку Перевести.

Откройте на редактирование нужный макет (макеты, которые поддерживают перевод, отмечены значком ), переключите на дополнительный язык и выполните перевод.

В макете следует переводить только статический текст, например заголовки, подписи и т. д.

Не нужно переводить имена областей и параметры. Параметры в печатной форме отображаются в угловых скобках, например <Наименование>. Параметры могут находиться внутри шаблонов текста, в этом случае они отображаются в квадратных скобках, например <Счет на оплату № [Номер] от [Дата]>, в этом случае переводить следует только текст шаблона за скобками.

После сохранения макета в колонке Доступные языки добавляется язык, на который был выполнен перевод.

Как перевести наименования, выводимые в печатной форме, на другой язык

Некоторые текстовые реквизиты элементов списков, выводимые в печатной форме, могут быть введены на других языках (например, в списке Демо: Номенклатура поле Наименование для печати). У таких реквизитов есть кнопка, при нажатии на которую открывается ввод на разных языках. Необходимо её нажать и ввести значение на нужном языке.

Помимо наименований может потребоваться перевод суммы прописью на другой язык. Для этого в карточке валюты (подробнее см. раздел документации Валюты) нажмите кнопку Параметры прописи в панели навигации, выберите язык из выпадающего списка, заполните параметры прописи на этом языке. После выхода из окна параметров прописи нажмите Записать и закрыть.

Сервис автоматического перевода

Примечание для технического писателя: для подключения автоматического перевода текстов требуется наличие подсистемы «Перевод текста».

Для упрощения перевода макетов и ввода реквизитов на разных языках в приложении предусмотрена возможность использования онлайн-сервисов перевода текста (Яндекс.Переводчик и Google Переводчик). Для того чтобы задействовать эту возможность, включите флажок Перевод текста с помощью внешнего сервиса в разделе Администрирование – Печатные формы, отчеты и обработки и выберите из списка нужный Сервис перевода текста, далее следуйте инструкции по настройке выбранного сервиса.

За использование сервиса перевода текста может взиматься плата. Условия использования необходимо уточнить на сайте соответствующего сервиса.

После подключения сервиса перевода текста становится возможным:

■ перевести макет печатной формы автоматически, для этого в окне редактирования макета нужно нажать кнопку Перевести.

■ автоматически перевести наименования элементов списков в окне ввода на разных языках с помощью кнопки Перевести автоматически.

Как сформировать печатную форму на другом языке

Если для печатной формы предусмотрен вывод на других языках, то при просмотре печатной формы появляется меню выбора языка. Выберите необходимый язык, печатная форма переформируется на этом языке. Можно проверить печатную форму и распечатать. Подробнее см. раздел документации Печать.

Если в печатной форме наблюдается некорректная настройка (например, не все переведено на требуемый язык), необходимо проверить правильность действий на всех этапах работы: проверить корректность переводов макета, элементов списков и валюты.

Роли для перевода на дополнительные языки

Для перевода на дополнительные языки в приложении предусмотрены следующие роли:

Роль

Краткое описание

Полные права

Выбор дополнительных языков, настройка сервиса перевода текста, перевод текста макетов печатных форм.

Базовые права

Перевод текста необходимых элементов списков, формирование печатных форм на других языках.
